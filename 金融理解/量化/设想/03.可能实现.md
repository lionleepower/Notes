有，而且已经存在不少可以拆解复用的开源代码。你不需要从爬虫、NLP 模型和回测框架全部重新写起。

# 二、新闻情绪分析模块

## 2. ProsusAI FinBERT

仓库：

```text
ProsusAI/finBERT
```

FinBERT 是面向金融文本的情绪分类模型。它可以将一句新闻标题或文本分类为：

```text
positive
negative
neutral
```

并输出每个类别的概率。([GitHub](https://github.com/ProsusAI/finBERT "GitHub - ProsusAI/finBERT: Financial Sentiment Analysis with BERT · GitHub"))

例如：

```text
"NVIDIA reports record quarterly revenue."

positive: 0.94
neutral:  0.05
negative: 0.01
```

原始仓库本身具有参考价值，但它的实现依赖较早版本的 `pytorch_pretrained_bert`。仓库也说明模型已经发布到 Hugging Face Model Hub。对于新项目，建议直接通过现代版本的 `transformers` 加载模型，而不是完全照搬旧代码。([GitHub](https://github.com/ProsusAI/finBERT "GitHub - ProsusAI/finBERT: Financial Sentiment Analysis with BERT · GitHub"))

克隆命令：

```bash
git clone https://github.com/ProsusAI/finBERT.git
```

在自己的项目中，更适合使用类似下面的简化代码：

```python
from transformers import pipeline

classifier = pipeline(
    task="text-classification",
    model="ProsusAI/finbert",
    tokenizer="ProsusAI/finbert",
    top_k=None,
)

headline = "Company reports weaker-than-expected quarterly revenue."
result = classifier(headline)

print(result)
```

你可以将输出转换为单一情绪分数：

```python
sentiment_score = positive_probability - negative_probability
```

这样：

```text
接近 +1：明显利好
接近  0：接近中性
接近 -1：明显利空
```

signal = bar.get("signals", {}).get("prediction", 0)

# 八、最适合你的第一版项目结构

不要直接修改这些大型仓库。创建自己的轻量级项目：

```text
news_trading_system/
├── data/
│   ├── raw_news/
│   ├── processed_news/
│   └── prices/
│
├── src/
│   ├── fetch_news.py
│   ├── fetch_prices.py
│   ├── sentiment_finbert.py
│   ├── aggregate_daily_score.py
│   ├── strategy.py
│   ├── backtest.py
│   └── metrics.py
│
├── notebooks/
│   ├── 01_test_finbert.ipynb
│   ├── 02_build_daily_signal.ipynb
│   └── 03_backtest_spy.ipynb
│
├── requirements.txt
└── README.md
```

第一版的数据流应该保持简单：

```text
获取 SPY 历史价格
-> 获取财经新闻标题
-> 使用 FinBERT 评分
-> 按日期聚合
-> 生成每日风险分数
-> 根据信号决定持有 0%、50% 或 100% SPY
-> 与 Buy-and-Hold 比较
```

情绪聚合公式可以先写成：

# $$  
DailySentiment_t

## \frac{1}{N_t}  
\sum_{i=1}^{N_t}  
\left(  
P_{i,\text{positive}}

P_{i,\text{negative}}  
\right)  
$$

后续再加入来源权重和时间衰减：

# $$  
DailySentiment_t

## \frac{  
\sum_{i=1}^{N_t}  
w_i  
e^{-\lambda \Delta t_i}  
\left(  
P_{i,\text{positive}}

P_{i,\text{negative}}  
\right)  
}{  
\sum_{i=1}^{N_t}  
w_i  
e^{-\lambda \Delta t_i}  
}  
$$

# 十、需要避免的误区

有一些 GitHub 项目会展示类似的结构：

```text
FinBERT 情绪分析
-> Alpaca API
-> 自动买卖股票
```

例如，有开源项目将 FinBERT、新闻标题、回测和 Alpaca 实盘接口组合在一起。([GitHub](https://github.com/Praneshv25/AI-Trading-Bot?utm_source=chatgpt.com "Praneshv25/AI-Trading-Bot"))

这些项目可以用来阅读代码，但不应该直接接入真实资金。常见问题包括：

```text
没有严格处理新闻发布时间
存在未来数据泄漏
没有去除重复新闻
忽略买卖价差和滑点
没有处理市场休市时间
没有比较简单基准策略
没有 Walk-Forward 验证
```

你目前最合理的起点不是“自动交易机器人”，而是：

> 用 FinBERT、历史新闻和 SPY 数据制作一个可重复运行的离线回测 Notebook，先验证新闻情绪是否能够降低最大回撤，或者改善风险调整后的收益。
