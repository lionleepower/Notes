## 建议阅读顺序

先按下面顺序看：

```text
1. ProsusAI/finBERT
2. AI4Finance-Foundation/FinNLP
3. ml4t/backtest
4. microsoft/qlib
```

原因是：

```text
FinBERT：
先理解一条新闻如何变成情绪分数

FinNLP：
再理解新闻从哪里获取，如何整理成数据集

ml4t/backtest：
学习如何将信号放进一个严格按时间运行的回测系统

Qlib：
最后再学习更完整、更工程化的量化研究框架
```

## 克隆命令

```bash
git clone https://github.com/ProsusAI/finBERT.git
git clone https://github.com/AI4Finance-Foundation/FinNLP.git
git clone https://github.com/ml4t/backtest.git
git clone https://github.com/microsoft/qlib.git
```

其中，`ml4t/backtest` 的官方文档也给出了 `pip install ml4t-backtest` 的安装方式。([ml4trading.io](https://ml4trading.io/docs/backtest/getting-started/installation/?utm_source=chatgpt.com "Installation - ML4T Backtest"))

你一开始不需要把四个仓库全部读完。最优先的目标是先运行 FinBERT，输入几条新闻标题，观察它输出的情绪概率。
