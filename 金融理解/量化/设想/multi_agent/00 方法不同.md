
现在比较吃香的量化方向，大概分几层：

## 1. 传统但仍然很强的

**因子投资 Factor Investing**

比如动量、价值、质量、低波动、盈利能力、资金流。很多机构还是靠这个框架吃饭。

**统计套利 Statistical Arbitrage**

包括 pairs trading、mean reversion、cointegration。你的“股票 A 涨，股票 B 后面会不会涨”就靠近这一类。

**事件驱动 Event-driven**

财报、并购、政策、FDA 批准、降息、战争、供应链新闻等。

## 2. 现在很常见的机器学习路线

**Gradient Boosting**

比如 XGBoost、LightGBM、CatBoost。  
这类非常实用，比深度学习更适合个人先上手。

**时间序列模型**

ARIMA、GARCH、HMM、Kalman Filter、DCC-GARCH。  
适合研究波动率、状态切换、资产相关性变化。

**深度学习时间序列**

LSTM、GRU、Transformer、Temporal Fusion Transformer。  
听起来高级，但容易过拟合，个人项目要谨慎。

## 3. 最近比较热的 AI / LLM 路线

**新闻情绪分析**

用 FinBERT、LLM、新闻摘要、财报电话会、社交媒体情绪做信号。现在很多 AI quant survey 都把 LLM 和 unstructured data 当成重点方向。([arXiv](https://arxiv.org/html/2503.21422v1?utm_source=chatgpt.com "From Deep Learning to LLMs: A survey of AI in Quantitative ..."))

**Agentic Quant / Research Agent**

让 agent 自动做：

```text
找新闻
提取事件
生成假设
跑回测
写报告
监控风险
```

这正好适合你现在的想法。2025 年相关讨论里，LLM 被更多用于数据 ingestion、sentiment analysis、forecasting 和研究流程自动化。([BizTech Magazine](https://biztechmagazine.com/article/2025/03/quant-strats-2025-4-ways-integrate-llms-quantitative-finance?utm_source=chatgpt.com "Quant Strats 2025: 4 Ways to Integrate LLMs in ..."))

**Reinforcement Learning**

让 agent 学会买、卖、持有。这个听起来最酷，但个人做起来最容易翻车，因为 reward design、交易成本、滑点、非平稳市场都很麻烦。

## 4. 我建议你优先做的路线

你的项目最适合这样走：

```text
第一层：新闻情绪分析
第二层：股票联动条件概率
第三层：LightGBM / XGBoost 排序模型
第四层：简单 agent 自动生成每日观察列表
```

不要一开始就冲 RL。  
更靠谱的 MVP 是：

```text
输入：新闻 + 股票价格 + 大盘状态
输出：
1. 今日强事件股票
2. 相关股票联动概率
3. 未来 1/3/5 天上涨概率
4. 风险评分
5. 是否进入 watchlist
```

最适合你的项目名可以叫：

```text
News-Driven Stock Linkage Agent
```

或者更学术一点：

```text
Event-Aware Temporal Lead-Lag Trading System
```

最关键一句：**现在先进的不是“某一个神奇模型”，而是多信号融合：价格、新闻、情绪、事件、市场状态、风险控制一起用。**
