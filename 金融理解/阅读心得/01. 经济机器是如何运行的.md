
>三条原则

> 1 不要让债务的增长速度超过收入

债务的最终负担可能会把你给压垮

> 2. 不要让收入的增长速度超过生产率

价格上升会导致竞争力下降

> 3.  尽一切努力提高生产率

天行健，君子以自强不息


## 三条原则之间的关系


```
债务增长 > 收入增长= 未来还债压力变大
收入增长 > 生产率增长= 成本上升、通胀、竞争力下降
生产率增长= 真正可持续的财富来源
```

所以它们不是三条孤立的规则，而是一条链：

```
生产率决定长期收入
收入决定债务承受能力
债务只能提前消费未来收入
```


## 1. 不要让债务增长速度超过收入

更完整地说是：

> 债务本身不一定坏，但如果债务增长长期快于收入增长，未来收入会越来越多地被拿去还债，消费和投资能力会被压缩。

### 个人例子

比如你每月收入 £1500：

```
房租 + 吃饭 + 交通 = £1000剩余 = £500
```

如果你借钱买手机、旅游、炒股，每月还款变成 £400：

```
剩余现金 = £100
```

这时候你看起来还能生活，但抗风险能力很低。  
一旦生病、丢工作、家里有事，就很容易崩。

### 国家例子

一个国家如果靠大量借债刺激经济，短期 GDP 会好看：

```
修路、建楼、发贷款、企业扩张
```

但如果这些投资没有带来足够高的收入增长，未来就会变成：

```
债务利息越来越高财政压力越来越大企业还债压力越来越大居民不敢消费
```

所以债务不是不能用，而是要看它有没有带来未来收入。

### 投资例子

贷款炒股就是典型风险：

```
贷款利率 = 5%股票预期收益 = 8%
```

看起来能赚 3%，但问题是股票收益不稳定。  
如果第一年股票跌 20%，你不但亏本金，还要继续还利息。

所以这条原则放到个人身上就是：

> 不要用稳定的还款义务，去赌不稳定的未来收益。


## 2. 不要让收入增长速度超过生产率


这句话不是说“收入增长不好”，而是说：

> 如果工资、消费、资产价格上涨，但真实生产效率没有提高，那么这种增长很容易变成通胀，最终削弱竞争力。

### 简单例子

假设一个咖啡店员工以前每小时做 20 杯咖啡，工资 £10/h。

后来工资涨到 £15/h，但每小时还是只能做 20 杯咖啡。  
那么老板的单位成本上升了。

老板可能会：

```
提高咖啡价格减少员工降低利润
```

如果咖啡涨价太多，顾客就不买了。  
所以收入上涨要有生产率支撑。

### 国家竞争力例子

如果一个国家工资涨得很快，但工人效率、技术水平、产业能力没有同步提升，那么出口商品会变贵。

比如原来：

```
一件产品成本 = $10卖 $12 还有竞争力
```

后来工资上涨，但生产效率没提高：

```
成本变成 $15卖 $17 才赚钱
```

这时候其他国家可能还能 $12 卖同类产品，你就失去竞争力。

### 资产泡沫例子

房价、股价暴涨，但居民收入和企业利润没有同步增长，也是一种“价格增长超过生产率”的表现。

比如：

```
工资一年涨 3%房价一年涨 20%
```

短期看大家觉得资产升值了，但长期会导致：

```
年轻人买不起房,消费被房贷压缩
资金流向炒房而不是创新,
经济效率下降
```

所以这条原则可以理解成：

> 财富增长不能长期靠价格上涨，最终要靠真实产出提高。


## 3. 尽一切努力提高生产率


这条是三条里最根本的。

债务可以制造短期繁荣，收入上涨可以制造短期快乐，但真正让社会和个人长期变强的是：

> 单位时间内创造更多真实价值。

### 个人例子

比如你现在作为学生，有几种提升生产率的方式：

```
学会更高效写代码掌握 AI / HPC / 数据分析技能提高英语沟通能力建立求职项目集锻炼身体，提高精力
```

这些东西短期不一定立刻赚钱，但会提高你未来的单位时间价值。

以前你可能一周才能完成一个项目 demo。  
以后你有更强的工具链、英语、工程能力后，可能两天就能完成。

这就是个人生产率提高。

### 企业例子

一个公司提高生产率，不只是让员工加班，而是：

```
自动化流程改进供应链使用更好的软件系统培训员工提高产品质量减少浪费
```

比如以前 10 个人一天处理 1000 个订单。  
引入自动化系统后，10 个人一天处理 5000 个订单。  
这才是真正的生产率提升。

### 国家例子

国家层面的生产率来自：

```
教育科技基础设施制度效率能源效率产业升级
```

比如高铁、港口、互联网、芯片、AI、自动化制造，本质上都在提高社会整体生产率。

同样一小时劳动，能创造更多价值，社会才会真正变富。
