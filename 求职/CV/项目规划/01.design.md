Performance-Agent Lab

一个结合 HPC/CUDA/AI Agent 的工程项目：

1. CUDA Kernel Benchmark Suite
   - softmax / layernorm / reduction / matrix transpose
   - naive vs optimized
   - correctness check
   - latency / bandwidth / speedup
   - Nsight Compute profiling notes

2. HPC Experiment Automation
   - 自动生成 Slurm scripts
   - 跑不同 problem size / threads / ranks
   - 收集 runtime / speedup / efficiency
   - 输出 CSV + plots

3. AI Agent Layer
   - agent 读取 benchmark results
   - 自动总结 bottleneck
   - 根据 profiling metrics 给优化建议
   - 用 eval set 测试 agent 的建议是否靠谱
   - 记录 tool calls / latency / cost / failure cases

4. Report + Dashboard
   - 每个 kernel/experiment 有图表
   - 每次优化有 before/after
   - 每个 agent 输出有 evaluation
