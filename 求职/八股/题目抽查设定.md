


先给你一个**能直接用的万能模板**：

```
请扮演面试官，抽查我的面试题。

范围：{TCP 这篇 / 全部四篇 / 三次握手+四次挥手+TIME_WAIT}
方式：{一次问一道，我答完你再点评并给下一题 / 一次性出 5 道我统一作答}
数量：{5 道}
难度：{高频必考为主 / 混入易混点和常见误区 / 上压力追问}
标准：{对照笔记里的"面试怎么答"和"常见误区"判分，指出我漏了哪个关键词、哪里说反了}
```

把花括号换成你当时想要的就行。

---

几种我预判你会常用的场景，直接抄：

**日常滚动复习（最推荐）**

```
面试官模式，从 TCP 这篇随机抽 5 道高频题，一次问一道。
我答完你按笔记的"面试怎么答"点评，重点指出漏掉的关键词和答反的地方，然后再出下一题。
```

**模拟真实压力面**

```
模拟真实面试，主题限定 HTTP。先问一道基础题，根据我的回答顺着追问深挖，
答得好就加难度，答错或含糊就抓住继续问。至少追问三层。
```

**专攻易混点**

```
只考我笔记里"常见误区"部分：TCP、HTTP 两篇。
每题给一个容易答错的说法，让我判断对错并说明理由，最后告诉我正确版本。
```

**快速自测（省时间）**

```
从四篇里各抽 2 道，一次性列出 8 道题，我统一作答后你一起批改打分。
```

---

两个能让抽查更准的小技巧：

一是**明确"对照笔记判分"**。因为这些内容我训练数据里也有，但你的笔记有自己的措辞、关键词和误区清单，你要我按你的笔记标准来查，就在提示词里点明「对照我笔记的关键词/面试怎么答」，我会以你的版本为准，而不是自由发挥。

二是**告诉我要不要藏答案**。默认我问完会等你答；如果你只想要题目自己先想，可以加一句「只出题，先别给答案，我说『看答案』你再公布」。

要不要我现在就先从某一篇出几道给你试跑一轮，顺便让你感受下点评的颗粒度？
