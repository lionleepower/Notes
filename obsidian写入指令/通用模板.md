## 格式要求

1. 输出完整 Markdown 内容，便于直接复制到 Obsidian。
    
2. 数学公式必须使用 Obsidian 兼容的 MathJax 格式：
    
    - 行内公式使用 `$...$`
        
    - 在 Obsidian 中，独立公式应当直接使用：

```
$$公式$$
```

不要写成：

```
## $$公式$$
```

也不要在公式内部的每一行前面加 `##`        ```
        
3. 不要使用 `\(...\)` 或 `\[...\]`。
    
4. 不要在代码块标记后添加额外属性，例如 `id="..."`。
    
5. 代码、命令行和目录结构使用 Markdown 代码块。
    
6. 中英文术语同时保留，例如：
    
    - discretisation：离散化
        
    - sparse matrix：稀疏矩阵
        
7. 解释尽量使用中文，但保留关键 English keywords。
    
8. 不要省略中间推导步骤。
    
9. 对抽象概念至少给出一个具体例子。
    
10. 对容易混淆的地方单独增加“常见误区”章节。
    
11. 最后增加：
    

- 关键术语表
    
- 核心结论
    
- 自测问题
    
- 下一步学习建议
