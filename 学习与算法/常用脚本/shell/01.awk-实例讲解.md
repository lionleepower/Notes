这句：

```
awk '/Time \(sec\):/{t= $NF} END{print t}' $LOG
```

不是“直接取最后一行的最后一列”。

它真正的逻辑是：

```
每次遇到 Time (sec): 这一行，
就把这一行的最后一列保存到变量 t。
最后文件读完后，
打印变量 t。
```

拆开看：

```
/Time \(sec\):/
```

条件：只处理包含 `Time (sec):` 的行。

```
{t=$NF}
```

动作：把当前行的最后一列保存到变量 `t`。

`NF` 是当前行字段数量。  
$NF 就是“当前行最后一列”。

例如：

```
Time (sec): 12.345
```

这一行有 3 列：

```
$1 = Time
$2 = (sec):
$3 = 12.345
NF = 3
$NF = $3 = 12.345
```

如果日志里有三次：

```
Time (sec): 12.345
Time (sec): 11.980
Time (sec): 25.500
```

awk 会这样走：

```
读到第一行 Time：t = 12.345
读到第二行 Time：t = 11.980
读到第三行 Time：t = 25.500
文件结束：执行 END{print t}
输出：25.500
```

所以它打印的是：

```
最后一次匹配到 Time (sec): 的那一行的最后一列
```

不是整个文件最后一行。

最后这一段：

```
END{print t}
```

意思是：所有行都读完以后，只执行一次，打印 `t`。

推荐写法稍微改一下：

```
awk '/Time \(sec\):/{t=$NF} END{print t}' "${LOG}"
```

`{t= $NF}` 里的空格不影响，但 `{t=$NF}` 更清楚。  
$LOG 推荐写成 `"${LOG}"`，更安全。
