# Awk 基础：按行读取、按列处理、按条件筛选

| 类型         | 写法 / 符号                  | 含义                              | 例子                                                      | 注意点                                       |
| ---------- | ------------------------ | ------------------------------- | ------------------------------------------------------- | ----------------------------------------- |
| 整行匹配       | `/abc/`                  | 当前整行包含 `abc` 就执行动作              | `awk '/Time/{print $0}' log.txt`                        | `/.../` 里面是 regular expression，不是普通字符串    |
| 列等于字符串     | `$1 == "small"`          | 第 1 列等于 `small`                 | `awk -F, '$1 == "small" {print $0}' file.csv`           | 字符串要加双引号 `"small"`                        |
| 数字比较       | `$4 > 10`                | 第 4 列大于 `10`                    | `awk -F, '$4 > 10 {print $0}' file.csv`                 | 常见比较符号：常见比较符号：==、!=、`>`、`<`、`>=`、`<=`     |
| 行号条件       | `NR > 1`                 | 从第 2 行开始处理，也就是跳过表头              | `awk -F, 'NR > 1 {print $0}' file.csv`                  | `NR` 是当前行号，不是列号                           |
| 某列匹配正则     | `$1 ~ /small/`           | 第 1 列匹配 `small`                 | `awk '$1 ~ /small/ {print $0}' file.txt`                | `~` 表示左边字段匹配右边正则                          |
| 某列不匹配正则    | `$1 !~ /small/`          | 第 1 列不匹配 `small`                | `awk '$1 !~ /small/ {print $0}' file.txt`               | `!~` 表示不匹配                                |
| 多条件：并且     | `&&`                     | 两个条件都满足才执行动作                    | `awk -F, 'NR > 1 && $1 == "small" {print $0}' file.csv` | 常用于“跳过表头 + 筛选列”                           |
| 多条件：或者     | `                        |                                 | `                                                       | 任意一个条件满足就执行动作                             |
| 正则特殊字符     | `. * + ? ^ $ [] () \| \` | 这些符号在 `/.../` 中有特殊含义            | `awk '/3\.14/{print $0}' file.txt`                      | 如果想匹配符号本身，通常要加 `\` 转义                     |
| 匹配小数点      | `\.`                     | 匹配真正的点号 `.`                     | `awk '/3\.14/{print $0}' file.txt`                      | `/3.14/` 中的 `.` 会表示“任意一个字符”               |
| 匹配括号       | `\(` 和 `\)`              | 匹配真正的括号                         | `awk '/Time \(sec\):/{print $3}' log.txt`               | `()` 在正则中有分组含义，所以要转义                      |
| 匹配方括号      | `\[` 和 `\]`              | 匹配真正的方括号                        | `awk '/error\[0\]/{print $0}' log.txt`                  | `[]` 在正则中表示字符集合，所以要转义                     |
| Shell 引号保护 | `'...'`                  | 用单引号包住 awk 程序，保护 `$1`、`$2`、`$3` | `awk '{print $3}' file.txt`                             | 推荐写法，避免 shell 提前展开 `$3`                   |
| 不推荐写法      | `"..."`                  | 双引号可能让 shell 先处理 `$3`           | `awk "{print $3}" file.txt`                             | `$3` 可能先被 shell 当成参数展开，导致 awk 收不到真正的 `$3` |
| 普通字符串匹配    | `index($0, "文本")`        | 按普通字符串查找，不走正则                   | `awk 'index($0, "Time (sec):") {print $3}' log.txt`     | 复杂文本可以用 `index` 避免写很多 `\`                 |
| 最实用记法      | `awk '/.../'`            | `/.../` 里面是正则                   | `awk '/Time \(sec\):/{print $3}' log.txt`               | 特殊字符要转义                                   |
| 最实用记法      | `awk '{print $3}'`       | awk 程序外面优先用单引号                  | `awk '{print $3}' file.txt`                             | 单引号保护 `$3` 不被 shell 提前处理                  |
| 最实用记法      | `index($0, "文本")`        | 复杂普通文本匹配用 `index`               | `awk 'index($0, "Time (sec):") {print $3}' log.txt`     | 不需要把括号写成 `\(sec\)`                        |
## 1. awk 是什么？

可以先把 `awk` 理解成一个专门处理文本和表格数据的命令行工具。

它最核心的功能是：

```text
awk = 一行一行读文件 + 把每行切成列 + 按条件处理或打印
```

也就是说，`awk` 很适合处理：

- `.txt` 文本日志
    
- `.log` 程序输出
    
- `.csv` 表格文件
    
- HPC 实验产生的 runtime / speedup / efficiency 结果
    
- Slurm job output
    
- 任何“很多行 + 每行有很多列”的数据
    

例如有一个文件 `log.txt`：

```text
Step 1 Time 0.23
Step 2 Time 0.25
Step 3 Time 0.22
```

如果想打印每一行的第 4 列，也就是时间，可以写：

```bash
awk '{print $4}' log.txt
```

输出：

```text
0.23
0.25
0.22
```

---

## 2. awk 的最基本格式

`awk` 的基本语法是：

```bash
awk '条件 {动作}' 文件
```

可以理解为：

```text
对于文件中的每一行：
    如果这一行满足条件：
        执行动作
    如果这一行不满足条件：
        跳过
```

所以：

```bash
awk '条件 {动作}' file
```

里面的“条件”控制是否处理当前行。

里面的“动作”控制对当前行做什么。

---

## 3. 最简单的 awk：打印内容

### 3.1 打印整行

```bash
awk '{print $0}' file.txt
```

含义：

```text
对 file.txt 的每一行，打印整行。
```

其中 `$0` 表示当前整行。

例如 `file.txt` 内容是：

```text
small 10 0.5
medium 20 0.8
large 30 1.2
```

执行：

```bash
awk '{print $0}' file.txt
```

输出：

```text
small 10 0.5
medium 20 0.8
large 30 1.2
```

---

### 3.2 打印第 1 列

```bash
awk '{print $1}' file.txt
```

含义：

```text
对每一行，打印第 1 列。
```

输出：

```text
small
medium
large
```

---

### 3.3 打印第 1 列和第 3 列

```bash
awk '{print $1, $3}' file.txt
```

含义：

```text
对每一行，打印第 1 列和第 3 列。
```

输出：

```text
small 0.5
medium 0.8
large 1.2
```

这里的逗号 `,` 会让 `awk` 在输出列之间自动加空格。

## 4. awk 如何把一行切成列？

默认情况下，`awk` 使用空白字符分列。

空白字符包括：

- 空格
    
- Tab
    
- 连续多个空格
    

例如这一行：

```text
small    10     0.5
```

虽然中间有多个空格，但是 `awk` 仍然会把它看成三列：

```text
$1 = small
$2 = 10
$3 = 0.5
```

所以：

```bash
awk '{print $1, $3}' file.txt
```

会打印第 1 列和第 3 列。

```text

```


```text
10
```

```text
100
```

# 11. awk 的条件：什么情况下执行动作？

`awk '条件 {动作}' file` 里的条件可以理解成：

```text
当前这一行满足条件，就执行动作。
当前这一行不满足条件，就跳过。
```

例如：

```bash
awk '$2 > 10 {print $0}' file.txt
```

意思是：

```text
如果第 2 列大于 10，就打印整行。
```

---

## 12. 条件 1：匹配整行

### 12.1 打印包含某个关键词的行

```bash
awk '/Time/{print $0}' log.txt
```

含义：

```text
如果当前这一整行包含 Time，就打印整行。
```

例如 `log.txt`：

```text
Start simulation
Time 0.23
Finish simulation
```

执行：

```bash
awk '/Time/{print $0}' log.txt
```

输出：

```text
Time 0.23
```

---

### 12.2 匹配带特殊符号的文本

原始命令：

```bash
awk '/Time \(sec\):/{print $3}' log.txt
```

含义：

```text
如果当前行包含 Time (sec):，就打印第 3 列。
```

这里写成：

```text
\(sec\)
```

是因为括号 `(` 和 `)` 在正则表达式里有特殊含义。

所以如果想匹配字面意义上的括号，需要转义：

```text
\( 表示匹配普通左括号
\) 表示匹配普通右括号
```

例如 `log.txt`：

```text
Size 1000
Time (sec): 12.35
Memory 512MB
```

执行：

```bash
awk '/Time \(sec\):/{print $3}' log.txt
```

输出：

```text
12.35
```

这一行按照空格分列：

```text
$1 = Time
$2 = (sec):
$3 = 12.35
```

## 13. 条件 2：判断某一列等于某个值

```bash
awk -F, '$1 == "small" {print $0}' file.csv
```

含义：


例如 `file.csv`：

```csv
size,runtime,cores

large,1.9,16
```

执行：

```bash
awk -F, '$1 == "small" {print $0}' file.csv
```


注意：

这里使用了 `-F,`，表示用逗号作为分隔符。

否则 `awk` 默认会按空格分列，而 CSV 文件通常是用逗号分列。

## 19. 条件 7：多个条件组合

### 19.1 使用 `&&` 表示“并且”

```bash
awk -F, 'NR > 1 && $1 == "small" {print $0}' file.csv
```

含义：

```text
行号大于 1，并且第 1 列等于 small，才打印整行。
```

例如：

```csv
size,runtime,cores
small,10.2,1
medium,5.3,4
small,2.8,8
large,1.9,16
```

执行：

```bash
awk -F, 'NR > 1 && $1 == "small" {print $0}' file.csv
```

输出：

```text
small,10.2,1
small,2.8,8
```

这里 `NR > 1` 用来跳过表头。

`$1 == "small"` 用来筛选 size 等于 small 的行。

两个条件都满足才输出。

### 19.2 使用 `||` 表示“或者”

```bash
awk -F, '$1 == "small" || $1 == "medium" {print $0}' file.csv
```

含义：

```text
如果第 1 列等于 small，或者第 1 列等于 medium，就打印整行。
```

例如：

```csv

```

执行：

```bash
awk -F, '$1 == "small" || $1 == "medium" {print $0}' file.csv
```


# 20. 处理 CSV 文件

## 20.1 为什么 CSV 要用 `-F,`？

CSV 文件通常长这样：

```csv
size,runtime,cores,threads
small,10.2,1,1
medium,5.3,4,1
large,2.1,8,2
```

它的字段之间不是空格，而是逗号。

所以要告诉 `awk`：

```text
请用逗号分列。
```

命令是：

```bash
awk -F, '{print $1, $4}' file.csv
```

其中：

```text
-F, = field separator is comma
```

也就是：

```text
字段分隔符是逗号。
```

---

## 20.2 打印 CSV 的第 1 列和第 4 列

```bash
awk -F, '{print $1, $4}' file.csv
```

例如：

```csv
size,runtime,cores,threads
small,10.2,1,1
medium,5.3,4,1
large,2.1,8,2
```

执行：

```bash
awk -F, '{print $1, $4}' file.csv
```

输出：

```text
size threads
small 1
medium 1
large 2
```

注意：输出默认用空格分隔，而不是逗号。

如果想输出仍然是逗号，可以写：

```bash
awk -F, '{print $1 "," $4}' file.csv
```

输出：

```csv
size,threads
small,1
medium,1
large,2
```

---

## 20.3 跳过 CSV 表头

```bash
awk -F, 'NR > 1 {print $0}' file.csv
```

含义：

```text
跳过第 1 行，从第 2 行开始打印。
```

## 20.4 筛选某一列

```bash
awk -F, 'NR > 1 && $1 == "small" {print $0}' file.csv
```

含义：

```text
跳过表头，并且只打印第 1 列等于 small 的数据行。
```

# 21. awk 的计算功能

- 求和
    
- 计数
    
- 求平均值
    
- 统计最大值

## 22. 求平均值

原始命令：

```bash
awk -F, 'NR > 1 {sum += $4; count += 1} END{print sum / count}' file.csv
```

它的核心结构是：

```bash
awk -F, 'NR > 1 {sum += $4; count += 1} END{print sum / count}' file.csv
```

可以拆成两部分：

```text
NR > 1 {sum += $4; count += 1}
```

和：

```text
END{print sum / count}
```

---

## 23. 逐步理解平均值命令

假设 `file.csv` 是：

```csv
size,cores,threads,runtime
small,1,1,20
medium,4,1,10
large,8,2,5
```

命令：

```bash
awk -F, 'NR > 1 {sum += $4; count += 1} END{print sum / count}' file.csv
```

### 23.1 第 1 行：表头

```text
size,cores,threads,runtime
```

此时：

```text
NR = 1
```

条件是：

```text
NR > 1
```

不满足，所以跳过。

---

### 23.2 第 2 行

```text
small,1,1,20
```

此时：

```text
NR = 2
$4 = 20
```

执行：

```text
sum += $4
count += 1
```

也就是：

$$  
\mathrm{sum} = 0 + 20 = 20  
$$

$$  
\mathrm{count} = 0 + 1 = 1  
$$

---

### 23.3 第 3 行

```text
medium,4,1,10
```

此时：

```text
$4 = 10
```

执行后：

$$  
\mathrm{sum} = 20 + 10 = 30  
$$

$$  
\mathrm{count} = 1 + 1 = 2  
$$

---

### 23.4 第 4 行

```text
large,8,2,5
```

此时：

```text
$4 = 5
```

执行后：

$$  
\mathrm{sum} = 30 + 5 = 35  
$$

$$  
\mathrm{count} = 2 + 1 = 3  
$$

---

### 23.5 文件读完后执行 END

文件所有行处理完后，执行：

```text
END{print sum / count}
```

也就是：

$$  
\frac{\mathrm{sum}}{\mathrm{count}} = \frac{35}{3} = 11.6667  
$$

所以输出大约是：

```text
11.6667
```

## 24. awk 的核心模板

最重要的模板是：

```bash
awk '条件 {每一行要做的事} END{最后统一做的事}' 文件
```

可以理解成：

```text
awk '
    条件 {
        对每一行执行的动作
    }
    END {
        文件全部读完后执行的动作
    }
' 文件
```

例如求平均值：

```bash
awk -F, 'NR > 1 {sum += $4; count += 1} END{print sum / count}' file.csv
```

含义：

```text
对每一行：
    如果不是表头：
        把第 4 列加入 sum
        count 加 1

文件读完后：
    打印 sum / count
```

# 25. BEGIN、主体、END 的执行顺序

完整的 `awk` 可以分成三段：

```bash
awk 'BEGIN{开始前执行} 条件{逐行执行} END{结束后执行}' file
```

执行顺序是：

```text
1. BEGIN：读取文件之前执行一次
2. 主体：读取文件时，每一行判断条件并执行动作
3. END：文件全部读完之后执行一次
```

例如：

```bash
awk -F, 'BEGIN{print "runtime values:"} NR > 1 {print $4} END{print "done"}' file.csv
```

假设 `file.csv` 是：

```csv
size,cores,threads,runtime
small,1,1,20
medium,4,1,10
large,8,2,5
```

输出：

```text
runtime values:
20
10
5
done
```

## 26.5 计算总核心数


这里：

## 26.6 根据最大核心数筛选合法配置


$$

$$

$$

$$

$$  
128 \times 1 = 128 \leq 128  
$$

$$

$$

# 27. awk 和 grep 的区别

`grep` 更像是：

```text
从很多行里挑出包含某个关键词的行。
```

`awk` 更像是：

```text
从很多行里挑出某些行，再从这些行里挑出某些列，还可以计算。
```

|工具|主要用途|例子|
|---|---|---|
|`grep`|按关键词筛选行|找出包含 `Time` 的行|
|`awk`|按列处理、筛选、计算|打印第 3 列、计算平均 runtime|

例如：

```bash
grep "Time" log.txt
```

只能找出包含 `Time` 的行。

而：

```bash
awk '/Time/{print $3}' log.txt
```

不仅能找出包含 `Time` 的行，还能只打印第 3 列。

# 31. 核心结论

1. `awk` 的核心逻辑是：
    

```text
一行一行读文件，按列切分，然后根据条件执行动作。
```

2. 最基本格式是：
    

```bash
awk '条件 {动作}' 文件
```

3. 最常用的列变量是：
    

```text
$0 = 整行
$1 = 第 1 列
$2 = 第 2 列
$NF = 最后一列
```

4. 最常用的行变量是：
    

```text
NR = 当前行号
NF = 当前行列数
```

5. 处理 CSV 时通常要加：
    

```bash
-F,
```

表示用逗号分列。

6. 跳过表头最常用：
    

```bash
NR > 1
```

7. 求平均值的基本模板是：
    

```bash
awk -F, 'NR > 1 {sum += $4; count += 1} END{print sum / count}' file.csv
```

8. 记住这个模板就能解决很多日志和 CSV 处理问题：
    

```bash
awk '条件 {每一行要做的事} END{最后统一做的事}' 文件
```

# 32. 常见误区

## 误区 1：以为 awk 只能查找文字

`awk` 不只是查找文字。

它还可以：

- 打印某一列
    
- 筛选某一列
    
- 做数字比较
    
- 求和
    
- 求平均值
    
- 统计行数
    
- 处理 CSV
    

如果只是找包含某个关键词的行，用 `grep` 更简单。

如果还要处理列，用 `awk` 更合适。

---

## 误区 2：忘记 CSV 要加 `-F,`

错误写法：

```bash
awk '{print $1}' file.csv
```

如果 CSV 是：

```csv
small,10.2,1
```

默认按空格分列时，整行会被当作第 1 列。

所以 `$1` 是：

```text
small,10.2,1
```

正确写法：

```bash
awk -F, '{print $1}' file.csv
```

输出：

```text
small
```

---

## 误区 3：把 `$1` 理解成第 1 行

`$1` 不是第 1 行。

`$1` 是当前行的第 1 列。

第几行要用 `NR`。

例如：

```bash
awk 'NR == 1 {print $0}' file.txt
```

表示打印第 1 行。

```bash
awk '{print $1}' file.txt
```

表示打印每一行的第 1 列。

---

## 误区 4：忘记字符串要加双引号

正确：

```bash
awk -F, '$1 == "small" {print $0}' file.csv
```

不推荐：

```bash
awk -F, '$1 == small {print $0}' file.csv
```

因为 `small` 不加双引号时，可能被 `awk` 当作变量名，而不是字符串。

---

## 误区 5：不知道 `END` 什么时候执行

`END` 不是每一行都执行。

`END` 是文件全部读完之后才执行一次。

所以它适合做：

- 输出最终结果
    
- 打印总和
    
- 打印平均值
    
- 打印统计结果
    

例如：

```bash
awk -F, 'NR > 1 {sum += $4} END{print sum}' file.csv
```

这里 `sum += $4` 是每一行执行。

`END{print sum}` 是最后执行一次。

---

## 误区 6：把 `/Time/` 理解成只匹配某一列

```bash
awk '/Time/{print $0}' log.txt
```

这里 `/Time/` 是匹配整行。

如果只想匹配第 1 列，要写：

```bash
awk '$1 ~ /Time/ {print $0}' log.txt
```

## 问题 5

`$NF` 表示什么？

答案：

```text
当前行的最后一列。
```

例如：

```text
a b c d
```

这一行中：

```text
NF = 4
$NF = $4 = d
```

`NR > 1` 常用来做什么？

```text
跳过表头，从第 2 行开始处理。
```

## 问题 7

下面命令是什么意思？

```bash
awk -F, 'NR > 1 {sum += $4; count += 1} END{print sum / count}' file.csv
```

答案：

```text
跳过表头，把第 4 列所有数值加起来，同时统计行数，最后输出第 4 列的平均值。
```

数学上就是：

$$  
\mathrm{average} = \frac{\mathrm{sum}}{\mathrm{count}}  
$$

## 问题 8

`&&` 和 `||` 分别是什么意思？

答案：

```text
&& 表示并且，两个条件都要满足。
|| 表示或者，只要有一个条件满足即可。
```

例如：

```bash
awk -F, 'NR > 1 && $1 == "small" {print $0}' file.csv
```

意思是：

```text
行号大于 1，并且第 1 列等于 small。
```

如果只想找行，用 `grep`。

如果想找行之后还要处理列、筛选列、计算数值，用 `awk`。
