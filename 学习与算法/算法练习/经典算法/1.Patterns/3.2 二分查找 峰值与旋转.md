# 峰值与旋转数组二分模板

这类题的核心不是“数组整体有序”，而是：

> 能否根据某个判断条件，每次排除一半区间。

只要能定义出稳定的二分方向，就可以用 Binary Search。

---

## 一、什么时候用哪种思路？

> [!summary]- 总判断表
> 
> |题型|数组特征|核心判断|使用方法|
> |---|---|---|---|
> |寻找峰值|不要求整体有序，但能看局部趋势|`nums[mid] > nums[mid + 1]`|根据上升/下降趋势找峰值方向|
> |旋转数组最小值|原本升序，被旋转|`nums[mid] < nums[-1]`|找第一个进入右半段的位置|
> |搜索旋转数组|原本升序，被旋转，要找 target|判断 `target` 和 `nums[mid]` 是否同段|重新定义 `is_blue(i)`，用红蓝染色二分|
> 
> 共同点：
> 
> - 不一定是普通升序数组
>     
> - 但一定可以找到某种“可二分的边界”
>     
> - 关键不是背模板，而是先定义：
>     
>     - 什么是红色区间
>         
>     - 什么是蓝色区间
>         
>     - 我要找第一个蓝色，还是最后一个红色
>         

---

## 二、通用红蓝染色模板

> [!tip]- 红蓝染色法核心模板  
> 适用于：找第一个满足条件的位置。
> 
> ```python
> left = -1
> right = len(nums)
> 
> while left + 1 < right:
>     mid = (left + right) // 2
> 
>     if is_blue(mid):
>         right = mid
>     else:
>         left = mid
> 
> return right
> ```
> 
> 含义：
> 
> - `left`：最后一个红色位置
>     
> - `right`：第一个蓝色位置
>     
> - `is_blue(mid)`：判断 `mid` 是否已经进入答案侧
>     
> 
> 注意：
> 
> - 如果答案一定存在，可以直接返回 `right`
>     
> - 如果答案可能不存在，最后必须检查：
>     
> 
> ```python
> if right == len(nums) or nums[right] != target:
>     return -1
> ```

---

## 三、峰值题模板

> [!tip]- 寻找峰值的判断条件  
> 峰值题看的是局部趋势。
> 
> 核心判断：
> 
> ```python
> nums[mid] > nums[mid + 1]
> ```
> 
> 如果：
> 
> ```python
> nums[mid] > nums[mid + 1]
> ```
> 
> 说明 `mid` 到 `mid + 1` 是下降趋势，峰值在左侧或 `mid` 本身。
> 
> 所以：
> 
> ```python
> right = mid
> ```
> 
> 如果：
> 
> ```python
> nums[mid] < nums[mid + 1]
> ```
> 
> 说明右侧一定存在峰值。
> 
> 所以：
> 
> ```python
> left = mid
> ```

> [!success]- 峰值题代码模板
> 
> ```python
> class Solution:
>     def findPeakElement(self, nums: list[int]) -> int:
>         left = -1
>         right = len(nums) - 1
> 
>         while left + 1 < right:
>             mid = (left + right) // 2
> 
>             if nums[mid] > nums[mid + 1]:
>                 right = mid
>             else:
>                 left = mid
> 
>         return right
> ```
> 
> 关键点：
> 
> - `right = len(nums) - 1`
>     
> - 因为代码里要访问 `nums[mid + 1]`
>     
> - 不能让 `mid + 1` 越界
>     
> - 最后返回的是峰值下标 `right`
>

## 四、旋转数组最小值模板

> [!tip]- 旋转数组找最小值的判断条件  
> 旋转数组可以看成两段升序数组：
> 
> ```text
> [4, 5, 6, 7, 0, 1, 2]
>  左大段        右小段
> ```
> 
> 用最后一个元素 `nums[-1]` 作为参考：
> 
> ```python
> end = nums[-1]
> ```
> 
> 判断规则：
> 
> - `nums[i] > end`：在左大段
>     
> - `nums[i] <= end`：在右小段
>     
> 
> 最小值就是右小段的第一个元素。
> 
> 所以目标是：
> 
> ```text
> 找第一个 nums[i] <= nums[-1] 的位置
> ```
> 
> 在元素互不相同的情况下，也可以写成：
> 
> ```python
> nums[mid] < nums[-1]
> ```
> 
> 但为了兼容没有旋转的情况，模板更推荐使用：
> 
> ```python
> nums[mid] <= nums[-1]
> ```

> [!success]- 旋转数组最小值代码模板
> 
> ```python
> class Solution:
>     def findMin(self, nums: list[int]) -> int:
>         left = -1
>         right = len(nums) - 1
> 
>         while left + 1 < right:
>             mid = (left + right) // 2
> 
>             if nums[mid] <= nums[-1]:
>                 right = mid
>             else:
>                 left = mid
> 
>         return nums[right]
> ```
> 
> 关键点：
> 
> - `nums[-1]` 是分段参照物
>     
> - `right` 表示第一个进入右小段的位置
>     
> - 返回的是 `nums[right]`，不是 `right`
>

## 五、搜索旋转排序数组模板

> [!tip]- 搜索旋转数组的判断条件  
> 搜索旋转数组时，不能直接普通二分，因为数组不是整体有序。
> 
> 仍然用：
> 
> ```python
> end = nums[-1]
> ```
> 
> 把数组分成两段：
> 
> - `nums[i] > end`：左大段
>     
> - `nums[i] <= end`：右小段
>     
> 
> 同时判断：
> 
> - `target > end`：目标在左大段
>     
> - `target <= end`：目标在右小段
>     
> 
> 核心问题：
> 
> > 如何重新定义 `is_blue(i)`，让旋转数组重新变成可二分结构？(blue = 答案侧 ;
is_blue(i) = 判断 i 是否已经到达答案侧,或已经越过答案侧，若为蓝色侧，此时答案只可能在mid的左边)

> [!success]- 搜索旋转数组红蓝染色模板
> 
> ```python
> class Solution:
>     def search(self, nums: list[int], target: int) -> int:
>         end = nums[-1]
> 
>         def is_blue(i: int) -> bool:
>             if nums[i] > end:
>                 return target > end and nums[i] >= target
>             else:
>                 return target > end or nums[i] >= target
>           #def is_blue(i):  
>			#mid_in_left = nums[i] > end  
>			#target_in_left = target > end  
>
>			#if mid_in_left and target_in_left:  
>				#return nums[i] >= target  
>
>			#if mid_in_left and not target_in_left:  
>				#return False  
>
>			#if not mid_in_left and target_in_left:  
>				#return True  
>
>			#return nums[i] >= target
> 
>         left = -1
>         right = len(nums)
> 
>         while left + 1 < right:
>             mid = (left + right) // 2
> 
>             if is_blue(mid):
>                 right = mid
>             else:
>                 left = mid
> 
>         if right == len(nums) or nums[right] != target:
>             return -1
> 
>         return right
> ```
> 
> 关键点：
> 
> - 如果 `target` 和 `nums[i]` 在同一段，就正常比较 `nums[i] >= target`
>     
> - 如果 `nums[i]` 在左段，`target` 在右段，说明 `nums[i]` 还没到 target，属于红色
>     
> - 如果 `nums[i]` 在右段，`target` 在左段，说明 `nums[i]` 已经越过 target，属于蓝色
>     
> - 最后一定要检查 `nums[right] == target`
>     

> [!success]- 左右有序区间写法
> 
> ```python
> class Solution:
>     def search(self, nums: list[int], target: int) -> int:
>         left = 0
>         right = len(nums) - 1
> 
>         while left <= right:
>             mid = (left + right) // 2
> 
>             if nums[mid] == target:
>                 return mid
> 
>             if nums[left] <= nums[mid]:
>                 if nums[left] <= target < nums[mid]:
>                     right = mid - 1
>                 else:
>                     left = mid + 1
>             else:
>                 if nums[mid] < target <= nums[right]:
>                     left = mid + 1
>                 else:
>                     right = mid - 1
> 
>         return -1
> ```
> 
> 这版的思路是：
> 
> - 每次判断左半边是否有序
>     
> - 如果左半边有序，就看 `target` 是否落在左半边
>     
> - 否则右半边有序，就看 `target` 是否落在右半边
>     
> 
> 面试中这版更直观。
> 
> 红蓝染色版更统一，更适合放进自己的模板系统里。

# 162. 寻找峰值

给定数组 `nums`，返回任意一个峰值元素下标。

---

## 核心思路

> [!tip]- 为什么可以二分？  
> 题目假设：
> 
> $$  
> nums[-1] = nums[n] = -\infty  
> $$
> 
> 所以数组两端也可能成为峰值。
> 
> 峰值满足：
> 
> $$  
> nums[i] > nums[i - 1]  
> $$
> 
> 并且：
> 
> $$  
> nums[i] > nums[i + 1]  
> $$
> 
> 这题不需要找全局最大值，只要找任意一个局部峰值。
> 
> 每次比较：
> 
> ```python
> nums[mid] > nums[mid + 1]
> ```
> 
> 如果当前位置往右下降，说明左侧或当前位置一定存在峰值。
> 
> 如果当前位置往右上升，说明右侧一定存在峰值。

---

## 示例推演

> [!example]- `nums = [1, 2, 3, 1]`  
> 初始：
> 
> ```text
> left = -1
> right = 3
> ```
> 
> 第一次：
> 
> ```text
> mid = 1
> nums[1] = 2
> nums[2] = 3
> ```
> 
> 因为：
> 
> ```python
> nums[1] < nums[2]
> ```
> 
> 说明右侧有峰值：
> 
> ```python
> left = mid
> ```
> 
> 第二次：
> 
> ```text
> mid = 2
> nums[2] = 3
> nums[3] = 1
> ```
> 
> 因为：
> 
> ```python
> nums[2] > nums[3]
> ```
> 
> 说明峰值在左侧或当前位置：
> 
> ```python
> right = mid
> ```
> 
> 最后：
> 
> ```python
> return right
> ```
> 
> 返回：
> 
> ```text
> 2
> ```

---

## 代码

> [!success]- Python 实现
> 
> ```python
> class Solution:
>     def findPeakElement(self, nums: list[int]) -> int:
>         left = -1
>         right = len(nums) - 1
> 
>         while left + 1 < right:
>             mid = (left + right) // 2
> 
>             if nums[mid] > nums[mid + 1]:
>                 right = mid
>             else:
>                 left = mid
> 
>         return right
> ```

---

## 易错点

> [!warning]- 常见错误
> 
> - 误以为必须找到全局最大值
>     
> - 用 `mid - 1` 判断，容易左边界越界
>     
> - 把 `right` 初始化为 `len(nums)`，导致 `nums[mid + 1]` 越界
>     
> - `nums[mid] > nums[mid + 1]` 时更新方向写反
>     
> - 忘记题目保证相邻元素不相等，所以不会出现相等无法判断方向的问题
>     

---

## 一句话总结

> [!summary]- 结论  
> 寻找峰值的本质是根据局部上升/下降趋势，二分锁定一定存在峰值的一侧。

---

# 153. 寻找旋转排序数组中的最小值

给定旋转后的升序数组 `nums`，返回数组中的最小值。

---

## 核心思路

> [!tip]- 为什么可以用 `nums[-1]` 分段？  
> 旋转数组可以看成两段升序数组：
> 
> ```python
> nums = [4, 5, 6, 7, 0, 1, 2]
> ```
> 
> 用最后一个元素作为参照：
> 
> ```python
> end = nums[-1]
> ```
> 
> 这里：
> 
> ```python
> end = 2
> ```
> 
> 左大段：
> 
> ```text
> 4, 5, 6, 7
> ```
> 
> 都满足：
> 
> ```python
> nums[i] > end
> ```
> 
> 右小段：
> 
> ```text
> 0, 1, 2
> ```
> 
> 都满足：
> 
> ```python
> nums[i] <= end
> ```
> 
> 最小值就是右小段的第一个元素。
> 
> 所以目标变成：
> 
> ```text
> 找第一个 nums[i] <= nums[-1] 的位置
> ```

---

## 示例推演

> [!example]- `nums = [4, 5, 6, 7, 0, 1, 2]`  
> 参考值：
> 
> ```python
> end = nums[-1] = 2
> ```
> 
> 初始：
> 
> ```text
> left = -1
> right = 6
> ```
> 
> 第一次：
> 
> ```text
> mid = 2
> nums[2] = 6
> ```
> 
> 因为：
> 
> ```python
> nums[2] > end
> ```
> 
> 说明 `mid` 还在左大段，最小值在右边：
> 
> ```python
> left = mid
> ```
> 
> 第二次：
> 
> ```text
> mid = 4
> nums[4] = 0
> ```
> 
> 因为：
> 
> ```python
> nums[4] <= end
> ```
> 
> 说明 `mid` 已经进入右小段，可能就是最小值：
> 
> ```python
> right = mid
> ```
> 
> 最后返回：
> 
> ```python
> nums[right]
> ```

---

## 代码

> [!success]- Python 实现
> 
> ```python
> class Solution:
>     def findMin(self, nums: list[int]) -> int:
>         left = -1
>         right = len(nums) - 1
> 
>         while left + 1 < right:
>             mid = (left + right) // 2
> 
>             if nums[mid] <= nums[-1]:
>                 right = mid
>             else:
>                 left = mid
> 
>         return nums[right]
> ```

---

## 另一种常见写法

> [!tip]- 比较 `nums[mid]` 和 `nums[right]`  
> 也可以写成左闭右闭区间：
> 
> ```python
> class Solution:
>     def findMin(self, nums: list[int]) -> int:
>         left = 0
>         right = len(nums) - 1
> 
>         while left < right:
>             mid = (left + right) // 2
> 
>             if nums[mid] > nums[right]:
>                 left = mid + 1
>             else:
>                 right = mid
> 
>         return nums[left]
> ```
> 
> 解释：
> 
> - `nums[mid] > nums[right]`：`mid` 在左大段，最小值在右边
>     
> - `nums[mid] <= nums[right]`：`mid` 在右小段，最小值在左边或就是 `mid`
>     
> 
> 这版也很常见，适合面试直接写。

---

## 易错点

> [!warning]- 常见错误
> 
> - 返回下标而不是最小值
>     
> - 把旋转数组当普通升序数组处理
>     
> - 忘记最小值是右小段的第一个元素
>     
> - 判断条件和边界更新方向不匹配
>     
> - 没有考虑数组可能旋转 `n` 次，即数组保持原样
>     

---

## 一句话总结

> [!summary]- 结论  
> 旋转数组找最小值，本质是用 `nums[-1]` 分段，二分找第一个进入右小段的位置。

# 33. 搜索旋转排序数组

给定旋转后的升序数组 `nums` 和 `target`，存在则返回下标，否则返回 `-1`。

---

## 核心思路

> [!tip]- 为什么不能直接普通二分？  
> 普通二分要求数组整体升序。
> 
> 但旋转数组长这样：
> 
> ```python
> nums = [4, 5, 6, 7, 0, 1, 2]
> ```
> 
> 它不是整体升序，而是两段升序：
> 
> ```text
> [4, 5, 6, 7] [0, 1, 2]
> ```
> 
> 所以要先判断：
> 
> - `target` 在左大段还是右小段
>     
> - `nums[mid]` 在左大段还是右小段
>     
> 
> 如果二者同段，可以普通比较。
> 
> 如果二者异段，需要人为定义红蓝关系。

---

## `is_blue(i)` 逻辑

> [!tip]- 红蓝判断拆解  
> 设：
> 
> ```python
> end = nums[-1]
> ```
> 
> 判断当前位置在哪一段：
> 
> ```python
> nums[i] > end
> ```
> 
> 说明 `nums[i]` 在左大段。
> 
> ```python
> nums[i] <= end
> ```
> 
> 说明 `nums[i]` 在右小段。
> 
> 判断目标在哪一段：
> 
> ```python
> target > end
> ```
> 
> 说明 `target` 在左大段。
> 
> ```python
> target <= end
> ```
> 
> 说明 `target` 在右小段。
> 
> `is_blue(i)` 的目标是：
> 
> ```text
> 判断 i 是否已经到达 target 或越过 target
> ```
> 
> 也就是找第一个 `>= target` 的位置，只不过旋转数组需要处理跨段情况。

---

## 分情况理解

> [!example]- 情况 1：`nums[i]` 在左大段
> 
> ```python
> if nums[i] > end:
> ```
> 
> 如果 `target` 也在左大段：
> 
> ```python
> target > end
> ```
> 
> 那就可以普通比较：
> 
> ```python
> nums[i] >= target
> ```
> 
> 所以：
> 
> ```python
> return target > end and nums[i] >= target
> ```
> 
> 如果 `target` 在右小段，那么左大段所有元素都在目标左边，不应该染蓝。
> 
> 所以返回 `False`。

> [!example]- 情况 2：`nums[i]` 在右小段
> 
> ```python
> else:
> ```
> 
> 如果 `target` 在左大段：
> 
> ```python
> target > end
> ```
> 
> 那么右小段已经整体越过目标位置，应该染蓝。
> 
> 所以：
> 
> ```python
> return True
> ```
> 
> 如果 `target` 也在右小段，就正常比较：
> 
> ```python
> nums[i] >= target
> ```
> 
> 合并写法：
> 
> ```python
> return target > end or nums[i] >= target
> ```

---

## 示例推演

> [!example]- `nums = [4, 5, 6, 7, 0, 1, 2]`，`target = 0`
> 
> ```python
> end = nums[-1] = 2
> ```
> 
> 因为：
> 
> ```python
> target <= end
> ```
> 
> 所以目标在右小段。
> 
> 如果：
> 
> ```python
> nums[mid] = 7
> ```
> 
> 那么：
> 
> ```python
> nums[mid] > end
> ```
> 
> 说明 `mid` 在左大段。
> 
> 左大段在目标左边，所以不是蓝色：
> 
> ```python
> left = mid
> ```
> 
> 如果：
> 
> ```python
> nums[mid] = 1
> ```
> 
> 那么：
> 
> ```python
> nums[mid] <= end
> ```
> 
> 说明 `mid` 和 `target` 都在右小段，可以正常比较。
> 
> 因为：
> 
> ```python
> 1 >= 0
> ```
> 
> 所以是蓝色：
> 
> ```python
> right = mid
> ```

---

## 代码

> [!success]- Python 实现
> 
> ```python
> class Solution:
>     def search(self, nums: list[int], target: int) -> int:
>         end = nums[-1]
> 
>         def is_blue(i: int) -> bool:
>             if nums[i] > end:
>                 return target > end and nums[i] >= target
>             else:
>                 return target > end or nums[i] >= target
> 
>         left = -1
>         right = len(nums)
> 
>         while left + 1 < right:
>             mid = (left + right) // 2
> 
>             if is_blue(mid):
>                 right = mid
>             else:
>                 left = mid
> 
>         if right == len(nums) or nums[right] != target:
>             return -1
> 
>         return right
> ```

---

## 另一种常见写法：判断哪半边有序(最常用)

> [!success]- 左右有序区间写法
> 
> ```python
> class Solution:
>     def search(self, nums: list[int], target: int) -> int:
>         left = 0
>         right = len(nums) - 1
> 
>         while left <= right:
>             mid = (left + right) // 2
> 
>             if nums[mid] == target:
>                 return mid
> 
>             if nums[left] <= nums[mid]:
>                 if nums[left] <= target < nums[mid]:
>                     right = mid - 1
>                 else:
>                     left = mid + 1
>             else:
>                 if nums[mid] < target <= nums[right]:
>                     left = mid + 1
>                 else:
>                     right = mid - 1
> 
>         return -1
> ```
> 
> 这版的思路是：
> 
> - 每次判断左半边是否有序
>     
> - 如果左半边有序，就看 `target` 是否落在左半边
>     
> - 否则右半边有序，就看 `target` 是否落在右半边
>     
> 
> 面试中这版更直观。
> 
> 红蓝染色版更统一，更适合放进自己的模板系统里。

---

## 易错点

> [!warning]- 常见错误
> 
> - 只判断 `target` 在哪一段，不判断 `nums[mid]` 在哪一段
>     
> - 直接使用普通二分条件 `nums[mid] < target`
>     
> - 跨段时比较大小，导致方向错误
>     
> - 二分结束后直接返回 `right`
>     
> - 忘记判断 `right == len(nums)`
>     
> - 忘记检查 `nums[right] == target`
>

## 一句话总结

> [!summary]- 结论  
> 搜索旋转数组的本质是重新定义 `is_blue(i)`，让不完全有序的数组重新拥有可二分边界。

## 核心区别

> [!summary]- 三类题怎么区分？
> 
> |题目|关注点|判断条件|返回内容|
> |---|---|---|---|
> |162. 寻找峰值|局部趋势|`nums[mid] > nums[mid + 1]`|峰值下标|
> |153. 旋转数组最小值|分段边界|`nums[mid] <= nums[-1]`|最小值|
> |33. 搜索旋转数组|target 所在位置|`is_blue(i)`|target 下标或 `-1`|
> 
> 记忆方式：
> 
> - 峰值：看坡度
>     
> - 最小值：看是否进入右小段
>     
> - 搜索 target：看 target 和 mid 是否同段
>

## 面试时的思考顺序

> [!tip]- 五步思考法  
> 看到这种题，先问自己：
> 
> 1. 数组是真的整体有序吗？
>     
> 2. 如果不是整体有序，它有没有局部结构？
>     
> 3. 我能不能定义红色和蓝色？
>     
> 4. `is_blue(mid)` 应该怎么写？
>     
> 5. 最后返回的是下标、值，还是需要额外检查？
>

## 最终口诀

> [!summary]- 记忆口诀  
> 峰值看趋势：
> 
> ```python
> nums[mid] > nums[mid + 1]
> ```
> 
> 旋转找最小看尾部：
> 
> ```python
> nums[mid] <= nums[-1]
> ```
>

> ```python
