# 2861. 最大合金数

## 1. 题目要解决什么问题？

给定 `n` 种金属、`k` 台机器、预算 `budget`、每台机器制造一份合金所需的金属配方 `composition`、已有库存 `stock` 和每种金属单价 `cost`。  
要求选择一台机器来制造合金，并在预算内制造尽可能多的合金。  
输出公司最多可以制造的合金数量。

小例子：

```python
n = 3
k = 2
budget = 15
composition = [[1, 1, 1], [1, 1, 10]]
stock = [0, 0, 0]
cost = [1, 2, 3]
```

目标是判断：用某一台机器，最多能造多少份合金。

## 2. 核心思路

这题属于 **二分答案 Binary Search on Answer**。

我们不是直接枚举答案，而是问一个问题：

```text
如果要制造 num 份合金，预算够不够？
```

这个问题可以写成 `check(num)`。

如果能制造 `num` 份，那么一定也能制造更少份。  
如果不能制造 `num` 份，那么一定不能制造更多份。

所以答案具有单调性：

```text
能造：True True True
不能造：False False False
```

因此可以二分最大可行答案。

这题还要注意：有 `k` 台机器，每台机器的配方不同。  
所以需要对每台机器分别二分，最后取最大值。

## 3. 关键公式 / 判断条件

对于某台机器的配方 `comp`，制造 `num` 份合金时，第 `i` 种金属一共需要：

$$  
comp[i] \times num  
$$

已有库存是：

$$  
stock[i]  
$$

如果库存不够，需要额外购买：

$$  
\max(0, comp[i] \times num - stock[i])  
$$

购买这部分金属的花费是：

$$  
\max(0, comp[i] \times num - stock[i]) \times cost[i]  
$$

总花费：

$$  
money = \sum_i \max(0, comp[i] \times num - stock[i]) \times cost[i]  
$$

判断条件：

$$  
money \le budget  
$$

如果成立，说明可以制造 `num` 份合金。

## 4. 代码模板

```python
class Solution:
    def maxNumberOfAlloys(
        self,
        n: int,
        k: int,
        budget: int,
        composition: list[list[int]],
        stock: list[int],
        cost: list[int]
    ) -> int:
        ans = 0

        # 一个安全上界：库存和预算都可能贡献产量
        upper = min(stock) + budget + 1

        for comp in composition:

            def check(num: int) -> bool:
                money = 0

                for have, need, price in zip(stock, comp, cost):
                    required = need * num

                    if required > have:
                        money += (required - have) * price

                        # 提前剪枝，避免无意义继续计算
                        if money > budget:
                            return False

                return True

            left = ans
            right = upper

            # 开区间写法：(left, right)
            # left 表示当前已知可行
            # right 表示当前已知不可行
            while left + 1 < right:
                mid = (left + right) // 2

                if check(mid):
                    left = mid
                else:
                    right = mid

            ans = left

        return ans
```

## 5. 复杂度分析

时间复杂度：

$$  
O(k \cdot n \cdot \log U)  
$$

空间复杂度：

$$  
O(1)  
$$

其中 `U` 是二分答案的上界。每台机器都要二分，每次 `check` 需要遍历 `n` 种金属。

## 6. 核心结论

- 这题的关键是先明确结果：最多能制造多少份合金
    
- 判断函数是：`check(num)` 表示能不能制造 `num` 份
    
- `check(num)` 具有单调性，所以可以二分答案
    
- 每台机器配方不同，要分别计算最大值
    
- `zip(stock, comp, cost)` 可以避免写复杂的 `composition[i][j]`
    
- `money > budget` 时可以提前返回 `False`，这是提前剪枝
    

## 7. 常见误区

- 直接枚举合金数量，会超时
    
- 忘记每台机器的配方不同，只算了一台机器
    
- `check(num)` 里没有减去已有库存 `stock`
    
- 忘记提前剪枝，导致计算不够高效
    
- 不明确 `left` 和 `right` 分别代表可行还是不可行

# 二分答案总结

## 1. 二分答案解决什么问题？

当题目不是让你在数组里找元素，而是让你求一个最大值或最小值时，可以考虑二分答案。

典型形式：

```text
求最大可行值
求最小可行值
```

比如：

- 最多能制造多少个合金
    
- 最慢速度是多少
    
- 最少时间是多少
    
- 最大甜蜜度是多少
    

## 2. 使用条件

二分答案需要满足两个条件：

1. 答案空间有范围
    
2. 判定函数具有单调性
    

例如本题：

```text
能制造 2 个合金，则通常也能制造 1 个
不能制造 10 个合金，则通常也不能制造 11 个
```

所以可以把答案空间染色：

```text
可行 可行 可行 不可行 不可行
```

目标是找到最后一个可行的位置。

## 3. 以结果为导向设计二分

写二分前，先明确：

```text
input: num
output: True / False
含义：能不能制造 num 份合金
```

也就是先写清楚 `check(num)`。

本题的 `check(num)`：

```python
def check(num: int) -> bool:
    money = 0

    for have, need, price in zip(stock, comp, cost):
        required = need * num

        if required > have:
            money += (required - have) * price

            if money > budget:
                return False

    return True
```

## 4. 最大化答案模板

适合求：

```text
最大可行值
```

模板：

```python
left = 0
right = upper

while left + 1 < right:
    mid = (left + right) // 2

    if check(mid):
        left = mid
    else:
        right = mid

return left
```

含义：

- `left`：当前已知可行
    
- `right`：当前已知不可行
    
- 最后返回最后一个可行值 `left`
    

## 5. 最小化答案模板

适合求：

```text
最小可行值
```

模板：

```python
left = 0
right = upper

while left + 1 < right:
    mid = (left + right) // 2

    if check(mid):
        right = mid
    else:
        left = mid

return right
```

含义：

- `left`：当前已知不可行
    
- `right`：当前已知可行
    
- 最后返回第一个可行值 `right`
    

## 6. 提前剪枝

如果 `check()` 过程中已经可以确定结果，就不要继续算。

本题中：

```python
if money > budget:
    return False
```

因为预算已经超了，后面继续加只会更大。

提前剪枝的作用：

- 减少无效计算
    
- 避免大数据下超时
    
- 让 `check()` 更贴近真实判定逻辑
    

## 7. zip 的作用

原本可能写成：

```python
for i in range(n):
    have = stock[i]
    need = comp[i]
    price = cost[i]
```

可以改成：

```python
for have, need, price in zip(stock, comp, cost):
    ...
```

这样更清晰，也不容易写错下标。

## 8. 核心结论

- 二分答案要先写清楚 `check(x)` 的含义
    
- `check(x)` 必须返回 `True` 或 `False`
    
- 能二分的关键是单调性，不是数组本身有序
    
- 求最大可行值，通常返回 `left`
    
- 求最小可行值，通常返回 `right`
    
- `check()` 里能提前判断就提前返回
    
- 多数组同步遍历时，优先考虑 `zip`
    

## 9. 常见误区

- 没有先定义清楚 `check(x)`，导致二分方向混乱
    
- 把“二分数组下标”和“二分答案”混在一起
    
- 求最大值时返回了 `right`
    
- 求最小值时返回了 `left`
    
- 忘记判断函数必须有单调性
    
- 上界 `upper` 设得太小，导致答案被截断

```text
3. 判断 check(x) 是否单调
4. 选择最大化模板或最小化模板
5. 返回边界
```

```python
return right
```

二分答案不是在数组里找数，而是在答案范围里不断问：这个答案可不可行。
