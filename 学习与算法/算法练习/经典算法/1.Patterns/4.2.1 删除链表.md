删除节点，就是让这个节点的上一个节点指向下下个节点，所以实际上这个节点还是存在的，若是你的语言自带垃圾回收，它会将其直接回收，避免内存泄漏

![[Pasted image 20260707183457.png]]

但是若是没有上一个节点要如何删除呢？

![[Pasted image 20260707183807.png]]
因为题目保证不是最后一个节点，所以直接把下一个节点的值copy过来链接即可

```
# Definition for singly-linked list.

# class ListNode:

#     def __init__(self, x):

#         self.val = x

#         self.next = None

  

class Solution:

    def deleteNode(self, node):

        """

        :type node: ListNode

        :rtype: void Do not return anything, modify node in-place instead.

        """

        node.val=node.next.val

        node.next=node.next.next
```

如果需要删除掉头节点，最好再去创建一个dummy_node

当需要删除第n个节点时，可以创建一个左指针和一个右指针，让他们的距离始终为n，右指针到达末尾时，左指针恰好就是倒数第n+1个，然后删除

![[Pasted image 20260707185921.png]]

```
# Definition for singly-linked list.

# class ListNode:

#     def __init__(self, val=0, next=None):

#         self.val = val

#         self.next = next

class Solution:

    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:

        dummy=ListNode(next=head)

        right=dummy

        for _ in range(n):

            right=right.next

  

        left=dummy

        while right.next:

            left=left.next

            right=right.next

        left.next=left.next.next

        return dummy.next
```

 针对已排序的链表去删除重复元素，只要比较cur以及cur.next

![[Pasted image 20260707190719.png]]

```
# Definition for singly-linked list.

# class ListNode:

#     def __init__(self, val=0, next=None):

#         self.val = val

#         self.next = next

class Solution:

    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:

        if head is None:

            return head

        cur=head

        while cur.next:

            if cur.next.val==cur.val:

                cur.next=cur.next.next

            else:

                cur=cur.next

  

        return head
```

如果头节点也可能被删除，那就再去加一个dummy_node

![[Pasted image 20260707190903.png]]
```
# Definition for singly-linked list.

# class ListNode:

#     def __init__(self, val=0, next=None):

#         self.val = val

#         self.next = next

class Solution:

    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:

        dummy=ListNode(next=head)

        cur=dummy

        while cur.next and cur.next.next:

            val=cur.next.val

            if cur.next.next.val==val:

                while cur.next and cur.next.val==val:

                    cur.next=cur.next.next

            else:

                cur=cur.next

  

        return dummy.next
```
