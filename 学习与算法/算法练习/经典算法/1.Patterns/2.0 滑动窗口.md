# 题目

用滑动窗口 `Sliding Window` 解决连续子数组的最短长度问题和合法子数组数量统计问题。

---

## 思路

滑动窗口适合处理==连续区间==问题。  
如果数组元素为正数，右端扩张会让和或乘积变大，左端收缩会让和或乘积变小。  
这种单调性让我们可以用 `left` 和 `right` 维护一个动态窗口，而不用枚举所有子数组。

---

> [!tip]- 核心思路
> 
> ## 1. 209. 长度最小的子数组
> 
> 目标：找到和大于等于 `target` 的最短连续子数组。
> 
> 窗口维护：
> 
> ```text
> nums[left:right+1]
> ```
> 
> 窗口和：
> 
> $$  
> window_sum  
> $$
> 
> 窗口合法条件：
> 
> $$  
> window_sum \ge target  
> $$
> 
> 为什么用滑动窗口？
> 
> 因为 `nums` 中都是正整数：
> 
> - `right` 右移，窗口和只会变大
>     
> - `left` 右移，窗口和只会变小
>     
> 
> 所以流程是：
> 
> ```text
> 右指针扩张窗口
> 窗口合法后，左指针尽量收缩
> 每次合法时更新最短长度
> ```
> 
> 窗口长度：
> 
> $$  
> right - left + 1  
> $$
> 
> ---
> 
> ## 2. 713. 乘积小于 K 的子数组
> 
> 目标：统计乘积严格小于 `k` 的连续子数组数量。
> 
> 窗口维护：
> 
> $$  
> product < k  
> $$
> 
> 如果加入 `nums[right]` 后：
> 
> $$  
> product \ge k  
> $$
> 
> 就移动 `left` 收缩窗口，直到重新合法。
> 
> 关键不是求最长或最短，而是统计所有以 `right` 结尾的合法子数组。
> 
> 当窗口 `[left, right]` 合法时，以 `right` 结尾的合法子数组有：
> 
> ```text
> nums[right:right+1]
> nums[right-1:right+1]
> ...
> nums[left:right+1]
> ```
> 
> 数量是：
> 
> $$  
> right - left + 1  
> $$
> 
> 所以每轮：
> 
> ```python
> ans += right - left + 1
> ```
> 
> 特殊情况：
> 
> 如果 `k <= 1`，由于 `nums[i] >= 1`，不存在乘积小于 `k` 的正整数子数组，直接返回 `0`。

---

> [!example]- 示例推演
> 
> ## 209. 长度最小的子数组
> 
> ```python
> target = 7
> nums = [2, 3, 1, 2, 4, 3]
> ```
> 
> ```text
> right = 0，加 2，sum = 2，不合法
> right = 1，加 3，sum = 5，不合法
> right = 2，加 1，sum = 6，不合法
> right = 3，加 2，sum = 8，合法，长度 4
> 收缩 left，移出 2，sum = 6，不合法
> right = 4，加 4，sum = 10，合法，更新长度
> 继续收缩
> right = 5，加 3，最终找到 [4, 3]
> ```
> 
> 最短长度：
> 
> ```python
> 2
> ```
> 
> ---
> 
> ## 713. 乘积小于 K 的子数组
> 
> ```python
> nums = [10, 5, 2, 6]
> k = 100
> ```
> 
> ```text
> right = 0，窗口 [10]，新增 1 个
> right = 1，窗口 [10,5]，新增 2 个
> right = 2，乘积 100，不合法，移出 10
> 窗口 [5,2]，新增 2 个
> right = 3，窗口 [5,2,6]，新增 3 个
> ```
> 
> 总数：
> 
> ```python
> 1 + 2 + 2 + 3 = 8
> ```

---

> [!success]- Python 实现
> 
> ## 209. 长度最小的子数组
> 
> ```python
> class Solution:
>     def minSubArrayLen(self, target: int, nums: list[int]) -> int:
>         n = len(nums)
>         left = 0
>         window_sum = 0
>         ans = n + 1
> 
>         for right, x in enumerate(nums):
>             window_sum += x
> 
>             while window_sum >= target:
>                 ans = min(ans, right - left + 1)
>                 window_sum -= nums[left]
>                 left += 1
> 
>         return ans if ans <= n else 0
> ```
> 
> 代码结构：
> 
> - `right` 负责扩张窗口
>     
> - `window_sum` 维护当前窗口和
>     
> - 当 `window_sum >= target` 时，窗口合法
>     
> - 合法后用 `while` 持续收缩，寻找更短答案
>     
> - `ans = n + 1` 表示暂时没有找到合法窗口
>     
> 
> ---
> 
> ## 713. 乘积小于 K 的子数组
> 
> ```python
> class Solution:
>     def numSubarrayProductLessThanK(self, nums: list[int], k: int) -> int:
>         if k <= 1:
>             return 0
> 
>         left = 0
>         product = 1
>         ans = 0
> 
>         for right, x in enumerate(nums):
>             product *= x
> 
>             while product >= k:
>                 product //= nums[left]
>                 left += 1
> 
>             ans += right - left + 1
> 
>         return ans
> ```
> 
> 代码结构：
> 
> - `product` 维护当前窗口乘积
>     
> - `product >= k` 时窗口不合法，需要收缩左边界
>     
> - 窗口合法后，统计所有以 `right` 结尾的合法子数组
>     
> - `ans += right - left + 1` 是本题核心
>     

---

> [!warning]- 易错点
> 
> ## 1. 把连续子数组看成任意选元素
> 
> 滑动窗口只能处理连续区间。
> 
> 题目关键词通常是：
> 
> ```text
> subarray
> substring
> continuous
> ```
> 
> 如果不是连续区间，不能直接套滑动窗口。
> 
> ---
> 
> ## 2. 最短窗口题用 `if` 而不是 `while`
> 
> 209 要找最短长度。
> 
> 窗口一旦合法，必须不断收缩：
> 
> ```python
> while window_sum >= target:
> ```
> 
> 如果只用 `if`，只能收缩一次，可能错过更短答案。
> 
> ---
> 
> ## 3. 移动 `left` 前忘记移出元素
> 
> 错误：
> 
> ```python
> left += 1
> window_sum -= nums[left]
> ```
> 
> 正确：
> 
> ```python
> window_sum -= nums[left]
> left += 1
> ```
> 
> 因为要先移出当前左端元素，再移动左指针。
> 
> ---
> 
> ## 4. 713 忘记处理 `k <= 1`
> 
> 因为 `nums[i] >= 1`，所以当：
> 
> $$  
> k \le 1  
> $$
> 
> 不可能存在乘积小于 `k` 的正整数子数组。
> 
> 必须提前返回：
> 
> ```python
> if k <= 1:
>     return 0
> ```
> 
> ---
> 
> ## 5. 不理解 `ans += right - left + 1`
> 
> 当窗口 `[left, right]` 合法时，所有以 `right` 结尾、起点在 `[left, right]` 内的子数组都合法。
> 
> 数量正好是：
> 
> $$  
> right - left + 1  
> $$
> 
> 所以不是：
> 
> ```python
> ans += 1
> ```
> 
> 而是：
> 
> ```python
> ans += right - left + 1
> ```
> 
> ---
> 
> ## 6. 混淆最长、最短、统计数量
> 
> 最长窗口：
> 
> ```python
> while window_invalid:
>     shrink()
> ans = max(ans, length)
> ```
> 
> 最短窗口：
> 
> ```python
> while window_valid:
>     ans = min(ans, length)
>     shrink()
> ```
> 
> 统计数量：
> 
> ```python
> while window_invalid:
>     shrink()
> ans += right - left + 1
> ```

---

> [!summary]- 复杂度
> 
> ## 209. 长度最小的子数组
> 
> 时间复杂度：
> 
> $$  
> O(n)  
> $$
> 
> 空间复杂度：
> 
> $$  
> O(1)  
> $$
> 
> 为什么：
> 
> 每个元素最多被 `right` 加入窗口一次，被 `left` 移出窗口一次。
> 
> ---
> 
> ## 713. 乘积小于 K 的子数组
> 
> 时间复杂度：
> 
> $$  
> O(n)  
> $$
> 
> 空间复杂度：
> 
> $$  
> O(1)  
> $$
> 
> 为什么：
> 
> `right` 从左到右走一遍，`left` 也只会向右移动，不会回退。
> 
> 所以总移动次数是线性的。

---

## 一句话总结

滑动窗口本质就是维护一个连续区间，并通过左右指针的单调移动，把暴力枚举所有子数组降为 $O(n)$。

## 模板归纳

滑动窗口 Sliding Window 适合：

- 连续子数组 `subarray`
    
- 连续子串 `substring`
    
- 最长 / 最短区间
    
- 满足条件的区间数量
    
- 固定长度窗口
    
- 窗口状态可以被增量维护
    

通用模板：

```python
left = 0

for right in range(len(nums)):
    # 1. 扩张窗口
    add(nums[right])

    # 2. 如果窗口不合法，收缩左边界
    while window_invalid:
        remove(nums[left])
        left += 1

    # 3. 更新答案
    update_result()
```

最短窗口模板：

```python
left = 0

for right in range(n):
    add(nums[right])

    while window_valid:
        ans = min(ans, right - left + 1)
        remove(nums[left])
        left += 1
```

统计数量模板：

```python
left = 0

for right in range(n):
    add(nums[right])

    while window_invalid:
        remove(nums[left])
        left += 1

    ans += right - left + 1
```

固定长度窗口模板：

```python
window_sum = 0

for right in range(len(nums)):
    window_sum += nums[right]

    if right >= k:
        window_sum -= nums[right - k]

    if right >= k - 1:
        update_answer()
```

需要 `Hash Map` 的情况：

- 维护字符出现次数：`Counter`
    
- 维护字符最后出现位置：`dict`
    
- 维护窗口内是否存在某个元素：`set`
    

条件反射：

```text
看到连续子数组 / 连续子串 + 最长最短 / 满足条件数量
=> 优先想 Sliding Window
```
