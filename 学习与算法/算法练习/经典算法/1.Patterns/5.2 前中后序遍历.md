# 98. 验证二叉搜索树

## 题目

判断一棵二叉树是否为有效 BST：每个节点的值严格大于其左子树所有值、严格小于其右子树所有值。

## 思路

易错直觉是"只比较父子三个节点",但 BST 要求的是**整棵左/右子树**都满足范围约束,所以必须把"允许的取值区间"沿递归往下传,或利用"BST 中序遍历严格递增"这一等价性质。对应前序 / 中序 / 后序三种切入点。

> [!tip]- 核心思路 三种做法本质都是 DFS,区别在**何时判断**:
> 
> - **前序(先判断,再递归)**:每个节点带一个开区间 $(left, right)$,判断 `left < x < right`,再把区间收窄传给左右子树。左子树上界变 $x$,右子树下界变 $x$。 $$\text{左}\to(left,\ x)\qquad \text{右}\to(x,\ right)$$
> - **中序(大于上一个节点)**:BST 中序遍历结果严格递增 $\Rightarrow$ 只需维护上一个访问值 `pre`,当前 `x <= pre` 即非法。
> - **后序(先递归,再判断)**:自底向上返回子树的 $(\min,\max)$,当前节点须 $x > \text{左子树}\max$ 且 $x < \text{右子树}\min$。 为什么用 DFS:BST 的合法性由"子树 + 区间约束"递归定义,原问题与子问题同形,信任子问题返回值即可。

> [!example]- 示例推演(前序,root = [5,2,6,1,4,null,null,null,null,3])
> 
> ```
> 5 : (-∞,∞)      ✓
> ├─2 : (-∞,5)    ✓
> │ ├─1 : (-∞,2)  ✓
> │ └─4 : (2,5)   ✓
> │   └─3 : (2,4) ✓   ← 3 虽 <4 但仍需 >2,区间往下传才抓得住
> └─6 : (5,∞)     ✓
> 全部合法 → true
> ```
> 
> 关键:节点 3 只跟父亲比会漏判,靠区间 $(2,4)$ 才正确约束。

> [!success]- 做法一:前序(区间下传,最直观,推荐)
> 
> ```python
> class Solution:
>     def isValidBST(self, root, left=-inf, right=inf) -> bool:
>         if root is None:
>             return True
>         x = root.val
>         return left < x < right \
>             and self.isValidBST(root.left, left, x) \
>             and self.isValidBST(root.right, x, right)
> ```
> 
> ```cpp
> class Solution {
> public:
>     bool isValidBST(TreeNode* root, long left = LONG_MIN, long right = LONG_MAX) {
>         if (root == nullptr) return true;
>         long x = root->val;
>         return left < x && x < right
>             && isValidBST(root->left, left, x)
>             && isValidBST(root->right, x, right);
>     }
> };
> ```
> 
> - 主流程:空节点合法;当前值落在开区间内,再递归收窄区间校验左右。
> - 关键:区间是**开区间**(严格大小于),左子树换上界、右子树换下界。

> [!success]- 做法二:中序(维护 pre,利用递增性)
> 
> ```python
> class Solution:
>     pre = -inf
>     def isValidBST(self, root) -> bool:
>         if root is None:
>             return True
>         if not self.isValidBST(root.left):   # 先递归左
>             return False
>         if root.val <= self.pre:             # 中:与前驱比
>             return False
>         self.pre = root.val
>         return self.isValidBST(root.right)   # 再递归右
> ```
> 
> - 主流程:严格按"左→中→右"访问,当前值必须 > 上一个中序值 `pre`。
> - 关键:`pre` 初始 $-\infty$;顺序不能乱,否则递增判断失效。

> [!success]- 做法三:后序(返回子树 min/max,自底向上)
> 
> ```python
> class Solution:
>     def isValidBST(self, root) -> bool:
>         def f(node):
>             if node is None:
>                 return inf, -inf          # 空子树:min=+∞,max=-∞
>             l_min, l_max = f(node.left)
>             r_min, r_max = f(node.right)
>             x = node.val
>             if x <= l_max or x >= r_min:   # 非法 → 传毒
>                 return -inf, inf
>             return min(l_min, x), max(r_max, x)
>         return f(root)[1] != inf
> ```
> 
> - 主流程:返回子树 $(\min,\max)$;当前值需大于左 max、小于右 min。
> - 关键:空子树返回 $(+\infty,-\infty)$ 是刻意"反着设",让父节点的比较恒成立;非法时返回 $(-\infty,+\infty)$ 向上污染,最终看根的 max 是否被污染成 $+\infty$。

> [!warning]- 易错点
> 
> - **只比父子三节点**:必区间下传或用中序,否则像 `[5,4,6,null,null,3,7]` 会误判为合法。
> - **等号方向**:BST 要求**严格**大小,用 `<`/`>` 不用 `<=`/`>=`;做法一别写成闭区间。
> - **中序 pre 初值**:必须 $-\infty$;且左右递归顺序不可颠倒。
> - **整数边界**:节点值可能取 `INT_MIN/INT_MAX`,C++ 用 `int` 初值会溢出误判,改用 `long`(如上)。
> - **后序空子树返回值**:反向哨兵 $(+\infty,-\infty)$ 别写反,否则叶子判断出错。

> [!summary]- 复杂度
> 
> - 时间:$O(n)$ —— 每个节点访问一次。
> - 空间:$O(h)$ —— 递归栈等于树高;最坏(链状)$O(n)$,平衡时 $O(\log n)$。

## 一句话总结

BST 合法性靠"区间约束"或"中序递增"跨层判断,单看父子三节点必错。

## 模板归纳

> [!tip]- 什么时候想到"BST + 区间下传 / 中序递增" **触发信号**:题目出现"二叉搜索树"、要求校验/搜索/第K小、或需要"节点值受祖先约束"。 **判断依据**:
> 
> 1. 若需**校验全局约束** → 前序把 $(\min,\max)$ 区间往下传,或后序把子树极值往上收。
> 2. 若涉及**有序性/第K个/相邻差** → 直接走中序遍历(严格递增),维护 `pre`。
> 3. 记住 BST 的两条等价刻画:区间约束 ⇔ 中序严格递增,选顺手的一种即可。
