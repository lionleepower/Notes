# 快慢指针专题：中点、环形链表、环入口、重排链表

整理自快慢指针与环形链表笔记。

一句话描述：用两个移动速度不同的指针，解决链表中点、是否有环、环入口，以及链表重排问题。

---

## 思路

链表不能像数组一样随机访问，所以很多问题不能直接通过下标解决。

快慢指针 Fast and Slow Pointers 的核心是：

- `slow` 每次走 1 步
    
- `fast` 每次走 2 步
    
- 通过两者速度差，判断中点、是否相遇、相遇后的位置关系
    

---

> [!tip]- 核心思路  
> 快慢指针适合链表问题，是因为链表只能从前往后走。
> 
> 常见用途：
> 
> - 找中点：`fast` 到末尾时，`slow` 在中间
>     
> - 判断环：如果有环，`fast` 一定会追上 `slow`
>     
> - 找环入口：第一次相遇后，让 `head` 和 `slow` 同速走，第二次相遇点就是入口
>     
> - 重排链表：先找中点，再反转后半段，最后交替合并
>     

---

> [!example]- 示例推演  
> 链表：
> 
> ```text
> 1 -> 2 -> 3 -> 4 -> 5
> ```
> 
> 快慢指针找中点：
> 
> ```text
> slow 每次走 1 步
> fast 每次走 2 步
> fast 到末尾时，slow 在 3
> ```
> 
> 如果链表有环：
> 
> ```text
> 3 -> 4 -> 5
>      ↑    ↓
>      7 <- 6
> ```
> 
> `fast` 比 `slow` 每轮多走 1 步，所以一定会在环内追上 `slow`。

---

> [!success]- Python 实现
> 
> ## 1. 找链表中点
> 
> ```python
> class Solution:
>     def middleNode(self, head):
>         slow = head
>         fast = head
> 
>         while fast and fast.next:
>             slow = slow.next
>             fast = fast.next.next
> 
>         return slow
> ```
> 
> 主流程：
> 
> - `slow` 每次走 1 步
>     
> - `fast` 每次走 2 步
>     
> - `fast` 走到末尾时，`slow` 就是中点
>     
> 
> 关键点：
> 
> - 奇数长度时，返回唯一中点
>     
> - 偶数长度时，返回第二个中点
>     
> 
> 例如：
> 
> ```text
> 1 -> 2 -> 3 -> 4
> ```
> 
> 返回：
> 
> ```text
> 3
> ```
> 
> ---
> 
> ## 2. 判断链表是否有环
> 
> ```python
> class Solution:
>     def hasCycle(self, head):
>         slow = head
>         fast = head
> 
>         while fast and fast.next:
>             slow = slow.next
>             fast = fast.next.next
> 
>             if slow is fast:
>                 return True
> 
>         return False
> ```
> 
> 主流程：
> 
> - 如果没有环，`fast` 会先走到 `None`
>     
> - 如果有环，`fast` 会在环内追上 `slow`
>     
> 
> 关键变量：
> 
> - `slow`：慢指针
>     
> - `fast`：快指针
>     
> 
> 容易写错的位置：
> 
> - 判断条件必须是 `while fast and fast.next`
>     
> - 判断节点是否相同用 `is`，不是比较节点值
>     
> 
> ---
> 
> ## 3. 找环形链表入口
> 
> ```python
> class Solution:
>     def detectCycle(self, head):
>         slow = head
>         fast = head
> 
>         while fast and fast.next:
>             slow = slow.next
>             fast = fast.next.next
> 
>             if slow is fast:
>                 while head is not slow:
>                     head = head.next
>                     slow = slow.next
> 
>                 return slow
> 
>         return None
> ```
> 
> 主流程：
> 
> - 第一步：快慢指针判断是否有环
>     
> - 第二步：如果相遇，让 `head` 和 `slow` 同时每次走 1 步
>     
> - 第三步：它们再次相遇的位置就是环入口
>     
> 
> 为什么第二次相遇是入口？
> 
> 设：
> 
> - `a`：头节点到环入口的距离
>     
> - `b`：环入口到第一次相遇点的距离
>     
> - `c`：第一次相遇点到环入口的距离
>     
> - 环长为 $b + c$
>     
> 
> 第一次相遇时：
> 
> ```text
> slow 走了 a + b
> fast 走了 2(a + b)
> ```
> 
> 快指针比慢指针多走了若干圈：
> 
> $$  
> 2(a + b) = a + b + k(b + c)  
> $$
> 
> 所以：
> 
> $$  
> a + b = k(b + c)  
> $$
> 
> 推出：
> 
> $$  
> a = k(b + c) - b  
> $$
> 
> 也就是：
> 
> $$  
> a = (k - 1)(b + c) + c  
> $$
> 
> 含义：
> 
> - 从 `head` 到入口要走 `a`
>     
> - 从相遇点到入口要走 `c`
>     
> - 两者只差若干个完整环长
>     
> 
> 所以让 `head` 和 `slow` 一起走，它们一定会在入口相遇。
> 
> ---
> 
> ## 4. 重排链表
> 
> 推荐面试写法：
> 
> ```python
> class Solution:
>     def middleNode(self, head):
>         slow = head
>         fast = head.next
> 
>         while fast and fast.next:
>             slow = slow.next
>             fast = fast.next.next
> 
>         return slow
> 
>     def reverseList(self, head):
>         pre = None
>         cur = head
> 
>         while cur:
>             nxt = cur.next
>             cur.next = pre
>             pre = cur
>             cur = nxt
> 
>         return pre
> 
>     def reorderList(self, head: Optional[ListNode]) -> None:
>         if not head or not head.next:
>             return
> 
>         mid = self.middleNode(head)
> 
>         head2 = mid.next
>         mid.next = None
> 
>         head2 = self.reverseList(head2)
>         head1 = head
> 
>         while head2:
>             nxt1 = head1.next
>             nxt2 = head2.next
> 
>             head1.next = head2
>             head2.next = nxt1
> 
>             head1 = nxt1
>             head2 = nxt2
> ```
> 
> 主流程：
> 
> - 找前半段尾节点
>     
> - 断开前后两段
>     
> - 反转后半段
>     
> - 交替合并
>     
> 
> 为什么这里 `fast = head.next`？
> 
> 因为重排链表更希望偶数长度时，`slow` 停在前半段末尾。
> 
> 例如：
> 
> ```text
> 1 -> 2 -> 3 -> 4
> ```
> 
> 希望拆成：
> 
> ```text
> 1 -> 2
> 3 -> 4
> ```
> 
> 所以 `slow` 应该停在 `2`，而不是 `3`。
> 
> 关键变量：
> 
> - `mid`：前半段尾节点
>     
> - `head2`：后半段头节点
>     
> - `nxt1`：保存前半段下一个节点
>     
> - `nxt2`：保存后半段下一个节点
>     

---

> [!warning]- 易错点
> 
> ## 1. 找中点时，`fast` 初始位置会影响结果
> 
> 写法一：
> 
> ```python
> slow = head
> fast = head
> ```
> 
> 偶数长度返回第二个中点。
> 
> ```text
> 1 -> 2 -> 3 -> 4
> 返回 3
> ```
> 
> 写法二：
> 
> ```python
> slow = head
> fast = head.next
> ```
> 
> 偶数长度返回第一个中点。
> 
> ```text
> 1 -> 2 -> 3 -> 4
> 返回 2
> ```
> 
> 面试中要根据题目选择。
> 
> ---
> 
> ## 2. 判断环时不能比较节点值
> 
> 错误写法：
> 
> ```python
> if slow.val == fast.val:
>     return True
> ```
> 
> 原因：
> 
> - 链表中可能有重复值
>     
> - 是否相遇看的是同一个节点对象
>     
> 
> 正确写法：
> 
> ```python
> if slow is fast:
>     return True
> ```
> 
> ---
> 
> ## 3. 环入口不是因为 `head` 到入口距离是环长倍数
> 
> 更准确地说：
> 
> ```text
> head 到入口的距离 a
> 相遇点到入口的距离 c
> ```
> 
> 它们满足：
> 
> $$  
> a = (k - 1)(b + c) + c  
> $$
> 
> 也就是说：
> 
> - `a` 不一定是环长的整数倍
>     
> - `a` 和 `c` 只差若干个完整环长
>     
> - 所以 `head` 和相遇点同时出发，会在入口相遇
>     
> 
> ---
> 
> ## 4. 慢指针不是“总距离小于环长”
> 
> 更准确地说：
> 
> - 慢指针进入环之后
>     
> - 快指针最多再用一个环长就能追上慢指针
>     
> - 第一次相遇点在环内，距离入口的偏移量一定小于一个环长
>     
> 
> 不能说慢指针从头开始走的总距离一定小于环长。
> 
> ---
> 
> ## 5. 重排链表不能反转整条链表
> 
> 错误写法：
> 
> ```python
> head2 = self.reverseList(head)
> ```
> 
> 原因：
> 
> - 这会破坏原来的前半段
>     
> - 后面无法正确交替合并
>     
> 
> 正确写法：
> 
> ```python
> head2 = mid.next
> mid.next = None
> head2 = self.reverseList(head2)
> ```
> 
> ---
> 
> ## 6. 重排链表一定要先保存 next
> 
> 正确顺序：
> 
> ```python
> nxt1 = head1.next
> nxt2 = head2.next
> 
> head1.next = head2
> head2.next = nxt1
> 
> head1 = nxt1
> head2 = nxt2
> ```
> 
> 如果不先保存 `nxt1` 和 `nxt2`，修改指针后会找不到后续节点。
> 
> ---
> 
> ## 7. 节点指针字段是 `.next`
> 
> 错误写法：
> 
> ```python
> head2.nxt = nxt
> ```
> 
> 正确写法：
> 
> ```python
> head2.next = nxt
> ```
> 
> Python 可能不会立刻报错，而是给对象新增一个 `nxt` 属性，但链表真正的连接没有被修改。

---

> [!summary]- 复杂度  
> 找链表中点：
> 
> 时间复杂度：$O(n)$
> 
> 空间复杂度：$O(1)$
> 
> 判断是否有环：
> 
> 时间复杂度：$O(n)$
> 
> 空间复杂度：$O(1)$
> 
> 找环入口：
> 
> 时间复杂度：$O(n)$
> 
> 空间复杂度：$O(1)$
> 
> 重排链表：
> 
> 时间复杂度：$O(n)$
> 
> 空间复杂度：$O(1)$
> 
> 为什么：
> 
> - 快慢指针最多遍历链表有限次数
>     
> - 反转和合并都只是修改原链表指针
>     
> - 没有使用额外数组或哈希表
>     

---

## 一句话总结

快慢指针的本质是利用速度差：无环时快指针先到终点，有环时快指针一定追上慢指针，相遇后再利用距离关系找到环入口。

---

## 模板归纳

快慢指针 Fast and Slow Pointers：

- 链表不能随机访问
    
- 需要找中点
    
- 需要判断是否有环
    
- 需要找环入口
    
- 需要把链表拆成前后两段
    

链表找中点：

- `fast = head`：偶数长度返回第二个中点
    
- `fast = head.next`：偶数长度返回第一个中点
    
- 重排链表通常用 `fast = head.next`
    

环形链表：

- 判断是否有环：看 `slow is fast`
    
- 找环入口：第一次相遇后，一个指针回到 `head`，两个指针同速走
    
- 第二次相遇点就是入口
    

重排链表：

- 找中点
    
- 断开后半段
    
- 反转后半段
    
- 交替合并
    
- 核心风险是断链和成环
