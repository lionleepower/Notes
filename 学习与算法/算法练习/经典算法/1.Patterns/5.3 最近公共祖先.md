# 236. 二叉树的最近公共祖先

## 题目
给定一棵二叉树和两个节点 p、q,返回它们的最近公共祖先 LCA(节点也可以是它自己的祖先)。默认 p、q 都存在于树中。

## 思路
LCA 的本质:对每个节点问一句「我这棵子树里到底有没有 p / q」。用 DFS **自底向上**把「找到了谁」的信息往上汇报 —— 若 p、q 分别落在某节点的左右两侧,该节点就是 LCA;若同在一侧,答案在那一侧更深处。原问题(整棵树的 LCA)能由左右子树的返回值直接拼出,这就是「树 + 递归」的信号。

> [!tip]- 核心思路(分类讨论 + 首达剪枝)
> 定义 `dfs(node)` = 「在以 node 为根的子树里,向上汇报的候选节点」。分类讨论:
> - **node 为空 / `node == p` / `node == q`** → 直接返回 node(首达即返回,不再深入)。
> - 否则递归左右,得到 `left = dfs(node.left)`、`right = dfs(node.right)`:
>     - `left` 与 `right` **都非空** → p、q 分居两侧,当前 node 就是 LCA,返回 node。
>     - **只有 left 非空** → 返回 left(答案在左边)。
>     - **只有 right 非空** → 返回 right(答案在右边)。
>     - **都为空** → 返回 None(这棵子树里什么都没有)。
>
> **为什么适合 DFS**:LCA 是典型的分治 —— 整体答案完全由左右子问题的答案决定,不需要跨子树的额外信息,自底向上一次遍历即可。
>
> **为什么找到 p 就能立刻返回、不用继续找 q**(关键剪枝):
> - 若 q 恰好在 p 的子树里 ⇒ p 本身就是 LCA,返回 p 向上正确;
> - 若 q 不在 p 的子树里 ⇒ p 作为「这一侧找到了」的信号向上冒泡,会在真正的 LCA 处与另一侧汇合。
> 两种情况返回 p 都对,所以无需再往 p 底下探。

## 示例推演
> [!example]- root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
> ```
> dfs(3)
> ├─ dfs(5)  命中 p → 返回 5(不再深入 6/2 子树)
> └─ dfs(1)
>    ├─ dfs(0) = None
>    └─ dfs(8) = None
>    → 命中 q → 返回 1
> 3 处:left=5, right=1 都非空 → p、q 分居两侧 → 返回 3
> ```
> 答案 = 3。

## 代码实现
> [!success]- 做法:自底向上 DFS(返回候选节点)
> ```python
> class Solution:
>     def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
>         if root is None or root is p or root is q:
>             return root
>         left = self.lowestCommonAncestor(root.left, p, q)
>         right = self.lowestCommonAncestor(root.right, p, q)
>         if left and right:      # p、q 分居左右 → 当前节点即 LCA
>             return root
>         return left if left else right   # 只有一侧找到,或都没找到
> ```
> ```cpp
> class Solution {
> public:
>     TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
>         if (root == nullptr || root == p || root == q) return root;
>         TreeNode* left  = lowestCommonAncestor(root->left,  p, q);
>         TreeNode* right = lowestCommonAncestor(root->right, p, q);
>         if (left && right) return root;   // 分居两侧 → 当前即 LCA
>         return left ? left : right;       // 汇报非空的那一侧
>     }
> };
> ```
> - **主流程**:base case 判空/判命中 → 递归左右 → 按左右返回值三选一。
> - **返回值语义**:返回的是「向上汇报的候选节点」,不是布尔、也不是计数。左右都非空才意味着「两个目标被劈开在此」。
> - **最易写错**:把 `left and right` 的判断写反,或漏掉「只有一侧」时的透传。

## 易错点
> [!warning]-
> - **base case 三合一别漏**:`root is None or root is p or root is q`,少一个都会漏底或错判。
> - **身份比较 vs 值比较**:Python 用 `is`(比对象),不要用 $==$(比值,值可能重复);C++ 用指针 $==$ 天然就是身份比较,没问题。
> - **返回值别当布尔用**:它是节点或 None;`if left and right` 借了 None 为假的特性,但语义上返回的是节点。
> - **剪枝的前提**:「找到 p 就返回、不再深入」依赖 p、q 都在树中。若不保证存在性,首达返回会得到错误的「LCA」,需另做存在性校验。
> - **顺序无关但缺一不可**:先判空还是先判命中不影响正确性,但两类都要判。

## 复杂度
> [!summary]-
> - 时间:$O(n)$ —— 每个节点最多访问一次(命中后剪枝只会更少)。
> - 空间:$O(h)$ —— 递归栈深度等于树高;最坏(链状)$O(n)$,平衡时 $O(\log n)$。

## 一句话总结
自底向上让每个节点汇报「我子树里有没有 p / q」,左右两边都汇报到 → 当前节点就是 LCA。

## 变体:235. 二叉搜索树的最近公共祖先
> [!tip]- 为什么 BST 能只走一条路径
> BST 的有序性(左 < 根 < 右)让「p、q 在哪一侧」可以直接由值大小判断,不必搜索整棵树:
> - p、q **都小于**当前值 → LCA 一定在左子树,只往左走;
> - p、q **都大于**当前值 → 只往右走;
> - **否则**(一左一右,或其一等于当前值)→ 当前节点就是那个「分叉点」,即 LCA。
>
> 换句话说:从根往下走,**第一个让 p、q 走向分开的节点**就是 LCA。相比 236 的 $O(n)$ 全树遍历,这里降到 $O(h)$。

> [!success]- BST 做法:利用有序性单向下探
> ```python
> class Solution:
>     def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
>         x = root.val
>         if p.val < x and q.val < x:
>             return self.lowestCommonAncestor(root.left, p, q)
>         if p.val > x and q.val > x:
>             return self.lowestCommonAncestor(root.right, p, q)
>         return root      # 分叉点:一左一右 / 命中 p 或 q
> ```
> ```cpp
> class Solution {
> public:
>     TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
>         int x = root->val;
>         if (p->val < x && q->val < x) return lowestCommonAncestor(root->left,  p, q);
>         if (p->val > x && q->val > x) return lowestCommonAncestor(root->right, p, q);
>         return root;   // 分叉点即 LCA
>     }
> };
> ```
> - **主流程**:两个方向判断都不成立时(即分叉或命中),当前节点就是答案。
> - **可优化到 $O(1)$ 空间**:这是单向下探,天然可改成 `while` 迭代,无需递归栈。
> - **易错**:第三种情况已隐含「命中 p 或 q」和「分居两侧」,不用像 236 那样单独判 `root is p`。

## 模板归纳
> [!tip]- 什么时候想到「自底向上汇报 + 分类讨论」
> **触发信号**:二叉树上,要找「同时和多个目标相关的某个节点」(公共祖先、分叉点、覆盖若干节点的最小子树)。
> **判断依据**:
> 1. 定义递归返回值 = 「子树向上汇报的信息」(这里是候选节点)。
> 2. 想清楚 base case(空 / 命中目标 返回什么)。
> 3. 用左右返回值做**分类讨论**:都有 / 只左 / 只右 / 都没有 → 分别返回什么。
> 4. 若树是 BST,先想「有序性能不能把全树遍历砍成单路径」(236 → 235 的降维)。
