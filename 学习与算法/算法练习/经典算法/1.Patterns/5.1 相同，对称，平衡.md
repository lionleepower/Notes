# 二叉树递归模板(递归的灵活运用)

> 模板笔记。`100 相同的树` / `101 对称二叉树` / `110 平衡二叉树` / `199 右视图` 是**同一套递归**的四个变体 —— 都基于"树 = 根 + 左子树 + 右子树",区别只在**返回什么**和**怎么组合**。

## 何时用
输入是二叉树(或链表/嵌套结构),问"整棵树的某个量或性质",且整体答案能由左右子问题结果组合出来 —— 就写 DFS 递归。

> [!tip]- 核心模板(三步走)
> $$f(node) = combine\big(node,\ f(node.left),\ f(node.right)\big)$$
> 1. **base case**:空节点返回什么(0 / True / 直接 return)。
> 2. **拆子问题**:当前答案 = 当前节点 与 左右子树返回值 的组合。
> 3. **信任归纳**:不在脑内展开整棵递归树,假设子问题已返回正确结果(**递**下去 → **归**上来)。
>
> 一句话心法:先想"整棵树与左右子树的**关系**",别一上来抠细节。base case 成立 + 能从子问题推到父问题 ⇒ 整棵树成立(数学归纳法 / 多米诺骨牌)。

> [!example]- 四种典型变体(本质同一套)
> | 变体 | 代表题 | 返回什么 | combine 怎么写 |
> |---|---|---|---|
> | 双树·同侧 | 100 相同的树 | `bool` | 值相等 且 左↔左、右↔右 都成立 |
> | 双树·交叉 | 101 对称二叉树 | `bool` | 值相等 且 左↔右、右↔左 都成立 |
> | 单树·哨兵 | 110 平衡二叉树 | 高度 / `-1` | 子树失衡上抛 -1,否则 `max+1` |
> | 单树·带 depth | 199 右视图 | 边遍历边填 | 先右后左,`depth==len(ans)` 记首达 |
>
> 掌握这四种,绝大多数"树 + 递归"题都能套:**要么改返回值类型,要么改 combine 逻辑,要么加一个参数**。

> [!success]- 四题代码 · Python(对照记忆)
> ```python
> # 100 相同的树 —— 双树·同侧;base case 一行判空
> def isSameTree(self, p, q) -> bool:
>     if p is None or q is None:
>         return q is p                       # 都空才 True
>     return (p.val == q.val
>             and self.isSameTree(p.left,  q.left)     # 同侧
>             and self.isSameTree(p.right, q.right))
>
> # 101 对称二叉树 —— 双树·交叉;只把比较交叉一下
> def isSymmetric(self, root) -> bool:
>     def mirror(p, q):
>         if p is None or q is None:
>             return p is q
>         return (p.val == q.val
>                 and mirror(p.left,  q.right)          # 交叉
>                 and mirror(p.right, q.left))
>     return mirror(root.left, root.right)
>
> # 110 平衡二叉树 —— 单树·哨兵;一次遍历同时求高度+判平衡
> def isBalanced(self, root) -> bool:
>     def height(node):
>         if node is None:
>             return 0
>         lh = height(node.left)
>         if lh == -1: return -1               # 失衡上抛
>         rh = height(node.right)
>         if rh == -1 or abs(lh - rh) > 1:
>             return -1
>         return max(lh, rh) + 1
>     return height(root) != -1
>
> # 199 右视图 —— 单树·带 depth;先右后左 + 判首达
> def rightSideView(self, root) -> List[int]:
>     ans = []
>     def f(node, depth):
>         if node is None: return
>         if depth == len(ans):                # 这层第一次到达 = 最右
>             ans.append(node.val)
>         f(node.right, depth + 1)             # 先右
>         f(node.left,  depth + 1)             # 后左
>     f(root, 0)
>     return ans
> ```

> [!success]- 四题代码 · C++(对照记忆)
> ```cpp
> // 100 相同的树 —— 双树·同侧
> bool isSameTree(TreeNode* p, TreeNode* q) {
>     if (!p || !q) return p == q;
>     return p->val == q->val
>         && isSameTree(p->left,  q->left)
>         && isSameTree(p->right, q->right);
> }
>
> // 101 对称二叉树 —— 双树·交叉
> bool isMirror(TreeNode* p, TreeNode* q) {
>     if (!p || !q) return p == q;
>     return p->val == q->val
>         && isMirror(p->left,  q->right)      // 交叉
>         && isMirror(p->right, q->left);
> }
> bool isSymmetric(TreeNode* root) { return isMirror(root->left, root->right); }
>
> // 110 平衡二叉树 —— 单树·哨兵
> int height(TreeNode* node) {
>     if (!node) return 0;
>     int lh = height(node->left);
>     if (lh == -1) return -1;
>     int rh = height(node->right);
>     if (rh == -1 || abs(lh - rh) > 1) return -1;
>     return max(lh, rh) + 1;
> }
> bool isBalanced(TreeNode* root) { return height(root) != -1; }
>
> // 199 右视图 —— 单树·带 depth
> vector<int> ans;
> void f(TreeNode* node, int depth) {
>     if (!node) return;
>     if (depth == (int)ans.size()) ans.push_back(node->val);
>     f(node->right, depth + 1);               // 先右
>     f(node->left,  depth + 1);
> }
> vector<int> rightSideView(TreeNode* root) { f(root, 0); return ans; }
> ```

> [!warning]- 通用易错点
> - **base case 漏判空**:空节点必须先处理,否则空指针 / 无限递归。含空时用 `p is q`(C++ `p == q`)一行判"是否都空"。
> - **同侧 vs 交叉(100 vs 101)**:对称是 `左↔右 / 右↔左`,写成同侧就退化成"判两子树相同"。
> - **哨兵别忘上抛(110)**:拿到左高 == -1 立刻 return;阈值是 `> 1` 不是 `>= 1`;最终判 `!= -1` 而非返回高度;别退化成对每个节点求高度的 $O(n^2)$。
> - **遍历顺序 + 判首达(199)**:先右后左不能反(反了变左视图);`depth == len(ans)` 用 `\==\`;depth 从 0 起;结尾别忘 `return ans`。
> - **combine 时的 +1 / 当前层**:想清楚"当前节点这一层"要不要算进结果(如求深度/高度要 `+1`)。

> [!summary]- 复杂度
> 四题同量级:时间 $O(n)$(每个节点恰好访问一次),空间 $O(h)$(递归栈深度,最坏链状 $O(n)$,平衡 $O(\log n)$)。

## 一句话总结
树的问题优先想"整棵树与左右子树的关系";返回值可以是 `bool` / 高度 / 哨兵,遍历可带 `depth` —— 递下去,归上来。

## 模板归纳
> [!tip]- 触发信号 + 判断依据
> **触发信号**:输入二叉树/嵌套结构;问"整体的某个量或性质"(相同 / 对称 / 平衡 / 深度 / 每层某值…)。
> **判断依据**:整体答案能由左右子问题结果简单组合 ⇒ 写递归。落笔三问:
> 1. **base case** 返回什么?
> 2. **返回值类型**是什么?(bool?数值?要不要哨兵值?要不要加 `depth` 参数?)
> 3. **combine** 怎么拼?然后信任归纳假设,别展开递归树。
