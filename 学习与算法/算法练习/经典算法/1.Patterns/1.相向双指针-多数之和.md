# 题目

在有序数组中用相向双指针解决 `Two Sum II`，并将 `3Sum` 转化为固定一个数后的 `Two Sum` 问题。

---

## 思路

相向双指针适合这类题的原因是：**排序后数组具有单调性**。  
如果当前和太小，移动左指针可以让和变大；如果当前和太大，移动右指针可以让和变小。  
`3Sum` 本质是：先排序，再固定一个数，把三数之和转化为两数之和。

---

> [!tip]- 核心思路
> 
> ## 1. Two Sum II
> 
> 数组已经有序，所以可以直接用相向双指针：
> 
> ```text
> left = 0
> right = n - 1
> ```
> 
> 当前和：
> 
> $$  
> s = numbers[left] + numbers[right]  
> $$
> 
> 判断逻辑：
> 
> - 如果 $s = target$，找到答案
>     
> - 如果 $s < target$，说明和太小，`left += 1`
>     
> - 如果 $s > target$，说明和太大，`right -= 1`
>     
> 
> 为什么这样移动？
> 
> 因为数组有序：
> 
> $$  
> numbers[left + 1] \ge numbers[left]  
> $$
> 
> 所以左指针右移会让和变大。
> 
> $$  
> numbers[right - 1] \le numbers[right]  
> $$
> 
> 所以右指针左移会让和变小。
> 
> ---
> 
> ## 2. 3Sum
> 
> `3Sum` 可以转化成多个 `Two Sum`。
> 
> 原问题：
> 
> $$  
> a + b + c = 0  
> $$
> 
> 固定一个数：
> 
> $$  
> a = nums[i]  
> $$
> 
> 剩下问题变成：
> 
> $$  
> b + c = -a  
> $$
> 
> 所以流程是：
> 
> ```text
> 排序 -> 固定 nums[i] -> 在右侧区间做 Two Sum -> 去重
> ```
> 
> 排序的两个作用：
> 
> - 让双指针移动有方向
>     
> - 让重复元素相邻，方便去重
>     

---

> [!example]- 示例推演
> 
> ## Two Sum II
> 
> ```python
> numbers = [2, 7, 11, 15]
> target = 9
> ```
> 
> ```text
> left = 0, right = 3
> 2 + 15 = 17 > 9，right 左移
> 
> left = 0, right = 2
> 2 + 11 = 13 > 9，right 左移
> 
> left = 0, right = 1
> 2 + 7 = 9，找到答案
> ```
> 
> 返回：
> 
> ```python
> [1, 2]
> ```
> 
> ---
> 
> ## 3Sum
> 
> ```python
> nums = [-1, 0, 1, 2, -1, -4]
> ```
> 
> 排序后：
> 
> ```python
> [-4, -1, -1, 0, 1, 2]
> ```
> 
> ```text
> 固定 -4：右侧双指针找不到答案
> 
> 固定 -1：
> -1 + -1 + 2 = 0，加入 [-1, -1, 2]
> -1 + 0 + 1 = 0，加入 [-1, 0, 1]
> 
> 固定第二个 -1：
> 和前一个固定值重复，跳过
> ```
> 
> 最终答案：
> 
> ```python
> [[-1, -1, 2], [-1, 0, 1]]
> ```

---

> [!success]- Python 实现
> 
> ## Two Sum II
> 
> ```python
> class Solution(object):
>     def twoSum(self, numbers, target):
>         left = 0
>         right = len(numbers) - 1
> 
>         while left < right:
>             s = numbers[left] + numbers[right]
> 
>             if s == target:
>                 return [left + 1, right + 1]
>             elif s < target:
>                 left += 1
>             else:
>                 right -= 1
> ```
> 
> 关键点：
> 
> - `left + 1` 和 `right + 1` 是因为题目要求返回 `1-based index`
>     
> - `s < target` 时移动 `left`
>     
> - `s > target` 时移动 `right`
>     
> 
> ---
> 
> ## 3Sum
> 
> ```python
> class Solution(object):
>     def threeSum(self, nums):
>         nums.sort()
>         ans = []
>         n = len(nums)
> 
>         for i in range(n - 2):
>             x = nums[i]
> 
>             if i > 0 and x == nums[i - 1]:
>                 continue
> 
>             if x + nums[i + 1] + nums[i + 2] > 0:
>                 break
> 
>             if x + nums[n - 2] + nums[n - 1] < 0:
>                 continue
> 
>             left = i + 1
>             right = n - 1
> 
>             while left < right:
>                 s = x + nums[left] + nums[right]
> 
>                 if s == 0:
>                     ans.append([x, nums[left], nums[right]])
> 
>                     left += 1
>                     while left < right and nums[left] == nums[left - 1]:
>                         left += 1
> 
>                     right -= 1
>                     while left < right and nums[right] == nums[right + 1]:
>                         right -= 1
> 
>                 elif s < 0:
>                     left += 1
>                 else:
>                     right -= 1
> 
>         return ans
> ```
> 
> 代码结构：
> 
> - `nums.sort()`：提供单调性和去重基础
>     
> - 外层 `for`：固定第一个数
>     
> - 内层 `while`：在右侧区间做 Two Sum
>     
> - 找到答案后同时移动左右指针，并跳过重复元素
>     
> 
> 最容易写错的位置：
> 
> - 固定值 `x` 要去重
>     
> - 找到答案后，左右指针都要移动
>     
> - 左右指针移动后还要继续跳过重复值
>     

---

> [!warning]- 易错点
> 
> ## 1. 没有排序就用相向双指针
> 
> 相向双指针依赖数组单调性。
> 
> 如果数组无序：
> 
> ```python
> left += 1
> ```
> 
> 不一定让和变大。
> 
> ```python
> right -= 1
> ```
> 
> 不一定让和变小。
> 
> ---
> 
> ## 2. Two Sum II 忘记返回 1-based index
> 
> LeetCode 167 要求返回从 `1` 开始的下标。
> 
> 正确：
> 
> ```python
> return [left + 1, right + 1]
> ```
> 
> 错误：
> 
> ```python
> return [left, right]
> ```
> 
> ---
> 
> ## 3. 3Sum 只对固定值去重
> 
> `3Sum` 需要三层去重：
> 
> ```text
> 固定值 nums[i] 去重
> left 去重
> right 去重
> ```
> 
> 只对 `nums[i]` 去重，仍然可能加入重复三元组。
> 
> ---
> 
> ## 4. 找到答案后只移动一个指针
> 
> 找到答案后应该继续缩小搜索区间：
> 
> ```python
> left += 1
> right -= 1
> ```
> 
> 然后分别跳过重复值。
> 
> 只移动一个指针容易产生重复答案。
> 
> ---
> 
> ## 5. 剪枝时 `break` 和 `continue` 混淆
> 
> 最小三数和已经大于 `0`：
> 
> ```python
> if x + nums[i + 1] + nums[i + 2] > 0:
>     break
> ```
> 
> 因为后面的 `x` 只会更大，所以直接结束。
> 
> 最大三数和仍然小于 `0`：
> 
> ```python
> if x + nums[n - 2] + nums[n - 1] < 0:
>     continue
> ```
> 
> 因为只是当前 `x` 太小，后面的 `x` 变大后仍可能有答案。

---

> [!summary]- 复杂度
> 
> ## Two Sum II
> 
> 时间复杂度：
> 
> $$  
> O(n)  
> $$
> 
> 空间复杂度：
> 
> $$  
> O(1)  
> $$
> 
> 为什么：
> 
> 两个指针总共最多移动 `n` 次，只使用常量变量。
> 
> ---
> 
> ## 3Sum
> 
> 时间复杂度：
> 
> $$  
> O(n^2)  
> $$
> 
> 空间复杂度：
> 
> $$  
> O(1)  
> $$
> 
> 为什么：
> 
> 排序是 $O(n \log n)$，外层固定一个数是 $O(n)$，内层双指针是 $O(n)$。
> 
> 所以整体主导项是：
> 
> $$  
> O(n^2)  
> $$
> 
> 如果考虑输出答案，空间复杂度还需要算上结果数组。

## 一句话总结

本题本质是利用排序后的单调性，用相向双指针把暴力枚举的搜索空间压缩掉。

## 模板归纳

相向双指针 Two Pointers from Both Ends 适合：

- 数组有序，或者可以先排序
    
- 两数之和 / 三数之和 / 多数之和
    
- 需要根据当前和与目标值的大小关系移动指针
    
- 当前值太小，移动左指针
    
- 当前值太大，移动右指针
    

多数之和模板：

```text
2Sum = 相向双指针

3Sum = 固定 1 个数 + 2Sum

4Sum = 固定 2 个数 + 2Sum

kSum = 固定 1 个数 + (k - 1)Sum
```

核心条件反射：

```text
看到多数之和 + 允许排序 + 要去重
=> 排序 + 固定若干个数 + 双指针
```
