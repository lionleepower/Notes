# 二叉树层序遍历 (BFS) 模板

> 主线：102. 二叉树的层序遍历；变体：103. 二叉树的锯齿形层序遍历、513. 找树左下角的值。三题共用同一个「一层一层往下推」的 BFS 框架。

## 题目
逐层、从左到右访问二叉树的所有节点,并按层组织结果(102 按层分组;103 奇偶层交替方向;513 取最底层最左的值)。

## 思路
「层序 / 逐层 / 按层输出 / 某一层的某个量 / 无权图最短步数」这类字眼,就是 BFS 的信号。关键是每一轮只处理**当前一整层**,把这一层的孩子收集成**下一层**,再进入下一轮 —— 天然按层切分。相比 DFS 的深度优先,BFS 用「当前层数组 cur / 队列」保证同层节点相邻,自然满足层序要求。

> [!tip]- 核心思路(两种等价实现)
> **写法一:双数组 cur / nxt(直观)**
> 维护「当前层」数组 cur。每轮遍历 cur:把每个节点的值收进 vals,把它的左右孩子收进 nxt(下一层)。遍历完把 vals 加入答案,再 `cur = nxt` 开启下一轮,直到 cur 为空。
>
> **写法二:队列 deque(更常见)**
> 队列的「先进先出 + 左出右进」天生保证节点按层序出队。诀窍:**每轮开始先记录本层大小** `n = len(q)`,只弹出 n 次 —— 这样当轮里新入队的孩子(下一层)不会混进本层。弹出 n 个节点后,队列里剩下的恰好是完整的下一层。
>
> 两种写法本质相同:cur/nxt 是把「本层」和「下一层」显式分成两个数组;队列是用「先冻结长度再出队」在一个容器里切开层。面试任选其一能默写即可。

## 示例推演
> [!example]- root = [1,2,3,4,5,6,null,null,null,7,null,8,9](队列写法)
> ```
> q=[1]         n=1  出1 → 入2,3        vals=[1]      → ans=[[1]]
> q=[2,3]       n=2  出2,3 → 入4,5,6     vals=[2,3]    → ans=[[1],[2,3]]
> q=[4,5,6]     n=3  出4,5,6 → 入7,8,9   vals=[4,5,6]  → ans+=[4,5,6]
> q=[7,8,9]     n=3  出7,8,9 → 无孩子     vals=[7,8,9]  → ans+=[7,8,9]
> q=[]          结束
> ```
> 每轮「先量长度、再逐个出队」是把每一层切开的关键。

## 代码实现
> [!success]- 102 写法一:双数组 cur / nxt
> ```python
> class Solution:
>     def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
>         if root is None:
>             return []
>         ans = []
>         cur = [root]
>         while cur:
>             nxt = []
>             vals = []
>             for node in cur:
>                 vals.append(node.val)
>                 if node.left:  nxt.append(node.left)
>                 if node.right: nxt.append(node.right)
>             cur = nxt
>             ans.append(vals)
>         return ans
> ```
> ```cpp
> class Solution {
> public:
>     vector<vector<int>> levelOrder(TreeNode* root) {
>         vector<vector<int>> ans;
>         if (root == nullptr) return ans;
>         vector<TreeNode*> cur = {root};
>         while (!cur.empty()) {
>             vector<TreeNode*> nxt;
>             vector<int> vals;
>             for (TreeNode* node : cur) {
>                 vals.push_back(node->val);
>                 if (node->left)  nxt.push_back(node->left);
>                 if (node->right) nxt.push_back(node->right);
>             }
>             cur = nxt;
>             ans.push_back(vals);
>         }
>         return ans;
>     }
> };
> ```
> - **主流程**:一轮处理一层 cur;边收值边攒下一层 nxt;轮末 `cur = nxt`。
> - **易错**:`cur = nxt` 必须在内层 for 之后,别在循环内改。

> [!success]- 102 写法二:队列 deque(推荐面试写这个)
> ```python
> class Solution:
>     def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
>         if root is None:
>             return []
>         ans = []
>         q = deque([root])
>         while q:
>             vals = []
>             for _ in range(len(q)):        # 先冻结本层大小
>                 node = q.popleft()
>                 vals.append(node.val)
>                 if node.left:  q.append(node.left)
>                 if node.right: q.append(node.right)
>             ans.append(vals)
>         return ans
> ```
> ```cpp
> class Solution {
> public:
>     vector<vector<int>> levelOrder(TreeNode* root) {
>         vector<vector<int>> ans;
>         if (root == nullptr) return ans;
>         queue<TreeNode*> q;
>         q.push(root);
>         while (!q.empty()) {
>             int n = q.size();              // 先冻结本层大小
>             vector<int> vals;
>             for (int i = 0; i < n; i++) {
>                 TreeNode* node = q.front(); q.pop();
>                 vals.push_back(node->val);
>                 if (node->left)  q.push(node->left);
>                 if (node->right) q.push(node->right);
>             }
>             ans.push_back(vals);
>         }
>         return ans;
>     }
> };
> ```
> - **关键变量**:`len(q)` / `q.size()` —— 进 for 前先取,决定本层弹出几个。
> - **最易写错**:忘了冻结长度,内层直接跟着 `while q` 走,会把下一层混进本层。

## 变体一:103. 锯齿形层序遍历
> [!success]- 同模板 + 一个奇偶标志位,只反转输出方向
> ```python
> class Solution:
>     def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
>         if root is None:
>             return []
>         ans = []
>         cur = [root]
>         even = False
>         while cur:
>             nxt = []
>             vals = []
>             for node in cur:
>                 vals.append(node.val)
>                 if node.left:  nxt.append(node.left)
>                 if node.right: nxt.append(node.right)
>             cur = nxt
>             ans.append(vals[::-1] if even else vals)   # 偶数层反转
>             even = not even
>         return ans
> ```
> ```cpp
> class Solution {
> public:
>     vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
>         vector<vector<int>> ans;
>         if (root == nullptr) return ans;
>         vector<TreeNode*> cur = {root};
>         bool even = false;
>         while (!cur.empty()) {
>             vector<TreeNode*> nxt;
>             vector<int> vals;
>             for (TreeNode* node : cur) {
>                 vals.push_back(node->val);
>                 if (node->left)  nxt.push_back(node->left);
>                 if (node->right) nxt.push_back(node->right);
>             }
>             cur = nxt;
>             if (even) reverse(vals.begin(), vals.end());
>             ans.push_back(vals);
>             even = !even;
>         }
>         return ans;
>     }
> };
> ```
> - **要点**:只反转**输出的 vals**,遍历顺序和入队顺序保持不变。若真去反转 nxt 的入队顺序,会打乱下一层的父子对应,越搞越乱。

## 变体二:513. 找树左下角的值
> [!success]- 单队列 + 先右后左,最后弹出的即答案
> ```python
> class Solution:
>     def findBottomLeftValue(self, root: Optional[TreeNode]) -> int:
>         q = deque([root])
>         while q:
>             node = q.popleft()
>             if node.right: q.append(node.right)   # 先右
>             if node.left:  q.append(node.left)    # 后左
>         return node.val
> ```
> ```cpp
> class Solution {
> public:
>     int findBottomLeftValue(TreeNode* root) {
>         queue<TreeNode*> q;
>         q.push(root);
>         TreeNode* node = root;
>         while (!q.empty()) {
>             node = q.front(); q.pop();
>             if (node->right) q.push(node->right);  // 先右
>             if (node->left)  q.push(node->left);   // 后左
>         }
>         return node->val;
>     }
> };
> ```
> - **巧思**:每次先入右孩子、后入左孩子,整棵树就按「层序但每层从右到左」出队,**最后一个出队的**必然是最底层最左的节点,不必按层分组。
> - **易错**:入队顺序写反成「先左后右」,得到的会是最底层最**右**的值。

## 易错点
> [!warning]-
> - **队列写法忘了冻结层大小**:进 for 前一定先 `n = len(q)`,再循环弹出 n 次;否则下一层节点会被算进本层。这是层序最经典的错。
> - **双数组 `cur = nxt` 位置**:必须在内层遍历结束后赋值,不能在循环体内改。
> - **收值时机**:节点值在出队/遍历到该节点时立刻记进 vals,不要等到入队子节点之后。
> - **base case**:root 为空要提前返回 `[]`(513 题目保证至少一个节点,可不判)。
> - **103 反转对象**:只反转输出的 vals,别动入队顺序。
> - **513 入队顺序**:先右后左才拿到「左下角」,写反即错。

## 复杂度
> [!summary]-
> - 时间:$O(n)$ —— 每个节点恰好入队、出队各一次。
> - 空间:$O(n)$ —— 队列最多同时存一层节点;最坏(满二叉树最底层)约 $n/2$,仍是 $O(n)$。

## 一句话总结
层序遍历就是 BFS 逐层推进;队列写法靠「进 for 前先量本层大小、再逐个出队」把每一层干净地切开。

## 模板归纳
> [!tip]- 什么时候想到「BFS + 队列」
> **触发信号**:要「逐层」处理、按层输出、求某一层的量(最大值 / 第一个 / 最后一个)、或无权图 / 树上求「距离根几步」「最短层数」。
> **判断依据**:只要答案和「层 / 到根的步数」直接相关,就上 BFS。
> **框架三步**:
> 1. 初始化队列放入 root(判空)。
> 2. 每轮 `while q`:先取本层大小 `n = len(q)`,内层弹出 n 次并把孩子入队。
> 3. 在这一轮里做「本层要做的事」(收集 vals / 更新答案 / 提前返回)。
> **变体套路**:要方向就加奇偶标志(103);只要某个特定节点(左下角、右视图)就不必分组,靠入队顺序或「每层最后一个」拿值(513 / 199)。
