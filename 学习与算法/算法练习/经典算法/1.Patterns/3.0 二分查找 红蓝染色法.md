# 题目

在==有序数组或具有单调性的答案空间==中，用二分查找定位第一个满足条件的位置。

---

## 思路

二分查找的核心不是“猜中目标”，而是维护一个稳定的边界。  
红蓝染色法把数组分成“不满足条件”和“满足条件”两部分。  
只要判定函数具有单调性，就可以通过不断缩小区间找到红蓝交界处。

---

> [!tip]- 核心思路
> 
> ## 1. 二分查找 Binary Search 的本质
> 
> 二分查找适合两类问题：
> 
> - 有序数组中找边界
>     
> - 有范围的答案空间中找最小 / 最大可行值
>     
> 
> 核心条件：
> 
> ```text
> 答案空间有范围 + 判定函数具有单调性
> ```
> 
> 单调性指的是：
> ![Exported image](Exported%20image%2020260514133524-0.png)  
> ![Exported image](Exported%20image%2020260514133529-1.png)
> 
> 
> ```text
> 前半部分不满足，后半部分满足
> ```
> 
> 或者：
> 
> ```text
> 前半部分满足，后半部分不满足
> ```
> 
> ---
> 
> ## 2. 红蓝染色法
> 
> 以寻找第一个 `>= target` 的位置为例：
> 
> - 红色：不满足条件，即 `< target`
>     
> - 蓝色：满足条件，即 `>= target`
>     
> 
> 目标：
> 
> ```text
> 找到第一个蓝色位置
> ```
> 
> 也就是：
> 
> ```text
> lower_bound(nums, target)
> ```
> 
> 含义：
> 
> ```text
> 返回第一个 >= target 的位置
> ```
> 
> ---
> 
> ## 3. 推荐模板：左闭右开 `[left, right)`
> 
> 初始化：
> 
> ```python
> left = 0
> right = len(nums)
> ```
> 
> 搜索区间：
> 
> ```text
> [left, right)
> ```
> 
> 循环条件：
> 
> ```python
> while left < right:
> ```
> 
> 中点：
> 
> $$  
> mid = \left\lfloor \frac{left + right}{2} \right\rfloor  
> $$
> 
> 判断：
> 
> ```python
> if nums[mid] < target: #注意这里还是得要根据题意来判断是否加等号，可以直接带入看是否满足条件
>     left = mid + 1
> else:
>     right = mid
> ```
> 
> 为什么 `right = mid`？
> 
> 因为当 `nums[mid] >= target` 时，`mid` 已经满足条件，可能就是第一个蓝色位置，不能丢掉。
> 
> 最终：
> 
> ```python
> return left
> ```
> 
> 此时 `left == right`，就是红蓝交界处。

> ```python
> nums = [5, 7, 7, 8, 8, 10]
> target = 8
> ```
> 
> 找第一个 `>= 8`：
> 
> ```text
> lower_bound(nums, 8) = 3
> ```

> ```text

> ```

> ```text
> 第一个 > 8 = 第一个 >= 9
> ```
> 
> 所以：

> ```text

> ```
>

> 
> ```python
> [3, 4]
> ```

> ## 1385. 两个数组间的距离值
> 
> 对每个 `x`，判断 `arr2` 中是否存在数字落在：
> 
> $$  
> [x - d, x + d]  
> $$
> 
> 内。
> 
> 用：
> 
> ```python
> i = bisect_left(arr2, x - d)
> ```
> 
> 找到第一个 `>= x - d` 的位置。
> 
> 如果：
> 
> ```python
> i == len(arr2) or arr2[i] > x + d
> ```
> 
> 说明区间内没有数，`x` 合法。

---

> [!success]- Python 实现
> 
> ## lower_bound 模板
> 
> ```python
> class Solution:
>     def lower_bound(self, nums: list[int], target: int) -> int:
>         left = 0
>         right = len(nums)
> 
>         while left < right:
>             mid = (left + right) // 2
> 
>             if nums[mid] < target:
>                 left = mid + 1
>             else:
>                 right = mid
> 
>         return left
> ```
> 
> 代码结构：
> 
> - `left = 0`，`right = len(nums)` 表示左闭右开区间 `[left, right)`
>     
> - `nums[mid] < target`，说明 `mid` 还是红色，答案在右边
>     
> - `nums[mid] >= target`，说明 `mid` 是蓝色，答案可能就是 `mid`
>     
> - 最后返回 `left`
>     
>

> ## 34. 在排序数组中查找元素的第一个和最后一个位置
> 
> ```python
> class Solution:
>     def lower_bound(self, nums: list[int], target: int) -> int:
>         left = 0
>         right = len(nums)
> 
>         while left < right:
>             mid = (left + right) // 2
> 
>             if nums[mid] < target:
>                 left = mid + 1
>             else:
>                 right = mid
> 
>         return left
> 
>     def searchRange(self, nums: list[int], target: int) -> list[int]:
>         start = self.lower_bound(nums, target)
> 
>         if start == len(nums) or nums[start] != target:
>             return [-1, -1]
> 
>         end = self.lower_bound(nums, target + 1) - 1
> 
>         return [start, end]
> ```
> 
> 关键点：
> 
> - `start = lower_bound(nums, target)` 找第一个 `target`
>     
> - `end = lower_bound(nums, target + 1) - 1` 找最后一个 `target`
>     
> - 必须检查 `target` 是否真的存在
>     
>

> ## 1385. 两个数组间的距离值
> 
> ```python
> from bisect import bisect_left
> 
> class Solution:
>     def findTheDistanceValue(self, arr1: list[int], arr2: list[int], d: int) -> int:
>         arr2.sort()
>         ans = 0
> 
>         for x in arr1:
>             i = bisect_left(arr2, x - d)
> 
>             if i == len(arr2) or arr2[i] > x + d:
>                 ans += 1
> 
>         return ans
> ```
> 
> 代码结构：
> 
> - 先排序 `arr2`
>     
> - 对每个 `x`，找 `arr2` 中第一个 `>= x - d` 的位置
>     
> - 如果这个位置不存在，或者已经超过 `x + d`，说明没有元素满足距离条件
>     

---

> [!warning]- 易错点
> 
> ## 1. 忘记二分需要单调性
> 
> 二分不是只能用于数组有序。
> 
> 更准确地说，二分需要：
> 
> ```text
> 判定结果具有单调性
> ```
> 
> 如果条件一会儿真一会儿假，就不能二分。
> 
> ---
> 
> ## 2. 不清楚自己写的是哪种区间
> 
> 常见三种写法：
> 
> ```text
> [left, right]
> [left, right)
> (left, right)
> ```
> 
> 推荐固定使用 `[left, right)`。
> 
> 因为它的初始化、循环条件、返回值都最统一：
> 
> ```python
> left = 0
> right = len(nums)
> while left < right:
>     ...
> return left
> ```
> 
> ---
> 
> ## 3. `[left, right)` 写法里误写 `right = mid - 1`
> 
> 在左闭右开写法中，`right` 本身不属于搜索区间。
> 
> 当 `nums[mid] >= target` 时，`mid` 可能就是答案，所以应该写：
> 
> ```python
> right = mid
> ```
> 
> 不是：
> 
> ```python
> right = mid - 1
> ```
> 
> ---
> 
> ## 4. 找最后一个 `target` 时硬写边界
> 
> 最后一个 `target` 可以转成：
> 
> ```text
> 第一个 > target 的位置 - 1
> ```
> 
> 对整数数组：
> 
> ```text
> 第一个 > target = 第一个 >= target + 1
> ```
> 
> 所以：
> 
> ```python
> end = lower_bound(nums, target + 1) - 1
> ```
> 
> 这样比单独写一个找右边界模板更稳。
> 
> ---
> 
> ## 5. 忘记检查 `target` 是否存在
> 
> `lower_bound(nums, target)` 返回的是第一个 `>= target` 的位置。
> 
> 但这个位置不一定真的等于 `target`。
> 
> 必须检查：
> 
> ```python
> if start == len(nums) or nums[start] != target:
>     return [-1, -1]
> ```
> 
> ---
> 
> ## 6. `bisect_left` 的含义记反
> 
> Python 中：
> 
> ```python
> bisect_left(arr, target)
> ```
> 
> 等价于：
> 
> ```text
> lower_bound(arr, target)
> ```
> 
> 也就是：
> 
> ```text
> 返回第一个 >= target 的位置
> ```

> [!summary]- 复杂度
> 
> ## lower_bound
> 
> 时间复杂度：
> 
> $$  
> O(\log n)  
> $$
> 
> 空间复杂度：
> 
> $$  
> O(1)  
> $$
> 
> 为什么：
> 
> 每次判断都会把搜索区间缩小一半。
> 
> ---
> 
> ## LeetCode 34
> 
> 时间复杂度：
> 
> $$  
> O(\log n)  
> $$
> 
> 空间复杂度：
> 
> $$  
> O(1)  
> $$
> 
> 为什么：
> 
> 执行两次 `lower_bound`，仍然是 $O(\log n)$。
> 
> ---
> 
> ## LeetCode 1385
> 
> 设：
> 
> - $n = len(arr1)$
>     
> - $m = len(arr2)$
>     
> 
> 时间复杂度：
> 
> $$  
> O(m \log m + n \log m)  
> $$
> 
> 空间复杂度：
> 
> $$  
> O(1)  
> $$
> 
> 为什么：
> 
> 排序 `arr2` 需要 $O(m \log m)$，对 `arr1` 中每个数做一次二分，每次 $O(\log m)$。

## 一句话总结

二分查找本质不是寻找某个值，而是在单调答案空间中寻找红色和蓝色的交界点。

---

## 模板归纳

Binary Search / lower_bound 适合：

- 有序数组
    
- 找第一个满足条件的位置
    
- 找左边界 / 右边界
    
- 答案空间有范围
    
- 判定函数具有单调性
    

标准 `lower_bound`：

```python
def lower_bound(nums, target):
    left = 0
    right = len(nums)

    while left < right:
        mid = (left + right) // 2

        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid

    return left
```

查找左右边界：

```python
start = lower_bound(nums, target)
end = lower_bound(nums, target + 1) - 1
```

判断不存在：

```python
if start == len(nums) or nums[start] != target:
    return [-1, -1]
```

`bisect_left`：
![[Pasted image 20260704103833.png]]


```python
from bisect import bisect_left

i = bisect_left(nums, target)
```

等价于：

```text
lower_bound(nums, target)
```

三种区间写法对比：

| 写法              | 初始化                       | 循环条件               | 蓝色时更新             | 返回      |
| --------------- | ------------------------- | ------------------ | ----------------- | ------- |
| `[left, right]` | `left = 0, right = n - 1` | `left <= right`    | `right = mid - 1` | `left`  |
| `[left, right)` | `left = 0, right = n`     | `left < right`     | `right = mid`     | `left`  |
| `(left, right)` | `left = -1, right = n`    | `left + 1 < right` | `right = mid`     | `right` |

条件反射：

```text
看到“第一个 >= target”
=> lower_bound

看到“最后一个 target”
=> lower_bound(target + 1) - 1

看到“最小可行值”
=> 二分答案，找第一个满足条件的位置

看到“最大可行值”
=> 二分答案，找最后一个满足条件的位置
```
