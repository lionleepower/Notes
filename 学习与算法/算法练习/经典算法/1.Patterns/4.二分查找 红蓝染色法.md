# 二分查找：红蓝染色法

## 1. 题目要解决什么问题？

二分查找用于在**有序数组**或具有**单调性**的答案空间中快速定位目标位置。  
典型问题是：找到数组中第一个满足某个条件的位置，例如第一个 `>= target` 的元素。  
在 LeetCode 34 中，需要在排序数组 `nums` 中找到 `target` 的第一个和最后一个位置；如果不存在，返回 `[-1, -1]`。

例子：

```python
nums = [5, 7, 7, 8, 8, 10]
target = 8
```

答案是：

```python
[3, 4]
```

## 2. 核心思路

这题属于 `Binary Search`。

核心不是“找等于 target 的位置”，而是转换成两个边界问题：

- 第一个 `>= target` 的位置
    
- 第一个 `>= target + 1` 的位置，再减一
    

也就是：

```text
start = lower_bound(nums, target)
end = lower_bound(nums, target + 1) - 1
```

## 3. 红蓝染色法

红蓝染色法本质是在维护一个循环不变量。

以寻找第一个 `>= target` 的位置为例：

- 红色：不满足条件，即 `< target`
    
- 蓝色：满足条件，即 `>= target`
    

目标是找到第一个蓝色位置。

循环不变量：

```text
left 左边一定是红色
right 右边一定是蓝色
```

最推荐的写法是左闭右开区间 `[left, right)`：

```text
[left, right)
```

含义：

- `left` 是当前搜索区间左边界
    
- `right` 是当前搜索区间右边界，但不包含 `right`
    
- 最终 `left == right`
    
- 返回 `left`
    

## 4. 关键公式 / 判断条件

中点：

$$  
mid = \lfloor \frac{left + right}{2} \rfloor  
$$

如果：

$$  
nums[mid] < target  
$$

说明 `mid` 是红色，答案一定在右边：

```python
left = mid + 1
```

否则：

$$  
nums[mid] \ge target  
$$

说明 `mid` 是蓝色，答案可能就是 `mid`，所以保留 `mid`：

```python
right = mid
```

最终返回：

$$  
left  
$$

## 5. 代码模板

### lower_bound：寻找第一个大于等于 target 的位置

```python
class Solution:
    def lower_bound(self, nums: list[int], target: int) -> int:
        left = 0
        right = len(nums)

        while left < right:
            mid = (left + right) // 2

            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid

        return left
```

### LeetCode 34：查找第一个和最后一个位置

```python
class Solution:
    def lower_bound(self, nums: list[int], target: int) -> int:
        left = 0
        right = len(nums)

        while left < right:
            mid = (left + right) // 2

            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid

        return left

    def searchRange(self, nums: list[int], target: int) -> list[int]:
        start = self.lower_bound(nums, target)

        if start == len(nums) or nums[start] != target:
            return [-1, -1]

        end = self.lower_bound(nums, target + 1) - 1

        return [start, end]
```

## 6. 为什么 end 要用 lower_bound(target + 1) - 1？

数组中最后一个 `target` 的位置，可以理解为：

```text
第一个 > target 的位置 - 1
```

对于整数数组：

```text
第一个 > target
```

等价于：

```text
第一个 >= target + 1
```

所以：

$$  
end = lower_bound(nums, target + 1) - 1  
$$

小例子：

```python
nums = [5, 7, 7, 8, 8, 10]
target = 8
```

第一个 `>= 8` 的位置是 `3`。  
第一个 `>= 9` 的位置是 `5`。  
所以最后一个 `8` 的位置是：

$$  
5 - 1 = 4  
$$

最终答案：

```python
[3, 4]
```

## 7. bisect_left

Python 内置函数 `bisect_left(arr, target)` 的作用就是：

```text
返回第一个 >= target 的位置
```

等价于手写的 `lower_bound`。

例子：

```python
from bisect import bisect_left

arr = [1, 3, 3, 3, 5]

i = bisect_left(arr, 3)
print(i)
```

输出：

```python
1
```

因为第一个 `3` 的下标是 `1`。

## 8. 补充例题：1385. 两个数组间的距离值

## 1. 题目要解决什么问题？

给定两个数组 `arr1`、`arr2` 和整数 `d`。  
对于 `arr1` 中的每个数 `x`，如果 `arr2` 中不存在任何数 `y` 使得：

$$  
|x - y| \le d  
$$

那么 `x` 就是一个合法元素。  
要求统计合法元素数量。

## 2. 核心思路

对 `arr2` 排序，然后对每个 `x`，只需要判断 `arr2` 中是否存在落在区间：

$$  
[x - d, x + d]  
$$

内的数。

使用 `bisect_left(arr2, x - d)` 找到第一个大于等于 `x - d` 的位置。  
如果这个位置不存在，或者这个位置的值已经大于 `x + d`，说明区间内没有数，答案加一。

## 3. 代码模板

```python
from bisect import bisect_left

class Solution:
    def findTheDistanceValue(self, arr1: list[int], arr2: list[int], d: int) -> int:
        arr2.sort()
        ans = 0

        for x in arr1:
            i = bisect_left(arr2, x - d)

            if i == len(arr2) or arr2[i] > x + d:
                ans += 1

        return ans
```

## 4. 复杂度分析

时间复杂度：

$$  
O(m \log m + n \log m)  
$$

空间复杂度：

$$  
O(1)  
$$

其中 `m = len(arr2)`，`n = len(arr1)`。排序 `arr2` 需要 $O(m \log m)$，之后对 `arr1` 中每个元素做一次二分查找。

# 二分查找总结

## 1. 什么时候用二分？

满足两个条件时，可以考虑二分：

- 答案空间有范围
    
- 判定函数具有单调性
    

也就是：

```text
前半部分不满足
后半部分满足
```

或者反过来：

```text
前半部分满足
后半部分不满足
```

## 2. 最推荐模板

寻找第一个 `>= target` 的位置：

```python
def lower_bound(nums: list[int], target: int) -> int:
    left = 0
    right = len(nums)

    while left < right:
        mid = (left + right) // 2

        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid

    return left
```

## 3. 三种常见区间写法

### 写法一：闭区间 `[left, right]`

```python
left = 0
right = len(nums) - 1

while left <= right:
    mid = (left + right) // 2

    if nums[mid] < target:
        left = mid + 1
    else:
        right = mid - 1

return left
```

### 写法二：左闭右开 `[left, right)`

最推荐。

```python
left = 0
right = len(nums)

while left < right:
    mid = (left + right) // 2

    if nums[mid] < target:
        left = mid + 1
    else:
        right = mid

return left
```

### 写法三：开区间 `(left, right)`

```python
left = -1
right = len(nums)

while left + 1 < right:
    mid = (left + right) // 2

    if nums[mid] < target:
        left = mid
    else:
        right = mid

return right
```

## 4. 三种写法怎么选？

优先使用左闭右开 `[left, right)`。

原因：

- 初始化简单：`left = 0, right = len(nums)`
    
- 循环条件简单：`while left < right`
    
- 返回值简单：`return left`
    
- 不容易出现 `mid - 1`、`mid + 1` 的边界错误
    

## 5. 复杂度分析

时间复杂度：

$$  
O(\log n)  
$$

空间复杂度：

$$  
O(1)  
$$

因为每次二分都会把搜索区间缩小一半。

## 6. 核心结论

- 二分查找的核心是维护循环不变量
    
- 红蓝染色法可以帮助理解边界
    
- `lower_bound(nums, target)` 返回第一个 `>= target` 的位置
    
- 查找最后一个 `target` 可以用 `lower_bound(nums, target + 1) - 1`
    
- 推荐统一使用 `[left, right)` 模板
    
- Python 里 `bisect_left(arr, target)` 就是 `lower_bound`
    

## 7. 常见误区

- 忘记数组必须有序，或者答案空间必须有单调性
    
- 不清楚自己维护的是 `[left, right]` 还是 `[left, right)`
    
- 在 `[left, right)` 写法里错误使用 `right = mid - 1`
    
- 找最后一个位置时直接硬搜，导致边界复杂
    
- 忘记检查 `target` 是否真的存在于数组中
