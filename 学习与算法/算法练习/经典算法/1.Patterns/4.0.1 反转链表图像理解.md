你现在卡住的点其实就一句话：

**每一轮循环，只把 `cur` 这个节点从原链表里“摘下来”，接到 `pre` 前面。**

原链表方向是：

```text
1 -> 2 -> 3 -> None
```

反转后要变成：

```text
3 -> 2 -> 1 -> None
```

---

## 先记住三个指针的含义

```python
pre = None
cur = head
```

可以理解成：

```text
pre：已经反转好的部分
cur：当前正在处理的节点
nxt：临时保存 cur 后面的节点
```

一开始：

```text
pre = None

cur
 |
 1 -> 2 -> 3 -> None
```

---

## 例子 1：反转 `1 -> 2 -> 3`

代码：

```python
while cur:
    nxt = cur.next
    cur.next = pre
    pre = cur
    cur = nxt
```

---

### 第 1 轮：处理节点 1

当前状态：

```text
pre = None
cur = 1

None    1 -> 2 -> 3 -> None
        cur
```

第一步，保存后面的节点：

```python
nxt = cur.next
```

也就是：

```text
nxt = 2
```

现在：

```text
None    1 -> 2 -> 3 -> None
        cur  nxt
```

第二步，反转当前节点的指针：

```python
cur.next = pre
```

也就是让 `1.next = None`：

```text
1 -> None     2 -> 3 -> None
cur           nxt
```

第三步，`pre` 往前走：

```python
pre = cur
```

```text
pre
 |
 1 -> None     2 -> 3 -> None
               nxt
```

第四步，`cur` 去处理下一个节点：

```python
cur = nxt
```

```text
pre            cur
 |              |
 1 -> None      2 -> 3 -> None
```

第 1 轮结束后，已经反转好的部分是：

```text
1 -> None
```

还没处理的是：

```text
2 -> 3 -> None
```

---

### 第 2 轮：处理节点 2

开始状态：

```text
pre            cur
 |              |
 1 -> None      2 -> 3 -> None
```

保存下一个：

```python
nxt = cur.next
```

```text
pre            cur  nxt
 |              |    |
 1 -> None      2 -> 3 -> None
```

反转当前节点：

```python
cur.next = pre
```

也就是让 `2.next = 1`：

```text
2 -> 1 -> None      3 -> None
cur                 nxt
```

移动 `pre`：

```python
pre = cur
```

```text
pre
 |
 2 -> 1 -> None      3 -> None
```

移动 `cur`：

```python
cur = nxt
```

```text
pre                 cur
 |                   |
 2 -> 1 -> None      3 -> None
```

第 2 轮结束后：

```text
已反转：2 -> 1 -> None
未处理：3 -> None
```

---

### 第 3 轮：处理节点 3

开始状态：

```text
pre                 cur
 |                   |
 2 -> 1 -> None      3 -> None
```

保存下一个：

```python
nxt = cur.next
```

```text
nxt = None
```

反转当前节点：

```python
cur.next = pre
```

也就是：

```text
3 -> 2 -> 1 -> None
cur
```

移动 `pre`：

```python
pre = cur
```

```text
pre
 |
 3 -> 2 -> 1 -> None
```

移动 `cur`：

```python
cur = nxt
```

```text
cur = None
```

循环结束。

最后返回：

```python
return pre
```

因为 `pre` 指向新的头节点 `3`。

结果：

```text
3 -> 2 -> 1 -> None
```

---

## 为什么一定要有 `nxt = cur.next`？

因为你马上要执行：

```python
cur.next = pre
```

这一步会改变 `cur.next`。

比如一开始：

```text
1 -> 2 -> 3
```

如果你不先保存 `2`，直接写：

```python
cur.next = pre
```

就变成：

```text
1 -> None
```

那后面的：

```text
2 -> 3
```

你就找不到了。

所以 `nxt` 的作用是：

```text
我先记住后面的路，等我把当前节点反转完，再继续往后走。
```

## 例子 2：只有一个节点

输入：

```text
1 -> None
```

初始：

```text
pre = None
cur = 1
```

循环一次：

```python
nxt = cur.next      # None
cur.next = pre      # 1 -> None
pre = cur           # pre 指向 1
cur = nxt           # cur = None
```

结束：

```text
pre
 |
 1 -> None
```

返回 `pre`。

所以单节点反转还是自己。

## 例子 3：空链表

输入：

```text
head = None
```

初始：

```python
pre = None
cur = head
```

所以：

```python
cur = None
```

循环条件：

```python
while cur:
```

不成立，直接返回：

```python
return pre
```

也就是：

```text
None
```

所以空链表返回空。

## 例子 4：两个节点 `1 -> 2`

初始：

```text
pre = None
cur = 1

None    1 -> 2 -> None
        cur
```

第 1 轮后：

```text
pre            cur
 |              |
 1 -> None      2 -> None
```

第 2 轮后：

```text
pre
 |
 2 -> 1 -> None

cur = None
```

返回：

```text
2 -> 1 -> None
```

## 把四行代码翻译成人话

```python
nxt = cur.next
```

先保存下一个节点，不然等会儿链表会断。

```python
cur.next = pre
```

让当前节点反过来指向前一个节点。

```python
pre = cur
```

当前节点已经反转好了，把它归入反转完成区。

```python
cur = nxt
```

继续处理原链表的下一个节点。

---

## 最核心的图像记忆

每一轮都是把这个：

```text
pre        cur       nxt
 |          |         |
反转区      当前节点   后续链表
```

变成：

```text
cur -> pre        nxt
 |                |
新反转区          后续链表
```

所以本质就是：

```text
把 cur 插到 pre 前面，然后 cur 继续往后走。
```

---

## 你真正要背的是这个不变量

循环过程中始终保持：

```text
pre：已经反转好的链表头
cur：还没反转的链表头
```

例如原链表：

```text
1 -> 2 -> 3 -> 4
```

过程是：

```text
pre = None,        cur = 1 -> 2 -> 3 -> 4

pre = 1,           cur = 2 -> 3 -> 4

pre = 2 -> 1,      cur = 3 -> 4

pre = 3 -> 2 -> 1, cur = 4

pre = 4 -> 3 -> 2 -> 1, cur = None
```

最后 `cur = None`，说明原链表处理完了。

所以答案就是 `pre`。
