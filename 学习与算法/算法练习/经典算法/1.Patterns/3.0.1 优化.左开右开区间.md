# 题目

在==有序数组或具有单调性的答案空间==中，用二分查找定位红蓝交界点。

---

## 思路

二分查找的核心不是“猜中目标”，而是维护两个稳定边界。  
红蓝染色法把答案空间分成“不满足条件”和“满足条件”两部分。  
只要判定函数具有单调性，就可以不断缩小区间，找到第一个满足条件的位置。

---

> [!tip]- 核心思路
> 
> ## 1. 二分查找 Binary Search 的本质
> 
> 二分查找适合两类问题：
> 
> - 有序数组中找边界
>     
> - 有范围的答案空间中找最小 / 最大可行值
>     
> 
> 核心条件：
> 
> ```text
> 答案空间有范围 + 判定函数具有单调性
> ```
> 
> 单调性指的是结果可以被分成两段：
> 
> ```text
> False False False True True True
> ```
> 
> 或者：
> 
> ```text
> True True True False False False
> ```
> 
> 最常用的是第一种：
> 
> ```text
> 前半部分不满足，后半部分满足
> ```
> 
> 目标就是找到：
> 
> ```text
> 第一个满足条件的位置
> ```
> 
> ---
> 
> ## 2. 红蓝染色法
> 
> 以寻找第一个 `>= target` 的位置为例：
> 
> - 红色：不满足条件，即 `< target`
>     
> - 蓝色：满足条件，即 `>= target`
>     
> 
> 目标：
> 
> ```text
> 找到第一个蓝色位置
> ```
> 
> 也就是：
> 
> ```text
> lower_bound(nums, target)
> ```
> 
> 含义：
> 
> ```text
> 返回第一个 >= target 的位置
> ```
> 
> ---
> 
> ## 3. 最推荐模板：左开右开 `(left, right)`
> 
> 初始化：
> 
> ```python
> left = -1
> right = len(nums)
> ```
> 
> 边界含义：
> 
> ```text
> left  = 最后一个红色位置，也就是最后一个不满足的位置
> right = 第一个蓝色位置，也就是第一个满足的位置
> ```
> 
> 循环条件：
> 
> ```python
> while left + 1 < right:
> ```
> 
> 中点：
> 
> $$  
> mid = \left\lfloor \frac{left + right}{2} \right\rfloor  
> $$
> 
> 判断：
> 
> ```python
> if nums[mid] < target:
>     left = mid
> else:
>     right = mid
> ```
> 
> 为什么这个模板好用？
> 
> - `mid` 不满足条件，就归到红色边界：`left = mid`
>     
> - `mid` 满足条件，就归到蓝色边界：`right = mid`
>     
> - 不需要写 `mid + 1` 或 `mid - 1`
>     
> - 结束时 `left + 1 == right`，红蓝边界贴在一起
>     
> 
> 最终：
> 
> ```python
> return right
> ```
> 
> 此时 `right` 就是第一个满足条件的位置。
> 
> ---
> 
> 
> 
## 关键理解：先定义 `check(mid)`，再写“不满足”

左开右开 `(left, right)` 模板本质上是在找：

```text
第一个满足 check(mid) 的位置
```

模板固定为：

```python
left = -1
right = n

while left + 1 < right:
    mid = (left + right) // 2

    if not check(mid):
        left = mid
    else:
        right = mid

return right
```

关键点：

```text
left 维护最后一个不满足的位置
right 维护第一个满足的位置
```

所以写代码时，不要先纠结：

```text
这里到底要不要加等号？
```

而是按顺序问：

```text
1. 我要找的“第一个满足”是什么？
2. check(mid) 应该怎么定义？
3. not check(mid) 是什么？
4. if not check(mid): left = mid
```

### 常见目标对比

|目标|满足条件 `check(mid)`|不满足条件 `not check(mid)`|代码里的 `if`|
|---|---|---|---|
|第一个 `>= target`|`nums[mid] >= target`|`nums[mid] < target`|`if nums[mid] < target:`|
|第一个 `> target`|`nums[mid] > target`|`nums[mid] <= target`|`if nums[mid] <= target:`|
|第一个 `>= n - i`|`citations[mid] >= n - mid`|`citations[mid] < n - mid`|`if citations[mid] < n - mid:`|
|第一个可行速度|`hours(mid) <= h`|`hours(mid) > h`|`if hours(mid) > h:`|
|第一个可行容量|`days(mid) <= D`|`days(mid) > D`|`if days(mid) > D:`|

### 例子 1：找第一个 `>= target`

目标：

```text
找到第一个 nums[mid] >= target 的位置
```

所以：

```python
check(mid) = nums[mid] >= target
```

不满足就是：

```python
not check(mid) = nums[mid] < target
```

代码：

```python
def lower_bound(nums, target):
    left = -1
    right = len(nums)

    while left + 1 < right:
        mid = (left + right) // 2

        if nums[mid] < target:
            left = mid
        else:
            right = mid

    return right
```

解释：

```text
nums[mid] < target
=> mid 还是红色，不满足
=> left = mid

nums[mid] >= target
=> mid 已经是蓝色，满足
=> right = mid
```

等号没有消失，而是被包含在 `else` 里。

---

### 例子 2：找第一个 `> target`

目标：

```text
找到第一个 nums[mid] > target 的位置
```

所以：

```python
check(mid) = nums[mid] > target
```

不满足就是：

```python
not check(mid) = nums[mid] <= target
```

代码：

```python
def upper_bound(nums, target):
    left = -1
    right = len(nums)

    while left + 1 < right:
        mid = (left + right) // 2

        if nums[mid] <= target:
            left = mid
        else:
            right = mid

    return right
```

解释：

```text
nums[mid] <= target
=> mid 还不满足“> target”
=> left = mid

nums[mid] > target
=> mid 已经满足
=> right = mid
```

所以：

```text
lower_bound: 第一个 >= target
upper_bound: 第一个 > target
```

### 例子 3：H 指数 II

目标：

```text
找到第一个满足 citations[mid] >= n - mid 的位置
```

所以：

```python
check(mid) = citations[mid] >= n - mid
```

不满足就是：

```python
not check(mid) = citations[mid] < n - mid
```

代码：

```python
class Solution(object):
    def hIndex(self, citations):
        n = len(citations)
        left = -1
        right = n

        while left + 1 < right:
            mid = (left + right) // 2

            if citations[mid] < n - mid:
                left = mid
            else:
                right = mid

        return n - right
```

解释：

```text
citations[mid] < n - mid
=> 从 mid 到末尾虽然有 n - mid 篇论文
=> 但 citations[mid] 还不够 n - mid
=> mid 不满足，left = mid

citations[mid] >= n - mid
=> mid 满足
=> right = mid
```

最后：

```python
return n - right
```

因为 `right` 是第一个满足的位置，真正的 H 指数是右侧论文数量。

### 例子 4：最小吃香蕉速度

目标：

```text
找到第一个能在 h 小时内吃完的速度 k
```

所以：

```python
check(k) = hours(k) <= h
```

不满足就是：

```python
not check(k) = hours(k) > h
```

代码结构：

```python
left = 0
right = max(piles)

while left + 1 < right:
    mid = (left + right) // 2

    hours = sum((p + mid - 1) // mid for p in piles)

    if hours > h:
        left = mid
    else:
        right = mid

return right
```

解释：

```text
hours > h
=> 速度 mid 太慢，不满足
=> left = mid

hours <= h
=> 速度 mid 可行
=> right = mid
```

这里的等号也被放进了 `else`：

```text
else 等价于 hours <= h
```

### 最核心记忆

```python
if not check(mid):
    left = mid
else:
    right = mid
```

不要死记 `>`、`>=`、`<`、`<=`。

先定义：

```text
check(mid) = mid 是否已经满足题目要求
```

再写：

```text
not check(mid) = mid 还不满足
```

---

### 三种区间写法对比

|写法|初始化|循环条件|蓝色时更新|红色时更新|返回|
|---|---|---|---|---|---|
|`[left, right]`|`left = 0, right = n - 1`|`left <= right`|`right = mid - 1`|`left = mid + 1`|`left`|
|`[left, right)`|`left = 0, right = n`|`left < right`|`right = mid`|`left = mid + 1`|`left`|
|`(left, right)`|`left = -1, right = n`|`left + 1 < right`|`right = mid`|`left = mid`|`right`|

### 条件反射

```text
看到“第一个 >= target”
=> lower_bound

看到“最后一个 target”
=> lower_bound(target + 1) - 1

看到“最小可行值”
=> 二分答案，找第一个满足条件的位置

看到“最大可行值”
=> 二分答案，找最后一个满足条件的位置

看到“False False True True”
=> 优先用左开右开模板

看到“红蓝交界”
=> left 是红，right 是蓝，最后返回 right
```
