
# 题目

删除链表中的节点，重点掌握：改指针、dummy node、快慢指针、排序链表去重。资料来源：

---

## 思路

链表删除的本质不是“删除节点本身”，而是让前一个节点跳过当前节点。  
如果可能删除头节点，就用 `dummy node` 统一处理边界。  
如果要删除倒数第 `n` 个节点，用快慢指针保持固定距离。  
如果是排序链表去重，可以利用相邻重复元素连续出现的性质。

---

> [!tip]- 核心思路
> 
> ## 1. 删除当前节点
> 
> 正常删除链表节点需要知道它的前一个节点：
> 
> ```python
> prev.next = prev.next.next
> ```
> 
> 但如果题目只给当前节点 `node`，没有 `prev`，就不能真正跳过自己。
> 
> 因为题目保证 `node` 不是尾节点，所以可以把下一个节点的值复制到当前节点，再跳过下一个节点：
> 
> ```python
> node.val = node.next.val
> node.next = node.next.next
> ```
> 
> 本质是：不删除当前节点，而是让当前节点“伪装成下一个节点”。
> 
> ---
> 
> ## 2. 删除倒数第 n 个节点
> 
> 想删除某个节点，必须找到它的前一个节点。
> 
> 用 `right` 先走 `n` 步，再让 `left` 和 `right` 一起走。
> 
> 当 `right` 到达最后一个节点时，`left` 正好停在倒数第 `n + 1` 个节点，也就是要删除节点的前一个节点。
> 
> ---
> 
> ## 3. 删除排序链表中的重复元素 I
> 
> 如果只保留一个重复元素，例如：
> 
> ```text
> 1 -> 1 -> 2 -> 3 -> 3
> ```
> 
> 结果是：
> 
> ```text
> 1 -> 2 -> 3
> ```
> 
> 因为链表已排序，所以重复元素一定相邻，只需要比较 `cur.val` 和 `cur.next.val`。
> 
> ---
> 
> ## 4. 删除排序链表中的重复元素 II
> 
> 如果所有重复元素都要删除，例如：
> 
> ```text
> 1 -> 2 -> 3 -> 3 -> 4 -> 4 -> 5
> ```
> 
> 结果是：
> 
> ```text
> 1 -> 2 -> 5
> ```
> 
> 因为头节点也可能被删除，所以必须使用 `dummy node`。

---

> [!example]- 示例推演
> 
> ## 删除倒数第 n 个节点
> 
> 链表：
> 
> ```text
> 1 -> 2 -> 3 -> 4 -> 5
> ```
> 
> 删除倒数第 `2` 个节点，也就是 `4`。
> 
> 初始：
> 
> ```text
> dummy -> 1 -> 2 -> 3 -> 4 -> 5
> left = dummy
> right = dummy
> ```
> 
> `right` 先走 `2` 步，到达 `2`。
> 
> 然后 `left` 和 `right` 一起走，直到 `right.next` 为空。
> 
> 此时：
> 
> ```text
> left = 3
> right = 5
> ```
> 
> 删除：
> 
> ```python
> left.next = left.next.next
> ```
> 
> 结果：
> 
> ```text
> 1 -> 2 -> 3 -> 5
> ```

> [!success]- C++/Python 实现
> 
> ## 1. 删除给定节点
> 
> ```python
> class Solution:
>     def deleteNode(self, node):
>         node.val = node.next.val
>         node.next = node.next.next
> ```
> 
> 主流程：
> 
> - 把下一个节点的值复制到当前节点
>     
> - 当前节点跳过下一个节点
>     
> 
> 关键变量：
> 
> - `node`：题目给定的待删除节点
>     
> 
> 容易写错：
> 
> - 这题不能写 `node = None`，因为只是改了局部变量
>     
> - 题目必须保证 `node.next` 存在，否则无法复制
>     
> 
> ---
> 
> ## 2. 删除倒数第 n 个节点
> 
> ```python
> class Solution:
>     def removeNthFromEnd(self, head, n):
>         dummy = ListNode(0, head)
>         left = dummy
>         right = dummy
> 
>         for _ in range(n):
>             right = right.next
> 
>         while right.next:
>             left = left.next
>             right = right.next
> 
>         left.next = left.next.next
> 
>         return dummy.next
> ```
> 
> 主流程：
> 
> - 建立 `dummy`，防止删除头节点时特殊处理
>     
> - `right` 先走 `n` 步
>     
> - `left` 和 `right` 同步移动
>     
> - `left` 停在待删除节点的前一个节点
>     
> 
> 关键变量：
> 
> - `dummy`：虚拟头节点
>     
> - `left`：最终指向待删除节点的前驱
>     
> - `right`：负责制造距离差
>     
> 
> 容易写错：
> 
> - `while right.next` 不是 `while right`
>     
> - 返回 `dummy.next`，不是 `head`
>     
> 
> ---
> 
> ## 3. 删除排序链表重复元素 I：重复只保留一个
> 
> ```python
> class Solution:
>     def deleteDuplicates(self, head):
>         if head is None:
>             return head
> 
>         cur = head
> 
>         while cur.next:
>             if cur.val == cur.next.val:
>                 cur.next = cur.next.next
>             else:
>                 cur = cur.next
> 
>         return head
> ```
> 
> 主流程：
> 
> - 当前节点和下一个节点相等，就跳过下一个节点
>     
> - 不相等时，`cur` 才向后移动
>     
> 
> 关键变量：
> 
> - `cur`：当前保留节点
>     
> 
> 容易写错：
> 
> - 删除节点后不能立刻 `cur = cur.next`
>     
> - 因为后面可能还有连续重复元素
>     
> 
> ---
> 
> ## 4. 删除排序链表重复元素 II：重复全部删除
> 
> ```python
> class Solution:
>     def deleteDuplicates(self, head):
>         dummy = ListNode(0, head)
>         cur = dummy
> 
>         while cur.next and cur.next.next:
>             val = cur.next.val
> 
>             if cur.next.next.val == val:
>                 while cur.next and cur.next.val == val:
>                     cur.next = cur.next.next
>             else:
>                 cur = cur.next
> 
>         return dummy.next
> ```
> 
> 主流程：
> 
> - `cur` 永远站在“待检查区间”的前一个节点
>     
> - 如果发现 `cur.next` 和 `cur.next.next` 重复，记录重复值 `val`
>     
> - 一次性删掉所有值等于 `val` 的节点
>     
> - 如果不重复，`cur` 才向后移动
>     
> 
> 关键变量：
> 
> - `dummy`：处理头节点被删除的情况
>     
> - `cur`：重复区间的前驱节点
>     
> - `val`：当前需要全部删除的重复值
>     
> 
> 容易写错：
> 
> - 外层条件必须是 `cur.next and cur.next.next`
>     
> - 内层删除时不能移动 `cur`
>     
> - 返回 `dummy.next`
>     

---

> [!warning]- 易错点
> 
> ## 1. 为什么需要 dummy node？
> 
> 如果头节点可能被删除，直接操作 `head` 会很麻烦。
> 
> 例如：
> 
> ```text
> 1 -> 1 -> 1 -> 2
> ```
> 
> 删除所有重复元素后，新的头节点应该是 `2`。
> 
> 如果没有 `dummy`，需要额外判断头节点变化。
> 
> 有了 `dummy`：
> 
> ```text
> dummy -> 1 -> 1 -> 1 -> 2
> ```
> 
> 最后统一返回：
> 
> ```python
> return dummy.next
> ```
> 
> ---
> 
> ## 2. 删除节点后，指针什么时候移动？
> 
> 删除后通常不要立刻移动当前指针。
> 
> 因为新的 `cur.next` 可能还是需要继续删除。
> 
> 例如：
> 
> ```text
> 1 -> 1 -> 1 -> 2
> ```
> 
> 删除第一个重复的 `1` 后，还要继续检查下一个 `1`。
> 
> ---
> 
> ## 3. 删除倒数第 n 个节点为什么 right 先走 n 步？
> 
> 目标是让 `left` 最后停在待删除节点的前一个节点。
> 
> 所以让 `right` 和 `left` 保持 `n` 个节点的距离。
> 
> 当 `right` 到达尾节点时，`left.next` 就是倒数第 `n` 个节点。
> 
> ---
> 
> ## 4. 删除给定节点为什么不能直接 node = node.next？
> 
> 因为 `node = node.next` 只是在修改局部变量引用。
> 
> 它不会改变链表中上一个节点的 `next` 指向。
> 
> 所以必须修改节点内部的值和指针：
> 
> ```python
> node.val = node.next.val
> node.next = node.next.next
> ```

---

> [!summary]- 复杂度
> 
> ## 删除给定节点
> 
> 时间复杂度：$O(1)$
> 
> 空间复杂度：$O(1)$
> 
> 为什么：只修改当前节点和下一个节点的值与指针。
> 
> ---
> 
> ## 删除倒数第 n 个节点
> 
> 时间复杂度：$O(n)$
> 
> 空间复杂度：$O(1)$
> 
> 为什么：快慢指针最多遍历链表一次。
> 
> ---
> 
> ## 删除排序链表重复元素 I
> 
> 时间复杂度：$O(n)$
> 
> 空间复杂度：$O(1)$
> 
> 为什么：每个节点最多被访问一次。
> 
> ---
> 
> ## 删除排序链表重复元素 II
> 
> 时间复杂度：$O(n)$
> 
> 空间复杂度：$O(1)$
> 
> 为什么：虽然有内层 `while`，但每个节点最多被删除或跳过一次。

---

## 一句话总结

链表删除题的本质是找到待删除节点的前驱节点，并通过改 `next` 指针跳过目标节点；如果头节点可能变化，就用 `dummy node` 统一边界。

## 模板归纳

> [!tip]- 链表删除模板  
> 什么时候想到链表删除模板：
> 
> - 题目要求删除某个节点
>     
> - 需要处理头节点可能被删除
>     
> - 需要删除倒数第 `n` 个节点
>     
> - 需要删除连续重复节点
>     
> 
> 核心套路：
> 
> ```python
> dummy = ListNode(0, head)
> cur = dummy
> 
> while cur.next:
>     if 需要删除 cur.next:
>         cur.next = cur.next.next
>     else:
>         cur = cur.next
> 
> return dummy.next
> ```
> 
> 面试记忆点：
> 
> - 删除当前节点：改值加改指针
>     
> - 删除头节点：用 `dummy`
>     
> - 删除倒数第 `n` 个节点：快慢指针保持距离
>     
> - 删除排序链表重复节点：重复元素一定连续
>
