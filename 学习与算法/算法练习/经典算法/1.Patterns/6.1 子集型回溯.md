# 子集型回溯

## 解决什么问题

从集合中**任选若干个**元素（可以一个都不选），元素之间没有顺序——子集 Subset、组合、任意切分方案都属于这一类，方案总数是 $2^n$ 量级。

对照 [[6.0 回溯型算法]] 里的 17 题：那是「必选型」，每一位**必须**填一个字母；子集型的每个元素**可选可不选**，因此多出「不选」这条分支，也因此有两种建树视角。

## 视角一：输入视角「选 / 不选」

站在**每个元素**的角度问：`nums[i]` 要不要进当前子集？每个元素二选一，树是标准二叉树，**只有叶子是答案**。

> [!tip]- 核心思路
> 
> `dfs(i)`：`nums[0..i-1]` 的选/不选已经决定好（结果记在 `path` 里），我负责**从第 $i$ 个数开始把剩下的决定做完**。
> 
> - 分支一「不选」：什么都不动，直接 `dfs(i+1)`——没借东西，自然不用还。
> - 分支二「选」：`append` → 递归 → `pop`，收支平衡。
> 
> 空集的由来：一路全走「不选」分支，到底时 `path` 还是空的——第一个被收进 `ans` 的就是 `[]`，不是凭空冒出来的。

> [!success]- 78. 子集（输入视角）
> 
> ```python
> class Solution:
>     def subsets(self, nums: List[int]) -> List[List[int]]:
>         ans = []
>         path = []
>         n = len(nums)
>         def dfs(i):
>             if i == n:
>                 ans.append(path.copy())   # 只有叶子收答案，必须拷贝
>                 return
>             dfs(i + 1)                    # 分支一：不选 nums[i]
>             path.append(nums[i])          # 分支二：选 nums[i]
>             dfs(i + 1)
>             path.pop()                    # 恢复现场，与 append 成对
>         dfs(0)
>         return ans
> ```
> 
> - 主流程：两条分支穷尽「选 / 不选」，`i == n` 收答案。
> - 关键变量：`path` 追加式使用，`append`/`pop` 成对夹住递归——见 [[状态恢复]]。
> - 易错位置：`path.copy()` 不能写成 `path`（引用坑，见 [[Python_赋值与拷贝]]）。

> [!example]- 示例推演：nums = [1, 2]
> 
> ```text
> dfs(0)  path=[]
> ├─ dfs(1)  path=[]            ← 不选 1
> │  ├─ dfs(2)  收 []
> │  ├─ append(2) → [2]         ← 选 2
> │  ├─ dfs(2)  收 [2]
> │  └─ pop() → []
> ├─ append(1) → [1]            ← 选 1
> ├─ dfs(1)  path=[1]
> │  ├─ dfs(2)  收 [1]
> │  ├─ append(2) → [1,2]       ← 选 2
> │  ├─ dfs(2)  收 [1,2]
> │  └─ pop() → [1]
> └─ pop() → []
> ```
> 
> 结果 `[[], [2], [1], [1,2]]`，恰好 $2^2$ 个。

## 视角二：答案视角「枚举选哪个」

站在**答案**的角度问：当前子集的**下一个**元素选谁？为了不重复，只能从 $i$ 往后选（`j in [i, n)`）。这棵树上**每个节点都是一个合法子集**，所以进门先收答案。

> [!tip]- 核心思路
> 
> `dfs(i)`：`path` 已经是一个合法子集，先收下它；然后枚举下一个加入的元素 `nums[j]`（$j \ge i$），加入后从 $j+1$ 继续。
> 
> - 「只往后选」保证同一个子集只会按下标递增的顺序被构造一次，天然不重复。
> - 不需要显式的「不选」分支：for 枚举完（或一开始就不进循环）就等于「后面都不选了」。

> [!success]- 78. 子集（答案视角）
> 
> ```python
> class Solution:
>     def subsets(self, nums: List[int]) -> List[List[int]]:
>         ans = []
>         path = []
>         n = len(nums)
>         def dfs(i):
>             ans.append(path.copy())       # 每个节点都是答案，进门先收
>             if i == n:                    # 可省略：i==n 时 for 本身为空
>                 return
>             for j in range(i, n):         # 枚举下一个选谁
>                 path.append(nums[j])
>                 dfs(j + 1)                # 注意是 j+1，不是 i+1
>                 path.pop()
>         dfs(0)
>         return ans
> ```
> 
> - 原稿此处写的是 `path.append(nums[i])`——笔误：循环变量是 `j`，写 `nums[i]` 会让同一层反复追加同一个数，产生 `[1, 1]` 这类非法子集。
> - 易错位置：递归入口是 `dfs(j + 1)`；收答案在循环**之前**。

## 两种视角怎么选

| 维度 | 输入视角「选/不选」 | 答案视角「枚举选哪个」 |
| --- | --- | --- |
| 每个节点分叉 | 固定 2 叉 | $n - i$ 叉 |
| 答案在哪里 | 只有叶子（`i == n`） | 每个节点 |
| 收答案时机 | 终止条件里 | 进门第一行 |
| 需要显式终止 | 需要 | 不需要（for 为空自然结束） |

判断标准一句话：**问自己「树上每个节点都是合法答案吗」**——是就用答案视角（进门收）；只有完整方案才合法就在 `i == n` 收（两种视角都可以）。

## 典型变体

### 变体一：90. 子集 II（含重复元素，原稿未覆盖）

相对 78「什么不变」：答案视角骨架原样保留。「什么改变」：先排序让相同元素相邻，再加一行**同层去重**——同一层里再次遇到相同的数直接跳过。

> [!success]- 90. 子集 II
> 
> ```python
> class Solution:
>     def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
>         nums.sort()                            # 去重前提：相同元素相邻
>         ans = []
>         path = []
>         n = len(nums)
>         def dfs(i):
>             ans.append(path.copy())
>             for j in range(i, n):
>                 if j > i and nums[j] == nums[j - 1]:
>                     continue                   # 同层去重：跳过本层的重复候选
>                 path.append(nums[j])
>                 dfs(j + 1)
>                 path.pop()
>         dfs(0)
>         return ans
> ```
> 
> - 易错位置：条件是 `j > i`（同一层的后续重复），不是 `j > 0`——写成 `j > 0` 会把「跨层连续选相同元素」也误杀，`[1, 1]` 这种合法子集就丢了。

### 变体二：131. 分割回文串

「以逗号为界，考虑选还是不选」——把 $n-1$ 个切分点看成集合，对切分点做子集型选择；等价地用答案视角：枚举当前段的右端点 $j$，段 `s[i..j]` 是回文才递归——这一判断就是剪枝 Pruning，见 [[6.0 回溯型算法]]。

> [!success]- 131. 分割回文串（修正版）
> 
> ```python
> class Solution:
>     def partition(self, s: str) -> List[List[str]]:
>         ans = []
>         path = []
>         n = len(s)
>         def dfs(i):
>             if i == n:                    # 切完整个字符串才是合法方案
>                 ans.append(path.copy())
>                 return
>             for j in range(i, n):         # 枚举当前段的右端点
>                 t = s[i:j + 1]
>                 if t == t[::-1]:          # 回文才继续（剪枝）
>                     path.append(t)
>                     dfs(j + 1)
>                     path.pop()
>         dfs(0)
>         return ans
> ```
> 
> 原稿代码有两处 bug，都源于照搬 78 答案视角的骨架：
> 
> 1. `path.append(nums[i])`——本题没有 `nums`，追加的应当是当前切出的子串 `t`。
> 2. `ans.append(path.copy())` 写在了 dfs 开头——78 里每个节点都是合法子集，但**本题只有把整个字符串切完（`i == n`）才是合法方案**，放开头会把半成品切法也收进去。
> 
> `t == t[::-1]` 判回文的语法见 [[Python_字符串常用操作]]；段长、判断次数多时可换相向双指针原地比较，见 [[1.0 相向双指针-多数之和]]。

## 易错点

> [!warning]- 易错点
> 
> - **收答案时机搞混**：先问「每个节点都是合法答案吗」。78 是（进门收），131 不是（只在 `i == n` 收）。照搬模板不想这个问题，就会重演原稿 131 的 bug。
> - **`path.copy()` 写成 `path`**：存引用不存快照，`ans` 里全变成最后一条路径的最终状态，见 [[Python_赋值与拷贝]]。
> - **`dfs(j + 1)` 写成 `dfs(i + 1)`**：答案视角推进的基准是刚选中的 `j`，写 `i + 1` 会重复选取已考虑过的元素。
> - **90 去重条件写错**：`j > i` 是同层去重；`j > 0` 会误杀跨层的合法重复。
> - **append / pop 不成对**：残留元素污染兄弟分支，见 [[状态恢复]]。

## 复杂度

> [!summary]- 复杂度
> 
> - 78 / 90：子集共 $2^n$ 个，每个拷贝花 $O(n)$ → 时间 $O(n \cdot 2^n)$；空间 $O(n)$（递归栈 + `path`，不计答案）。
> - 131：$n-1$ 个间隔各有切 / 不切两种 → 至多 $2^{n-1}$ 种切法，每种回文判断与拷贝共 $O(n)$ → 时间 $O(n \cdot 2^n)$；空间 $O(n)$。

## 一句话总结

子集型 = 每个元素独立决定去留：输入视角问「第 $i$ 个要不要」（叶子是答案），答案视角问「下一个选谁」（节点都是答案），收答案时机由「节点是否合法」决定。

## 模板归纳

**触发信号**：

- 「返回所有子集 / 组合 / 切分方案」
- 每个元素可选可不选，方案数 $2^n$ 量级
- 元素无顺序要求（有顺序要求的是排列型，另开专题）

**判断依据**：树上每个节点都合法 → 答案视角进门收；只有完整方案合法 → `i == n` 收。含重复元素 → 排序 + 同层去重 `j > i and nums[j] == nums[j-1]`。
