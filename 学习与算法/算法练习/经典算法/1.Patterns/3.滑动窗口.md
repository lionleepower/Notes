# 209. 长度最小的子数组

## 1. 题目要解决什么问题？

给定一个正整数数组 `nums` 和目标值 `target`，要求找到一个连续子数组，使其元素和大于等于 `target`。  
输出满足条件的最短子数组长度。  
如果不存在这样的子数组，返回 `0`。

例子：

```python
target = 7
nums = [2, 3, 1, 2, 4, 3]
```

最短满足条件的是 `[4, 3]`，长度为 `2`。

## 2. 核心思路

这道题是典型的 `Sliding Window`。

因为 `nums[i]` 都是正整数，所以窗口右端扩张时，窗口和只会变大；左端收缩时，窗口和只会变小。  
这就满足单调性，可以用双指针维护一个连续窗口 `[left, right]`。

核心过程：

1. 右指针 `right` 不断向右扩张，加入 `nums[right]`
    
2. 当窗口和 `window_sum >= target` 时，说明当前窗口合法
    
3. 尝试移动 `left` 收缩窗口，寻找更短答案
    

## 3. 关键公式 / 判断条件

窗口长度：

$$  
right - left + 1  
$$

窗口合法条件：

$$  
window_sum \ge target  
$$

更新答案：

$$  
ans = \min(ans, right - left + 1)  
$$

## 4. 代码模板

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: list[int]) -> int:
        n = len(nums)
        left = 0
        window_sum = 0
        ans = n + 1

        for right, x in enumerate(nums):
            window_sum += x

            # 只要当前窗口合法，就尝试收缩左边界
            while window_sum >= target:
                ans = min(ans, right - left + 1)
                window_sum -= nums[left]
                left += 1

        return ans if ans <= n else 0
```

## 5. 复杂度分析

时间复杂度：

$$  
O(n)  
$$

空间复杂度：

$$  
O(1)  
$$

每个元素最多被右指针加入一次，被左指针移出一次，所以总时间是线性的。

## 6. 核心结论

- 正整数数组满足单调性，因此可以用 `Sliding Window`
    
- 右指针负责扩张窗口，左指针负责缩小窗口
    
- 当 `window_sum >= target` 时，窗口合法
    
- 合法后要立刻尝试收缩，才能得到最短长度
    
- 窗口长度永远是 `right - left + 1`
    

## 7. 常见误区

- 忘记题目要求的是连续子数组，不是任意选元素
    
- 只在 `if window_sum >= target` 时更新一次，导致没有充分收缩窗口
    
- 忘记在移动 `left` 前先减去 `nums[left]`
    
- 如果不存在答案，要返回 `0`，不是返回 `n + 1`

# 713. 乘积小于 K 的子数组

## 1. 题目要解决什么问题？

给定一个正整数数组 `nums` 和整数 `k`，要求统计有多少个连续子数组的乘积严格小于 `k`。  
输出满足条件的子数组数量。

例子：

```python
nums = [10, 5, 2, 6]
k = 100
```

满足条件的子数组有：

```python
[10], [5], [2], [6], [10, 5], [5, 2], [2, 6], [5, 2, 6]
```

答案是 `8`。

## 2. 核心思路

这道题也是 `Sliding Window`。

因为数组元素都是正整数，所以右端加入新元素时，乘积只会变大；左端移出元素时，乘积只会变小。  
因此可以维护一个乘积小于 `k` 的窗口 `[left, right]`。

关键不是只判断当前整个窗口，而是统计所有以 `right` 结尾的合法子数组。

当窗口 `[left, right]` 合法后：

```python
nums[left:right+1]
```

所有以 `right` 结尾的子数组都合法：

```python
nums[right:right+1]
nums[right-1:right+1]
...
nums[left:right+1]
```

数量正好是：

$$  
right - left + 1  
$$

例如：

```python
nums = [10, 5, 2, 6]
left = 1
right = 3
```

窗口是：

```python
[5, 2, 6]
```

以 `right = 3` 结尾的合法子数组有：

```python
[6]
[2, 6]
[5, 2, 6]
```

一共：

$$  
3 - 1 + 1 = 3  
$$

## 3. 关键公式 / 判断条件

窗口合法条件：

$$  
product < k  
$$

窗口不合法条件：

$$  
product \ge k  
$$

每次统计以 `right` 结尾的合法子数组数量：

$$  
ans += right - left + 1  
$$

特殊情况：

$$  
k \le 1  
$$

因为 `nums[i] >= 1`，不存在乘积小于等于 `0` 或小于 `1` 的正整数子数组，所以直接返回 `0`。

## 4. 代码模板

```python
class Solution:
    def numSubarrayProductLessThanK(self, nums: list[int], k: int) -> int:
        if k <= 1:
            return 0

        left = 0
        product = 1
        ans = 0

        for right, x in enumerate(nums):
            product *= x

            # 如果乘积不合法，就收缩左边界
            while product >= k:
                product //= nums[left]
                left += 1

            # 统计所有以 right 结尾的合法子数组
            ans += right - left + 1

        return ans
```

## 5. 复杂度分析

时间复杂度：

$$  
O(n)  
$$

空间复杂度：

$$  
O(1)  
$$

每个元素最多进入窗口一次、移出窗口一次，因此总时间复杂度是 $O(n)$。

## 6. 核心结论

- 这题统计的是连续子数组数量，不是最长或最短长度
    
- 窗口维护的是当前子数组的乘积 `product`
    
- 当 `product >= k` 时，窗口不合法，需要移动 `left`
    
- 每次窗口合法后，新增答案是 `right - left + 1`
    
- `ans += right - left + 1` 的含义是统计所有以 `right` 结尾的合法子数组
    

## 7. 常见误区

- 忘记处理 `k <= 1`，导致死循环或错误答案
    
- 不理解为什么是 `ans += right - left + 1`
    
- 把题目看成求最长子数组，而不是统计数量
    
- 收缩窗口时忘记更新 `product`

# 滑动窗口 Sliding Window 总结

## 1. 适用场景

`Sliding Window` 主要用于处理连续区间问题：

- 连续子数组 `subarray`
    
- 连续子串 `substring`
    
- 最长 / 最短区间
    
- 满足条件的区间数量
    
- 固定长度窗口
    

看到这些关键词，可以优先考虑滑动窗口：

```text
substring
subarray
continuous
longest
shortest
at most k
without repeating
```

## 2. 统一模板

```python
left = 0

for right in range(len(nums)):
    # 1. 扩张窗口
    add(nums[right])

    # 2. 如果窗口不合法，收缩左边界
    while window_invalid:
        remove(nums[left])
        left += 1

    # 3. 更新答案
    update_result()
```

## 3. 三条核心规则

- 右端加入谁，就 `add(nums[right])`
    
- 左端移出谁，就 `remove(nums[left])`
    
- 窗口长度永远是：
    

$$  
right - left + 1  
$$

## 4. 常见类型

### 最长窗口

窗口必须保持合法。

```python
for right in range(n):
    add(nums[right])

    while window_invalid:
        remove(nums[left])
        left += 1

    ans = max(ans, right - left + 1)
```

### 最短窗口

窗口先扩张到满足条件，再尽量收缩。

```python
for right in range(n):
    add(nums[right])

    while window_valid:
        ans = min(ans, right - left + 1)
        remove(nums[left])
        left += 1
```

### 统计子数组数量

统计所有以 `right` 结尾的合法子数组。

```python
for right in range(n):
    add(nums[right])

    while window_invalid:
        remove(nums[left])
        left += 1

    ans += right - left + 1
```

### 固定长度窗口

窗口长度固定为 `k`。

```python
window_sum = 0

for right in range(len(nums)):
    window_sum += nums[right]

    if right >= k:
        window_sum -= nums[right - k]

    if right >= k - 1:
        update_answer()
```

## 5. Hash Map 什么时候用？

当窗口里需要维护频率、出现位置或是否存在时，常用 `Hash Map`。

常见情况：

- 字符出现次数：`Counter`
    
- 字符最后出现位置：`dict`
    
- 字符是否存在：`set`
    

例如无重复字符子串：

```python
seen = set()
```

用 `set` 维护当前窗口中有哪些字符。

## 6. 为什么滑动窗口是 O(n)？

因为：

- `right` 只会从左到右走一遍
    
- `left` 也只会从左到右走一遍
    
- 每个元素最多被加入窗口一次、移出窗口一次
    

所以总复杂度是：

$$  
O(n)  
$$
