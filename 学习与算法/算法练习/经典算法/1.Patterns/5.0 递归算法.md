# 144 / 94 / 145. 二叉树的前序 / 中序 / 后序遍历

## 题目

按前序（根左右）、中序（左根右）、后序（左右根）三种顺序访问二叉树的每个节点，返回节点值序列。

## 思路

"前 / 中 / 后"指的不是左右子树的顺序，而是**根节点被访问的时机**——左子树永远先于右子树，只有"根"在挪位置。递归写法极简（只是移动一行代码），真正的面试考点是**迭代写法**：用显式栈手动模拟系统递归栈。
![[Pasted image 20260711120349.png]]
递归最反直觉的地方:你不是在"扫描"整棵树一次,而是在写一份**可以套用在任意节点上的通用规则**,然后让 Python 自动把这份规则在每个节点上都跑一遍。

> [!tip]- 核心思路：三者只差"根在哪一步处理"
> 
> 三种遍历的骨架完全相同，唯一区别是"访问当前节点"这一行插在两次递归调用的哪个位置：
> 
> - **前序 Preorder = 根左右**：先处理当前节点，再下钻。**自顶向下**，信息从父传子。
> - **中序 Inorder = 左根右**：处理夹在左右递归之间。BST 的中序序列**严格递增**。
> - **后序 Postorder = 左右根**：先拿到左右子树结果，再处理当前。**自底向上**，信息从子汇报给父。
> 
> 为什么要区分（面试触发点）：
> 
> - 需要**先记录再展开**（序列化、复制树、路径前缀）→ 前序。
> - 涉及 BST **有序性 / 第 K 小 / 相邻差** → 中序。
> - 当前节点答案**依赖子树答案**（高度、直径、删树、LCA）→ 后序。

> [!example]- 示例推演
> 
> ```text
>       1
>      / \
>     2   3
>    / \
>   4   5
> ```
> 
> - 前序（根左右）：`1 2 4 5 3`
> - 中序（左根右）：`4 2 5 1 3`
> - 后序（左右根）：`4 5 2 3 1`
> 
> 观察：三行里 `4 5` 的相对位置随"根 2 的时机"前后移动，但 `4` 始终在 `5` 前——左先右后不变。

> [!success]- 递归实现（统一骨架，挪一行即可）
> 
> ```python
> def dfs(node, res):
>     if node is None:
>         return
>     # 前序：res.append(node.val)  ← 放这里
>     dfs(node.left, res)
>     # 中序：res.append(node.val)  ← 放这里
>     dfs(node.right, res)
>     # 后序：res.append(node.val)  ← 放这里
> ```
> 
> ```cpp
> void dfs(TreeNode* node, vector<int>& res) {
>     if (node == nullptr) return;
>     // 前序：res.push_back(node->val);  ← 放这里
>     dfs(node->left, res);
>     // 中序：res.push_back(node->val);  ← 放这里
>     dfs(node->right, res);
>     // 后序：res.push_back(node->val);  ← 放这里
> }
> ```
> 
> - 主流程：空节点直接返回；三种遍历唯一差异是那一行 append 的位置。
> - 易错：忘记空节点 return 会导致空指针 / `None.val` 报错。

> [!success]- 迭代实现（面试重点，用栈模拟）
> 
> **前序**：弹出即访问，压栈时**先右后左**（栈后进先出，才能让左先出）。
> 
> ```python
> def preorder(root):
>     if not root: return []
>     res, stack = [], [root]
>     while stack:
>         node = stack.pop()
>         res.append(node.val)                     # 访问根
>         if node.right: stack.append(node.right)  # 先压右
>         if node.left:  stack.append(node.left)   # 后压左 → 左先出
>     return res
> ```
> 
> ```cpp
> vector<int> preorder(TreeNode* root) {
>     vector<int> res;
>     if (!root) return res;
>     stack<TreeNode*> st; st.push(root);
>     while (!st.empty()) {
>         TreeNode* node = st.top(); st.pop();
>         res.push_back(node->val);
>         if (node->right) st.push(node->right);   // 先右
>         if (node->left)  st.push(node->left);    // 后左
>     }
>     return res;
> }
> ```
> 
> **中序**：指针一路向左压栈，弹出访问后转向右子树。
> 
> ```python
> def inorder(root):
>     res, stack, cur = [], [], root
>     while cur or stack:
>         while cur:                # 左链全部入栈
>             stack.append(cur)
>             cur = cur.left
>         cur = stack.pop()         # 最左节点出栈
>         res.append(cur.val)       # 访问
>         cur = cur.right           # 转向右子树
>     return res
> ```
> 
> **后序**：最省脑的写法——按"根右左"做前序，最后整体反转，即得"左右根"。
> 
> ```python
> def postorder(root):
>     if not root: return []
>     res, stack = [], [root]
>     while stack:
>         node = stack.pop()
>         res.append(node.val)                     # 根
>         if node.left:  stack.append(node.left)   # 先压左
>         if node.right: stack.append(node.right)  # 后压右 → 序列为 根右左
>     return res[::-1]                             # 反转 → 左右根
> ```
> 
> - C++ 中序 / 后序结构与 Python 完全对应（`stack<TreeNode*>` + 反转用 `reverse(res.begin(), res.end())`）。
> - 关键变量：`stack` 存待处理节点；中序额外用 `cur` 指针驱动"下沉左链"。

> [!warning]- 易错点
> 
> - **搞反根的位置**：记死"前 / 中 / 后 = 根在前 / 中 / 后"，左右顺序永远是**左先右后**。
> - **前序迭代压栈顺序**：必须**先压右再压左**，压反了输出就成了"根右左"。
> - **中序迭代漏压左链**：进入循环要先 `while cur` 把左边一路压完，否则顺序错乱。
> - **后序反转法搞错源序列**：是拿"根右左"反转得"左右根"，不是拿"根左右"反转。
> - **空节点处理**：递归里 `if node is None: return`，迭代里入栈前判 `if node.left/right`，否则压入 `None` 出错。

> [!summary]- 复杂度
> 
> - 时间：$O(n)$ —— 每个节点恰好入栈 / 访问一次。
> - 空间：$O(h)$ —— 栈深等于树高；最坏（链状）$O(n)$，平衡时 $O(\log n)$。
> - 进阶：Morris 遍历可做到 $O(1)$ 额外空间（借空指针建临时线索），面试提一句即可，实现较绕。

## 一句话总结

"前中后"说的是**根被访问的时机**，左永远在右之前；递归只需挪一行，迭代靠栈模拟（后序 = 根右左再反转）。

## 模板归纳

> [!tip]- 什么时候该想到哪种遍历
> 
> **触发信号 → 选择**：
> 
> 1. 当前节点的处理**不依赖子树结果**、只依赖祖先信息（前缀路径、深度、复制结构）→ **前序（自顶向下）**。
> 2. 出现"BST + 有序 / 第 K 小 / 相邻差值"→ **中序**（直接利用严格递增，维护 `pre`）。
> 3. 当前节点答案 = 左右子树答案的加工结果（高度、直径、是否平衡、删除、LCA）→ **后序（自底向上）**。
> 
> **判断依据一句话**：信息往下传用前序，往上收用后序，要有序就中序。


>一个简单的中序遍历：
```python
# Definition for a binary tree node.
# class TreeNode
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        ans=[]
        if root:
            ans+=self.inorderTraversal(root.left)
            ans.append(root.val)
            ans+=self.inorderTraversal(root.right)
        return ans
```

**核心思路**：每次递归调用 `inorderTraversal(node)`，都返回"以 node 为根的这棵子树"的完整中序序列（一个 list）。整个函数依赖一个递归假设：

- 如果 `inorderTraversal(root.left)` 已经能正确返回左子树的中序结果
- 那么当前答案就是：左子树结果 + 根节点值 + 右子树结果

这正好对应"左根右"的定义，而空节点作为递归的**终止条件**（base case），返回空 list `[]`，天然不会往结果里添任何东西。

### 逐步模拟

用这棵树举例：

text

```text
    1
   / \
  2   3
 / \
4   5
```

调用栈展开（从外到内）：

```
inorderTraversal(1)
├─ ans += inorderTraversal(2)
│         ├─ ans += inorderTraversal(4)
│         │         ├─ ans += inorderTraversal(None) → []
│         │         ├─ ans.append(4)      → [4]
│         │         ├─ ans += inorderTraversal(None) → []
│         │         └─ return [4]
│         ├─ ans.append(2)                → [4, 2]
│         ├─ ans += inorderTraversal(5)
│         │         └─ 同理 → [5]
│         │         → ans = [4, 2, 5]
│         └─ return [4, 2, 5]
├─ ans.append(1)                          → [4, 2, 5, 1]
├─ ans += inorderTraversal(3)
│         └─ 无子节点 → return [3]
│         → ans = [4, 2, 5, 1, 3]
└─ return [4, 2, 5, 1, 3]
```

最终结果 `[4, 2, 5, 1, 3]`，正是这棵树的中序序列（左→根→右)。
