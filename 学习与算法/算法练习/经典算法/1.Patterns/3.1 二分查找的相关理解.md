# 题目

给定多台机器的合金配方、库存、金属价格和预算，求最多能制造多少份合金。

---

## 思路

这题不是在数组里找元素，而是在“答案范围”里找最大可行值。  
如果能制造 `num` 份合金，那么一定也能制造更少份。  
如果不能制造 `num` 份合金，那么一定不能制造更多份。  
所以 `check(num)` 具有单调性，可以用二分答案 `Binary Search on Answer`。

---

> [!tip]- 核心思路
> 
> ## 1. 为什么是二分答案？
> 
> 题目要求：
> 
> ```text
> 最多能制造多少份合金
> ```
> 
> 可以把答案看成一个整数范围：
> 
> ```text
> 0, 1, 2, 3, ..., upper
> ```
> 
> 对于某个数量 `num`，只需要判断：
> 
> ```text
> 预算是否足够制造 num 份合金？
> ```
> 
> 这个判断函数记作：
> 
> ```python
> check(num)
> ```
> 
> 如果 `check(num) == True`，说明 `num` 份可行。  
> 如果 `check(num) == False`，说明 `num` 份不可行。
> 
> 单调性：
> 
> ```text
> True True True False False False
> ```
> 
> 目标：
> 
> ```text
> 找到最后一个 True
> ```
> 
> ---
> 
> ## 2. check(num) 怎么写？
> 
> 对某台机器配方 `comp`，制造 `num` 份合金时，第 `i` 种金属总需求是：
> 
> $$  
> comp[i] \times num  
> $$
> 
> 已有库存：
> 
> $$  
> stock[i]  
> $$
> 
> 需要额外购买：
> 
> $$  
> \max(0, comp[i] \times num - stock[i])  
> $$
> 
> 购买花费：
> 
> $$  
> \max(0, comp[i] \times num - stock[i]) \times cost[i]  
> $$
> 
> 总花费：
> 
> $$  
> money = \sum_i \max(0, comp[i] \times num - stock[i]) \times cost[i]  
> $$
> 
> 判断条件：
> 
> $$  
> money \le budget  
> $$
> 
> 如果成立，说明可以制造 `num` 份合金。
> 
> ---
> 
> ## 3. 为什么每台机器要分别算？
> 
> 每台机器的配方不同：
> 
> ```python
> composition = [[...], [...], ...]
> ```
> 
> 同样制造 `num` 份，不同机器需要的金属数量不同，花费也不同。
> 
> 所以流程是：
> 
> ```text
> 枚举每台机器
> 对当前机器二分最大可行数量
> 所有机器结果取最大值
> ```

---

> [!example]- 示例推演
> 
> ```python
> n = 3
> k = 2
> budget = 15
> composition = [[1, 1, 1], [1, 1, 10]]
> stock = [0, 0, 0]
> cost = [1, 2, 3]
> ```
> 
> 对第一台机器：
> 
> ```text
> comp = [1, 1, 1]
> 制造 num 份需要：
> 金属 1：num 个
> 金属 2：num 个
> 金属 3：num 个
> ```
> 
> 总花费：
> 
> $$  
> num \times 1 + num \times 2 + num \times 3 = 6num  
> $$
> 
> 预算 `15` 下最多制造：
> 
> ```text
> num = 2
> ```
> 
> 对第二台机器：
> 
> ```text
> comp = [1, 1, 10]
> ```
> 
> 每份花费：
> 
> $$  
> 1 + 2 + 10 \times 3 = 33  
> $$
> 
> 一份都超预算。
> 
> 最终答案：
> 
> ```python
> 2
> ```

---

> [!success]- Python 实现
> 
> ```python
> class Solution:
>     def maxNumberOfAlloys(
>         self,
>         n: int,
>         k: int,
>         budget: int,
>         composition: list[list[int]],
>         stock: list[int],
>         cost: list[int]
>     ) -> int:
>         ans = 0
> 
>         upper = min(stock) + budget + 1
> 
>         for comp in composition:
> 
>             def check(num: int) -> bool:
>                 money = 0
> 
>                 for have, need, price in zip(stock, comp, cost):
>                     required = need * num
> 
>                     if required > have:
>                         money += (required - have) * price
> 
>                         if money > budget:
>                             return False
> 
>                 return True
> 
>             left = ans
>             right = upper
> 
>             while left + 1 < right:
>                 mid = (left + right) // 2
> 
>                 if check(mid):
>                     left = mid
>                 else:
>                     right = mid
> 
>             ans = left
> 
>         return ans
> ```
> 
> 代码结构：
> 
> - `check(num)`：判断当前机器能否制造 `num` 份合金
>     
> - `money`：制造 `num` 份时需要额外购买金属的总费用
>     
> - `zip(stock, comp, cost)`：同步遍历库存、配方和价格
>     
> - `left`：当前已知可行答案
>     
> - `right`：当前已知不可行答案
>     
> - `ans`：所有机器中的最大可行数量
>     
> 
> 为什么用开区间 `(left, right)`：
> 
> ```text
> left 可行
> right 不可行
> ```
> 
> 每次二分后仍然保持这个含义。
> 
> 最后返回：
> 
> ```python
> left
> ```
> 
> 因为要找最后一个可行值。

---

> [!warning]- 易错点
> 
> ## 1. 没有先定义清楚 check(num)
> 
> 二分答案最重要的是先写清楚：
> 
> ```text
> check(num) = 能不能制造 num 份合金
> ```
> 
> 如果 `check` 含义不清楚，`left` 和 `right` 的移动方向就容易写反。
> 
> ---
> 
> ## 2. 把二分答案和二分数组下标混在一起
> 
> 这题二分的不是数组位置，而是答案：
> 
> ```text
> 最多制造多少份
> ```
> 
> 所以 `mid` 表示制造数量，不是数组下标。
> 
> ---
> 
> ## 3. 忘记减去已有库存
> 
> 错误理解：
> 
> ```text
> 花费 = 配方需求 × 数量 × 单价
> ```
> 
> 正确是只买缺少的部分：
> 
> $$  
> \max(0, need \times num - have) \times price  
> $$
> 
> ---
> 
> ## 4. 只算了一台机器
> 
> 每台机器配方不同，必须遍历所有 `composition`：
> 
> ```python
> for comp in composition:
> ```
> 
> 然后对每台机器分别二分。
> 
> ---
> 
> ## 5. 求最大可行值时返回了 right
> 
> 在最大化模板中：
> 
> ```text
> left 可行
> right 不可行
> ```
> 
> 所以最后应该返回：
> 
> ```python
> return left
> ```
> 
> 不是 `right`。
> 
> ---
> 
> ## 6. 上界 upper 设得太小
> 
> 二分答案必须保证：
> 
> ```text
> right 是不可行边界
> ```
> 
> 如果 `upper` 太小，真实答案可能被截断。
> 
> 保险写法可以用更宽的上界，例如：
> 
> ```python
> upper = min(stock) + budget + 1
> ```
> 
> 或根据题目数据范围设置更大的右边界。
> 
> ---
> 
> ## 7. 忘记提前剪枝
> 
> 当花费已经超过预算：
> 
> ```python
> if money > budget:
>     return False
> ```
> 
> 后面继续计算没有意义。
> 
> 提前返回可以减少无效计算。

---

> [!summary]- 复杂度  
> 设：
> 
> - $n$：金属种类数
>     
> - $k$：机器数量
>     
> - $U$：二分答案上界
>     
> 
> 时间复杂度：
> 
> $$  
> O(k \cdot n \cdot \log U)  
> $$
> 
> 为什么：
> 
> - 每台机器都要二分答案
>     
> - 每次 `check(num)` 要遍历 `n` 种金属
>     
> - 二分次数是 $\log U$
>     
> 
> 空间复杂度：
> 
> $$  
> O(1)  
> $$
> 
> 为什么：
> 
> 只使用了常量级变量，不考虑输入数组。

## 一句话总结

本题本质是在答案范围里二分最大可行值，每次用 `check(num)` 判断预算是否能支撑制造 `num` 份合金。

---

## 模板归纳

## 二分答案 Binary Search on Answer

适合：

- 求最大可行值
    
- 求最小可行值
    
- 答案是一个整数范围
    
- 能写出 `check(x)`
    
- `check(x)` 具有单调性
    

核心流程：

```text
1. 明确答案是什么
2. 写 check(x)
3. 判断 check(x) 是否单调
4. 选择最大化模板或最小化模板
5. 返回正确边界
```

---

### 最大可行值模板

适合：

```text
True True True False False
```

目标：

```text
找最后一个 True
```

模板：

```python
left = 0
right = upper

while left + 1 < right:
    mid = (left + right) // 2

    if check(mid):
        left = mid
    else:
        right = mid

return left
```

含义：

- `left`：当前已知可行
    
- `right`：当前已知不可行
    

---

### 最小可行值模板

适合：

```text
False False False True True
```

目标：

```text
找第一个 True
```

模板：

```python
left = 0
right = upper

while left + 1 < right:
    mid = (left + right) // 2

    if check(mid):
        right = mid
    else:
        left = mid

return right
```

含义：

- `left`：当前已知不可行
    
- `right`：当前已知可行
    

---

### 条件反射

```text
看到“最多 / 最大 / 最少 / 最小” + 答案范围巨大
=> 先想二分答案
```

```text
能造 x 个，则一定能造更少
不能造 x 个，则一定不能造更多
=> 找最大可行值
```

```text
x 时间内能完成，则更长时间也能完成
x 速度能完成，则更快速度也能完成
=> 找最小可行值
```
