# 二叉树最大深度、最小深度与路径总和：递归 DFS

给定一棵二叉树，分别求它的最大深度、最小深度，并判断是否存在一条从根节点到叶子节点的路径，使路径和等于目标值。

---

## 思路

二叉树天然适合递归，因为每棵树都可以拆成左子树和右子树。  
最大深度是找最长路径，左右子树取较大值。  
最小深度是找最近叶子节点，左右子树取较小值，但要注意空子树不能参与取最小值。  
路径总和是判断某条根到叶子的完整路径是否满足条件，本质也是 DFS 递归搜索。

---

> [!tip]- 核心思路
> ## 最大深度 Max Depth
>
> 最大深度表示：从根节点到最远叶子节点的节点数。
>
> 对于任意节点：
>
> $$
> maxDepth(root)=max(maxDepth(root.left), maxDepth(root.right))+1
> $$
>
> 为什么可以直接取 `max`？
>
> 因为空子树深度是 `0`，不会影响最大值。
>
> ---
>
> ## 最小深度 Min Depth
>
> 最小深度表示：从根节点到最近叶子节点的节点数。
>
> 注意：叶子节点必须是左右孩子都为空的节点。
>
> 所以不能简单写成：
>
> ```python
> return min(left, right) + 1
> ```
>
> 因为如果某一边是空子树，深度是 `0`，会被错误地当成最短路径。
>
> 正确逻辑：
>
> - 左右子树都为空：当前节点是叶子节点，返回 `1`
> - 左子树为空：只能走右子树
> - 右子树为空：只能走左子树
> - 左右子树都不为空：取较小值
>
> ---
>
> ## 路径总和 Path Sum
>
> 路径总和判断的是：
>
> 是否存在一条从根节点到叶子节点的路径，使得路径上的节点值之和等于 `targetSum`。
>
> 注意：必须走到叶子节点才能判断，不能在中间节点提前判断成功。
>
> 常见两种写法：
>
> - 递减目标值：每走一个节点，就让 `targetSum -= root.val`
> - 累加路径和：每走一个节点，就让 `ans += root.val`
>
> 更推荐递减目标值，因为代码更简洁。
>
> 递归逻辑：
>
> - 空节点：返回 `False`
> - 叶子节点：判断剩余目标值是否等于当前节点值
> - 非叶子节点：左子树或右子树有一条路径满足即可

---

> [!example]- 示例推演
> 例如：
>
> ```text
>      5
>     / \
>    4   8
>   /
>  11
>   \
>    2
> ```
>
> `targetSum = 22`
>
> 路径：
>
> ```text
> 5 -> 4 -> 11 -> 2
> ```
>
> 递减过程：
>
> - 到 `5`：剩余 `22 - 5 = 17`
> - 到 `4`：剩余 `17 - 4 = 13`
> - 到 `11`：剩余 `13 - 11 = 2`
> - 到 `2`：剩余 `2 - 2 = 0`
>
> 节点 `2` 是叶子节点，并且剩余值是 `0`，所以返回 `True`。

---

> [!success]- Python 实现
> ## 最大深度
>
> ```python
> class Solution:
>     def maxDepth(self, root: Optional[TreeNode]) -> int:
>         if root is None:
>             return 0
>
>         left = self.maxDepth(root.left)
>         right = self.maxDepth(root.right)
>
>         return max(left, right) + 1
> ```
>
> 主流程：
>
> - 空节点返回 `0`
> - 分别递归求左子树和右子树最大深度
> - 当前节点深度 = 左右子树最大值 + 1
>
> 关键变量：
>
> - `left`：左子树最大深度
> - `right`：右子树最大深度
>
> 容易写错的位置：
>
> - 最后忘记 `+ 1`
> - 空节点返回值写错
>
> ---
>
> ## 最小深度
>
> ```python
> class Solution:
>     def minDepth(self, root: Optional[TreeNode]) -> int:
>         if root is None:
>             return 0
>
>         if root.left is None and root.right is None:
>             return 1
>
>         if root.left is None:
>             return self.minDepth(root.right) + 1
>
>         if root.right is None:
>             return self.minDepth(root.left) + 1
>
>         left = self.minDepth(root.left)
>         right = self.minDepth(root.right)
>
>         return min(left, right) + 1
> ```
>
> 主流程：
>
> - 空树返回 `0`
> - 叶子节点返回 `1`
> - 只有一边子树存在时，只能走存在的那一边
> - 两边都存在时，取较小深度
>
> 关键变量：
>
> - `root.left`：左子树
> - `root.right`：右子树
> - `left`：左子树最小深度
> - `right`：右子树最小深度
>
> 容易写错的位置：
>
> - 最小深度不能直接写 `min(left, right) + 1`
> - 空子树不是一条有效的根到叶子路径
> - 叶子节点必须满足：`left is None and right is None`
>
> ---
>
> ## 路径总和：递减 targetSum 写法
>
> ```python
> class Solution:
>     def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
>         if root is None:
>             return False
>
>         targetSum -= root.val
>
>         if root.left is None and root.right is None:
>             return targetSum == 0
>
>         left = self.hasPathSum(root.left, targetSum)
>         right = self.hasPathSum(root.right, targetSum)
>
>         return left or right
> ```
>
> 主流程：
>
> - 空节点返回 `False`
> - 每访问一个真实节点，就从 `targetSum` 中减去当前节点值
> - 到叶子节点时，判断剩余值是否为 `0`
> - 左右子树只要有一边满足，就返回 `True`
>
> 关键变量：
>
> - `root`：当前节点
> - `targetSum`：当前路径还需要凑出的剩余值
> - `left`：左子树是否存在合法路径
> - `right`：右子树是否存在合法路径
>
> 容易写错的位置：
>
> - 空节点应该返回 `False`，不是 `0`
> - Python 中布尔值是 `True` 和 `False`
> - 递归调用时要写 `self.hasPathSum(...)`
> - 左右子树结果要用 `or` 合并
> - 必须到叶子节点才判断，不能中途判断
>
> ---
>
> ## 路径总和：累计 ans 写法
>
> ```python
> class Solution:
>     def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
>         def dfs(node, ans):
>             if node is None:
>                 return False
>
>             ans += node.val
>
>             if node.left is None and node.right is None:
>                 return ans == targetSum
>
>             left = dfs(node.left, ans)
>             right = dfs(node.right, ans)
>
>             return left or right
>
>         return dfs(root, 0)
> ```
>
> 主流程：
>
> - `ans` 记录当前路径和
> - 每走到一个节点，就把当前节点值加进 `ans`
> - 到叶子节点时，判断 `ans == targetSum`
> - 左右子树只要有一条路径满足，就返回 `True`
>
> 关键变量：
>
> - `ans`：当前路径累计和
> - `targetSum`：目标路径和
> - `node`：当前 DFS 节点
>
> 容易写错的位置：
>
> - `ans` 不能直接在外层随便 `ans += root.val`
> - 如果用累计和，应该把 `ans` 作为递归参数传下去
> - 最后不能直接 `return False`
> - 必须返回 `left or right`

---

> [!warning]- 易错点
> 1. 最大深度和最小深度的空节点处理不同
>
> 最大深度中，空节点返回 `0` 后可以直接参与 `max`。
>
> 最小深度中，空节点返回 `0` 不能直接参与 `min`，否则会把不存在的路径当成最短路径。
>
> ---
>
> 2. 最小深度错误写法
>
> ```python
> def minDepth(self, root):
>     if root is None:
>         return 0
>
>     left = self.minDepth(root.left)
>     right = self.minDepth(root.right)
>
>     return min(left, right) + 1
> ```
>
> 为什么错？
>
> 对于这种树：
>
> ```text
> 1
>  \
>   2
> ```
>
> 左子树深度是 `0`，右子树深度是 `1`。
>
> 错误代码会返回：
>
> ```text
> min(0, 1) + 1 = 1
> ```
>
> 但真正的最小深度是：
>
> ```text
> 1 -> 2
> ```
>
> 所以答案应该是 `2`。
>
> ---
>
> 3. 不要把“空节点”当成“叶子节点”
>
> 叶子节点是一个真实节点，并且：
>
> ```python
> root.left is None and root.right is None
> ```
>
> 空节点 `None` 不是叶子节点。
>
> ---
>
> 4. 路径总和必须走到叶子节点
>
> 错误想法：
>
> ```python
> if ans == targetSum:
>     return True
> ```
>
> 为什么错？
>
> 因为题目要求的是根节点到叶子节点的完整路径。
>
> 如果中间节点路径和刚好等于 `targetSum`，但它不是叶子节点，也不能返回 `True`。
>
> ---
>
> 5. 路径总和的递归结果要用 `or`
>
> ```python
> return left or right
> ```
>
> 含义是：
>
> - 左子树存在合法路径，返回 `True`
> - 右子树存在合法路径，返回 `True`
> - 两边都没有，才返回 `False`
>
> ---
>
> 6. `return` 的值会回到调用函数的位置
>
> 例如：
>
> ```python
> right = self.hasPathSum(root.right, targetSum)
> ```
>
> 如果右子树递归返回 `True`，就相当于：
>
> ```python
> right = True
> ```
>
> 如果写成：
>
> ```python
> return self.minDepth(root.right) + 1
> ```
>
> 子函数返回的值会直接参与计算。

---

> [!summary]- 复杂度
> 最大深度：
>
> 时间复杂度：$O(n)$
>
> 空间复杂度：$O(h)$
>
> 最小深度：
>
> 时间复杂度：$O(n)$
>
> 空间复杂度：$O(h)$
>
> 路径总和：
>
> 时间复杂度：$O(n)$
>
> 空间复杂度：$O(h)$
>
> 为什么：
>
> - 每个节点最多访问一次，所以时间复杂度是 $O(n)$
> - 递归调用栈深度取决于树高 $h$
> - 平衡二叉树中，$h=logn$
> - 链状二叉树中，$h=n$

---

## 一句话总结

最大深度找最长路径，最小深度找最近叶子路径，路径总和判断是否存在一条根到叶子的合法路径。

---

## 模板归纳

二叉树递归 DFS 应该这样想：

1. 当前节点为空时返回什么？
2. 当前节点是叶子节点时返回什么？
3. 左右子树分别返回什么？
4. 当前节点如何合并左右子树结果？

常见适用题型：

- 最大深度
- 最小深度
- 路径总和
- 判断平衡二叉树
- 二叉树直径
- 子树问题
- 节点数量统计

核心判断：

如果题目可以拆成：

$$
当前节点答案 = 左子树答案和右子树答案加工后的结果
$$

就应该优先想到递归 DFS。

对于路径类问题，还要额外想：

- 当前路径状态是什么？
- 是累计路径和，还是递减目标值？
- 是否必须走到叶子节点？
- 左右子树结果是用 `or` 还是 `and` 合并？
