# 162. 寻找峰值

给定数组 `nums`，返回任意一个峰值元素下标。

---

## 思路

数组不需要整体有序，但可以根据局部趋势判断峰值方向。  
比较 `nums[mid]` 和 `nums[mid + 1]`：  
下降说明左侧一定有峰值；上升说明右侧一定有峰值。  
因此可以用 Binary Search 每次排除一半。

---

> [!tip]- 核心思路
> ![Exported image](Exported%20image%2020260514133516-0.png)  
> 峰值满足：
>
> $$
> nums[i] > nums[i - 1]
> $$
>
> 并且：
>
> $$
> nums[i] > nums[i + 1]
> $$
>
> 题目假设：
>
> $$
> nums[-1] = nums[n] = -\infty
> $$
>
> 所以数组两端也可能是峰值。
>
> 关键判断：
>
> ```python
> nums[mid] > nums[mid + 1]
> ```
>
> - 如果 `nums[mid] > nums[mid + 1]`，说明当前位置往右是下降趋势，峰值在左侧或 `mid` 本身
> - 如果 `nums[mid] < nums[mid + 1]`，说明当前位置往右是上升趋势，峰值在右侧
>
> 这题本质不是找最大值，而是找任意一个局部峰值。

---

> [!example]- 示例推演
> ```python
> nums = [1, 2, 3, 1]
> ```
>
> 初始：
>
> ```text
> left = -1
> right = 3
> ```
>
> 第一次：
>
> ```text
> mid = 1
> nums[1] = 2
> nums[2] = 3
> ```
>
> 因为 `2 < 3`，说明右侧有峰值：
>
> ```python
> left = mid
> ```
>
> 第二次：
>
> ```text
> mid = 2
> nums[2] = 3
> nums[3] = 1
> ```
>
> 因为 `3 > 1`，说明峰值在左侧或当前位置：
>
> ```python
> right = mid
> ```
>
> 返回 `right = 2`。

---

> [!success]- Python 实现
> ```python
> class Solution:
>     def findPeakElement(self, nums: list[int]) -> int:
>         left = -1
>         right = len(nums) - 1
>
>         while left + 1 < right:
>             mid = (left + right) // 2
>
>             if nums[mid] > nums[mid + 1]:
>                 right = mid
>             else:
>                 left = mid
>
>         return right
> ```
>
> 主流程：
>
> - 用开区间思想维护搜索范围
> - 每次比较 `nums[mid]` 和 `nums[mid + 1]`
> - 根据上升或下降趋势决定峰值在哪一侧
>
> 关键变量：
>
> - `left`：排除掉的左边界
> - `right`：当前可能成为答案的位置
> - `mid`：用于判断局部趋势
>
> 容易写错的位置：
>
> - `right` 初始化为 `len(nums) - 1`，保证 `mid + 1` 不越界
> - 返回 `right`，不是 `left`
> - 不需要判断 `nums[mid - 1]`

---

> [!warning]- 易错点
> - 误以为必须找到全局最大值：题目只要求任意一个峰值
> - 用 `mid - 1` 判断：容易出现左边界越界
> - `right = len(nums)`：会导致 `nums[mid + 1]` 越界
> - 条件写反：`nums[mid] > nums[mid + 1]` 时应该收缩右边界
> - 忘记题目保证相邻元素不相等，所以不会出现无法判断方向的问题

---

> [!summary]- 复杂度
> 时间复杂度：
>
> $$
> O(\log n)
> $$
>
> 空间复杂度：
>
> $$
> O(1)
> $$
>
> 为什么：
>
> 每次根据局部趋势排除一半区间，只使用常数级变量。

---

## 一句话总结

寻找峰值的本质是根据局部上升/下降趋势，用二分锁定一定存在峰值的一侧。

---

## 模板归纳

Binary Search 适用场景：

- 不一定要求数组整体有序
- 只要能根据某个判断排除一半区间
- 峰值题看局部趋势
- 旋转数组题看分段关系
- 核心不是模板，而是先定义“答案在哪一侧”

---

# 153. 寻找旋转排序数组中的最小值

给定旋转后的升序数组 `nums`，返回数组中的最小值。

---

## 思路

旋转数组可以看成两段升序数组。  
最小值是右半段的第一个元素。  
用 `nums[-1]` 作为参照物，可以把数组分成左右两类。  
目标是找第一个小于 `nums[-1]` 的位置。

---

> [!tip]- 核心思路
> 例子：
>
> ```python
> nums = [4, 5, 6, 7, 0, 1, 2]
> ```
>
> 以最后一个元素 `nums[-1] = 2` 作为参考：
>
> - `nums[i] > nums[-1]`：在最小值左侧
> - `nums[i] < nums[-1]`：是最小值或在最小值右侧
>
> 所以可以把数组染色为：
>
> ```text
> 红 红 红 红 蓝 蓝 蓝
> ```
>
> 目标是找第一个蓝色位置。
>
> 判断条件：
>
> ```python
> nums[mid] < nums[-1]
> ```
>
> 如果成立，说明 `mid` 可能是最小值：
>
> ```python
> right = mid
> ```
>
> 否则说明 `mid` 还在最小值左侧：
>
> ```python
> left = mid
> ```

---

> [!example]- 示例推演
> ```python
> nums = [4, 5, 6, 7, 0, 1, 2]
> ```
>
> 参考值：
>
> ```python
> end = nums[-1] = 2
> ```
>
> 第一次：
>
> ```text
> mid = 3
> nums[3] = 7
> ```
>
> `7 > 2`，说明在最小值左侧：
>
> ```python
> left = mid
> ```
>
> 第二次：
>
> ```text
> mid = 5
> nums[5] = 1
> ```
>
> `1 < 2`，说明在最小值右侧或就是最小值：
>
> ```python
> right = mid
> ```
>
> 继续二分，最后返回 `nums[right] = 0`。

---

> [!success]- Python 实现
> ```python
> class Solution:
>     def findMin(self, nums: list[int]) -> int:
>         left = -1
>         right = len(nums) - 1
>
>         while left + 1 < right:
>             mid = (left + right) // 2
>
>             if nums[mid] < nums[-1]:
>                 right = mid
>             else:
>                 left = mid
>
>         return nums[right]
> ```
>
> 主流程：
>
> - 用 `nums[-1]` 判断元素属于旋转数组的哪一段
> - 找第一个小于 `nums[-1]` 的位置
> - 最后返回该位置的值
>
> 关键变量：
>
> - `left`：红色边界，表示最小值左侧
> - `right`：蓝色边界，表示可能是最小值的位置
> - `nums[-1]`：判断左右段的参照物
>
> 容易写错的位置：
>
> - 返回的是 `nums[right]`，不是 `right`
> - `right` 初始化为 `len(nums) - 1`
> - 题目元素互不相同，所以可以直接用 `<`

---

> [!warning]- 易错点
> - 把旋转数组当普通升序数组处理
> - 忘记最小值是“右半段第一个元素”
> - 返回下标而不是最小值
> - 没有利用 `nums[-1]` 作为分段参照
> - 条件写成 `nums[mid] > nums[-1]` 后更新方向混乱

---

> [!summary]- 复杂度
> 时间复杂度：
>
> $$
> O(\log n)
> $$
>
> 空间复杂度：
>
> $$
> O(1)
> $$
>
> 为什么：
>
> 每次通过 `nums[mid]` 和 `nums[-1]` 的比较排除一半区间。

---

## 一句话总结

旋转数组找最小值，本质是用 `nums[-1]` 分段，二分找第一个进入右半段的位置。

---

## 模板归纳

旋转数组最小值应该想到 Binary Search：

- 数组原本有序，但被旋转
- 可以分成两段升序数组
- 最小值是第二段的开头
- 用 `nums[-1]` 判断当前位置在哪一段
- 找第一个满足条件的位置

---

# 33. 搜索旋转排序数组

给定旋转后的升序数组 `nums` 和 `target`，存在则返回下标，否则返回 `-1`。

---

## 思路

旋转数组不是整体有序，不能直接普通二分。  
先用 `nums[-1]` 判断 `target` 和 `nums[mid]` 分别在哪一段。  
如果二者在同一段，就按普通升序比较。  
如果不在同一段，需要人为定义当前位置是否应该归为蓝色。

---

> [!tip]- 核心思路
> 例子：
>
> ```python
> nums = [4, 5, 6, 7, 0, 1, 2]
> target = 0
> ```
>
> 以 `end = nums[-1]` 为分界：
>
> - `nums[i] > end`：当前元素在左半段
> - `nums[i] <= end`：当前元素在右半段
> - `target > end`：目标在左半段
> - `target <= end`：目标在右半段
>
> 目标：重新定义 `is_blue(i)`，让数组仍然满足：
>
> ```text
> 红 红 红 蓝 蓝 蓝
> ```
>
> 判断逻辑：
>
> ```python
> if nums[i] > end:
>     return target > end and nums[i] >= target
> else:
>     return target > end or nums[i] >= target
> ```
>
> 为什么这样做：
>
> - 当前和目标在同一段时，可以正常比较 `nums[i] >= target`
> - 当前在左段，目标在右段时，当前一定在目标左边
> - 当前在右段，目标在左段时，当前一定在目标右边，可以视为蓝色

---

> [!example]- 示例推演
> ```python
> nums = [4, 5, 6, 7, 0, 1, 2]
> target = 0
> end = 2
> ```
>
> `target <= end`，目标在右半段。
>
> 如果：
>
> ```text
> nums[mid] = 7
> ```
>
> `7 > end`，当前在左半段，目标在右半段，当前不是蓝色。
>
> 如果：
>
> ```text
> nums[mid] = 1
> ```
>
> `1 <= end`，当前和目标都在右半段，可以正常比较。
>
> 因为 `1 >= 0`，当前是蓝色。
>
> 最终二分找到候选位置后，还要检查：
>
> ```python
> nums[right] == target
> ```

---

> [!success]- Python 实现
> ```python
> class Solution:
>     def search(self, nums: list[int], target: int) -> int:
>         end = nums[-1]
>
>         def is_blue(i: int) -> bool:
>             if nums[i] > end:
>                 return target > end and nums[i] >= target
>             else:
>                 return target > end or nums[i] >= target
>
>         left = -1
>         right = len(nums)
>
>         while left + 1 < right:
>             mid = (left + right) // 2
>
>             if is_blue(mid):
>                 right = mid
>             else:
>                 left = mid
>
>         if right == len(nums) or nums[right] != target:
>             return -1
>
>         return right
> ```
>
> 主流程：
>
> - 用 `nums[-1]` 判断左右半段
> - 定义 `is_blue(i)`，把旋转数组重新变成可二分结构
> - 二分找第一个蓝色位置
> - 最后检查候选位置是否真的等于 `target`
>
> 关键变量：
>
> - `end`：最后一个元素，用来判断左右段
> - `is_blue(i)`：判断当前位置是否已经到达目标右侧
> - `right`：候选答案位置
>
> 容易写错的位置：
>
> - `right` 初始化为 `len(nums)`，因为目标可能不存在
> - 二分结束后必须检查 `right == len(nums)`
> - 还必须检查 `nums[right] != target`
> - `is_blue()` 中跨段情况最容易写反

---

> [!warning]- 易错点
> - 直接用普通二分：旋转数组不是整体有序，会判断错方向
> - 忘记区分 `target` 在左半段还是右半段
> - `is_blue()` 条件写反
> - 二分结束后直接返回 `right`，没有验证 `nums[right] == target`
> - 忘记处理目标不存在时 `right == len(nums)` 的情况

---

> [!summary]- 复杂度
> 时间复杂度：
>
> $$
> O(\log n)
> $$
>
> 空间复杂度：
>
> $$
> O(1)
> $$
>
> 为什么：
>
> 每次通过 `is_blue(mid)` 判断搜索方向，把区间缩小一半。

---

## 一句话总结

搜索旋转数组的本质是重新定义二分的蓝色条件，让不完全有序的数组重新拥有可二分的边界。

---

## 模板归纳

旋转数组搜索应该想到 Binary Search + 红蓝染色法：

- 数组原本有序，但被旋转
- 不能直接使用普通二分条件
- 先判断 `target` 和 `nums[mid]` 分别在哪一段
- 同段时正常比较
- 异段时人为规定红蓝关系
- 最后必须验证候选答案

---

# 数组峰值与旋转数组总结

这类题的共同点：数组整体不一定有序，但可以构造出一个可二分的判断边界。

---

## 思路

二分查找的本质不是“数组有序”，而是“能否排除一半”。  
只要能把区间分成红色和蓝色两类，就可以用二分找边界。  
不同题目的关键，是先定义清楚什么叫蓝色。  
模板只是外壳，判断条件才是核心。

---

> [!tip]- 核心思路
> 红蓝染色法统一模板：
>
> ```python
> left = -1
> right = len(nums)
>
> while left + 1 < right:
>     mid = (left + right) // 2
>
>     if is_blue(mid):
>         right = mid
>     else:
>         left = mid
>
> return right
> ```
>
> 含义：
>
> - `left`：红色边界
> - `right`：蓝色边界
> - `is_blue(mid)`：判断当前位置是否属于答案侧
>
> 三道题的判断方式：
>
> | 题型 | 判断条件 | 本质 |
> |---|---|---|
> | 寻找峰值 | `nums[mid] > nums[mid + 1]` | 根据局部趋势找峰值方向 |
> | 旋转数组最小值 | `nums[mid] < nums[-1]` | 找第一个进入右半段的位置 |
> | 搜索旋转数组 | `is_blue(i)` | 重新定义旋转数组中的二分边界 |

---

> [!example]- 示例推演
> 峰值：
>
> ```python
> if nums[mid] > nums[mid + 1]:
>     right = mid
> else:
>     left = mid
> ```
>
> 旋转数组最小值：
>
> ```python
> if nums[mid] < nums[-1]:
>     right = mid
> else:
>     left = mid
> ```
>
> 搜索旋转数组：
>
> ```python
> def is_blue(i):
>     if nums[i] > end:
>         return target > end and nums[i] >= target
>     else:
>         return target > end or nums[i] >= target
> ```

---

> [!success]- Python 模板
> ```python
> def binary_search(nums):
>     left = -1
>     right = len(nums)
>
>     while left + 1 < right:
>         mid = (left + right) // 2
>
>         if is_blue(mid):
>             right = mid
>         else:
>             left = mid
>
>     return right
> ```
>
> 主流程：
>
> - 先定义红色和蓝色
> - 再写 `is_blue(mid)`
> - 最后用统一模板找第一个蓝色
>
> 关键变量：
>
> - `left`：最后一个红色位置
> - `right`：第一个蓝色位置
> - `is_blue()`：整道题最关键的判断逻辑
>
> 容易写错的位置：
>
> - 没有先定义蓝色含义
> - 不知道最终返回 `left` 还是 `right`
> - 判断条件和边界更新方向不匹配

---

> [!warning]- 易错点
> - 死记普通二分，而不是先判断能不能染色
> - 不清楚要找第一个蓝色还是最后一个红色
> - 条件成立后 `left/right` 更新反了
> - 对旋转数组直接使用普通升序数组判断
> - 忘记候选答案可能不存在，需要额外检查

---

> [!summary]- 复杂度
> 时间复杂度：
>
> $$
> O(\log n)
> $$
>
> 空间复杂度：
>
> $$
> O(1)
> $$
>
> 为什么：
>
> 红蓝染色法每次都通过判断条件排除一半区间。

---

## 一句话总结

二分的核心不是数组必须有序，而是能否定义一个稳定的红蓝边界，并不断逼近这个边界。

---

## 模板归纳

看到以下特征时，应该想到 Binary Search / 红蓝染色法：

- 要求 `O(log n)`
- 数组不是完全有序，但存在某种分界
- 可以通过一个判断条件排除一半
- 要找第一个满足条件的位置
- 要找局部峰值、旋转数组最小值、旋转数组目标值

面试时先问自己：

1. 我要找的是哪个边界？
2. 什么是红色？
3. 什么是蓝色？
4. `is_blue(mid)` 怎么写？
5. 最后返回 `right` 还是还需要检查？
