# 162. 寻找峰值

## 1. 题目要解决什么问题？

给定一个整数数组 `nums`，要求返回任意一个峰值元素的下标。  
峰值元素指的是：它严格大于左右相邻元素。  
题目允许假设：

$$  
nums[-1] = nums[n] = -\infty  
$$

因此数组两端也可能成为峰值。

小例子：

```python
nums = [1, 2, 3, 1]
```

`3` 是峰值，返回下标 `2`。

## 2. 核心思路

这题属于 `Binary Search`，但不是普通的有序数组二分。

关键是比较：

```python
nums[mid] > nums[mid + 1]
```

如果 `nums[mid] > nums[mid + 1]`，说明从 `mid` 到 `mid + 1` 是下降趋势。  
那么 `mid` 左侧或 `mid` 本身一定存在峰值。

如果 `nums[mid] < nums[mid + 1]`，说明从 `mid` 到 `mid + 1` 是上升趋势。  
那么 `mid + 1` 右侧或 `mid + 1` 本身一定存在峰值。

所以每次都可以排除一半区间。

小例子：

```python
nums = [1, 2, 1, 2, 4, 3, 6]
```

如果比较到：

```python
nums[mid] = 4
nums[mid + 1] = 3
```

因为 `4 > 3`，说明左边包含一个峰值，可以往左侧收缩。

## 3. 关键公式 / 判断条件

峰值条件：

$$  
nums[i] > nums[i - 1]  
$$

并且：

$$  
nums[i] > nums[i + 1]  
$$

二分判断：

$$  
nums[mid] > nums[mid + 1]  
$$

如果成立：

```python
right = mid
```

否则：

```python
left = mid
```

## 4. 代码模板

```python
class Solution:
    def findPeakElement(self, nums: list[int]) -> int:
        left = -1
        right = len(nums) - 1

        while left + 1 < right:
            mid = (left + right) // 2

            if nums[mid] > nums[mid + 1]:
                right = mid
            else:
                left = mid

        return right
```

## 5. 复杂度分析

时间复杂度：

$$  
O(\log n)  
$$

空间复杂度：

$$  
O(1)  
$$

每次比较 `nums[mid]` 和 `nums[mid + 1]` 后，都可以排除一半区间。

## 6. 核心结论

- 峰值题不要求数组整体有序
    
- 只需要根据局部上升 / 下降趋势判断峰值在哪一侧
    
- `nums[mid] > nums[mid + 1]`，峰值在左侧或当前位置
    
- `nums[mid] < nums[mid + 1]`，峰值在右侧
    
- 题目保证相邻元素不相等，所以判断方向不会卡住
    

## 7. 常见误区

- 误以为必须找到全局最大值
    
- 忘记题目只要求返回任意一个峰值
    
- 使用 `mid - 1` 判断时容易越界
    
- 忘记 `mid + 1` 必须合法，所以 `right` 初始为 `len(nums) - 1`

# 153. 寻找旋转排序数组中的最小值

## 1. 题目要解决什么问题？

给定一个原本升序排列、后来被旋转过的数组 `nums`。  
数组中元素互不相同。  
要求找到数组中的最小值。

小例子：

```python
nums = [4, 5, 6, 7, 0, 1, 2]
```

最小值是：

```python
0
```

## 2. 核心思路

这题属于 `Binary Search` + 旋转数组。

旋转数组可以看成两段升序数组：

```text
[4, 5, 6, 7, 0, 1, 2]
```

最小值右侧一定都比最后一个元素 `nums[-1]` 小或相等。  
最小值左侧则比 `nums[-1]` 大。

因此可以用 `nums[-1]` 作为参照物染色：

- 红色：`nums[i] > nums[-1]`，说明在最小值左侧
    
- 蓝色：`nums[i] < nums[-1]`，说明是最小值或在最小值右侧
    

目标是找到第一个蓝色位置。

## 3. 关键公式 / 判断条件

判断 `mid` 是否在最小值右侧：

$$  
nums[mid] < nums[-1]  
$$

如果成立，说明 `mid` 是蓝色，答案可能是 `mid`：

```python
right = mid
```

否则说明 `mid` 在最小值左侧：

```python
left = mid
```

最终返回：

```python
nums[right]
```

## 4. 代码模板

```python
class Solution:
    def findMin(self, nums: list[int]) -> int:
        left = -1
        right = len(nums) - 1

        while left + 1 < right:
            mid = (left + right) // 2

            if nums[mid] < nums[-1]:
                right = mid
            else:
                left = mid

        return nums[right]
```

## 5. 复杂度分析

时间复杂度：

$$  
O(\log n)  
$$

空间复杂度：

$$  
O(1)  
$$

每次通过 `nums[mid]` 和 `nums[-1]` 的比较排除一半区间。

## 6. 核心结论

- 旋转数组不是整体有序，但可以按 `nums[-1]` 分成两类
    
- 大于 `nums[-1]` 的元素在最小值左侧
    
- 小于 `nums[-1]` 的元素是最小值或在最小值右侧
    
- 目标是找第一个蓝色位置
    
- 返回的是 `nums[right]`，不是 `right`
    

## 7. 常见误区

- 把旋转数组当成普通升序数组处理
    
- 忘记数组元素互不相同
    
- `right` 初始化错误，导致 `nums[mid + 1]` 或边界越界
    
- 返回下标而不是最小值

# 33. 搜索旋转排序数组

## 1. 题目要解决什么问题？

给定一个旋转后的升序数组 `nums` 和目标值 `target`。  
数组中元素互不相同。  
如果 `target` 存在，返回它的下标；否则返回 `-1`。

小例子：

```python
nums = [4, 5, 6, 7, 0, 1, 2]
target = 0
```

答案是：

```python
4
```

## 2. 核心思路

这题也是 `Binary Search` + 红蓝染色法。

难点在于：旋转数组不是整体升序，不能直接用：

```python
nums[mid] >= target
```

所以需要重新定义“蓝色”的含义。

目标是找到第一个满足条件的位置。  
以 `nums[-1]` 作为分界参考，把数组分为左半段和右半段。

设：

```python
end = nums[-1]
```

分情况讨论：

### 情况一：`nums[i] > end`

说明 `nums[i]` 在左半段。

如果 `target > end`，说明 `target` 也在左半段。  
这时可以正常比较：

```python
nums[i] >= target
```

如果 `target <= end`，说明 `target` 在右半段。  
左半段所有元素都应该排在目标左边，不是蓝色。

### 情况二：`nums[i] <= end`

说明 `nums[i]` 在右半段。

如果 `target > end`，说明 `target` 在左半段。  
右半段所有元素都在目标右边，可以视为蓝色。

如果 `target <= end`，说明二者都在右半段。  
这时也可以正常比较：

```python
nums[i] >= target
```

## 3. 关键公式 / 判断条件

定义 `is_blue(i)`：

```python
if nums[i] > end:
    return target > end and nums[i] >= target
else:
    return target > end or nums[i] >= target
```

解释：

- `nums[i] > end`：当前元素在左半段
    
- `nums[i] <= end`：当前元素在右半段
    
- `target > end`：目标在左半段
    
- `target <= end`：目标在右半段
    

二分结束后：

```python
right
```

就是候选答案位置。

如果越界或不等于 `target`，返回 `-1`。

## 4. 代码模板

```python
class Solution:
    def search(self, nums: list[int], target: int) -> int:
        end = nums[-1]

        def is_blue(i: int) -> bool:
            if nums[i] > end:
                return target > end and nums[i] >= target
            else:
                return target > end or nums[i] >= target

        left = -1
        right = len(nums)

        while left + 1 < right:
            mid = (left + right) // 2

            if is_blue(mid):
                right = mid
            else:
                left = mid

        if right == len(nums) or nums[right] != target:
            return -1

        return right
```

## 5. 复杂度分析

时间复杂度：

$$  
O(\log n)  
$$

空间复杂度：

$$  
O(1)  
$$

每次通过 `is_blue(mid)` 判断，把搜索区间缩小一半。

## 6. 核心结论

- 旋转数组搜索的关键是重新定义二分中的“蓝色”
    
- `nums[-1]` 可以用来判断元素属于左半段还是右半段
    
- `target > nums[-1]` 说明目标在左半段
    
- `target <= nums[-1]` 说明目标在右半段
    
- 二分结束后还必须检查 `nums[right] == target`
    

## 7. 常见误区

- 直接用普通二分查找，会因为数组不整体有序而失败
    
- 忘记判断 `right == len(nums)`
    
- 没有区分 `target` 在左半段还是右半段
    
- `is_blue()` 的条件写反，导致边界方向错误

# 数组峰值与旋转数组总结

## 1. 这类题的共同点

这些题都不是普通的完整有序数组二分。  
它们的共同点是：数组虽然整体不一定有序，但可以根据某个判断条件构造出红蓝分界。

常见判断方式：

- 峰值题：比较 `nums[mid]` 和 `nums[mid + 1]`
    
- 旋转最小值：比较 `nums[mid]` 和 `nums[-1]`
    
- 旋转数组搜索：根据 `nums[i]`、`target` 和 `nums[-1]` 判断颜色
    

## 2. 红蓝染色法统一理解

二分查找的本质是找边界。

可以把数组染成两类：

```text
红色 红色 红色 蓝色 蓝色 蓝色
```

目标是找到第一个蓝色位置。

开区间模板：

```python
left = -1
right = len(nums)

while left + 1 < right:
    mid = (left + right) // 2

    if is_blue(mid):
        right = mid
    else:
        left = mid

return right
```

如果右边界本身一定是蓝色，也可以写成：

```python
left = -1
right = len(nums) - 1
```

## 3. 什么时候用这种写法？

当题目可以转化成：

```text
左边一类
右边一类
```

就可以用红蓝染色法。

例如：

- 找第一个满足条件的位置
    
- 找峰值
    
- 找旋转数组最小值
    
- 在旋转数组中查找目标值
    

## 4. 核心结论

- 不要死记普通二分，要先定义“红色”和“蓝色”
    
- 二分前先问：我要找的是哪个边界？
    
- `left` 通常表示红色边界
    
- `right` 通常表示蓝色边界
    
- 最终返回的一般是 `right`
    
- 条件写对，比模板本身更重要
    

## 5. 常见误区

- 没有先定义 `is_blue()`，直接硬写二分
    
- 不清楚返回 `left` 还是 `right`
    
- 对旋转数组仍然使用普通有序数组判断
    
- 峰值题误以为必须找最大值
    
- 忘记检查候选答案是否真的等于 `target`

# 最后速记版

## 峰值

```python
if nums[mid] > nums[mid + 1]:
    right = mid
else:
    left = mid
```

下降时，峰值在左边；上升时，峰值在右边。

## 旋转数组最小值

```python
if nums[mid] < nums[-1]:
    right = mid
else:
    left = mid
```

找第一个小于最后一个元素的位置。

## 搜索旋转数组

```python
def is_blue(i):
    end = nums[-1]

    if nums[i] > end:
        return target > end and nums[i] >= target
    else:
        return target > end or nums[i] >= target
```

核心是判断当前元素和目标值分别在旋转数组的哪一段。
