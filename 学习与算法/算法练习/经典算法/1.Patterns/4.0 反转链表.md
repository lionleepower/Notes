# 题目

反转链表系列：反转整个链表、反转指定区间、每 $k$ 个节点一组翻转。核心都是修改 `next` 指针，而不是交换节点值。

---

## 思路

链表反转的本质是：让当前节点 `cur` 的 `next` 指向前一个节点 `pre`。

反转过程中必须先保存 `nxt = cur.next`，否则链表后半段会丢失。

区间反转和 $k$ 个一组反转，本质都是：先局部反转，再把反转后的局部链表接回原链表。

原则：

pre：已经反转好的链表头
cur：还没反转的链表头

看cur, 存下一个(nxt)，反指前一个(cur.nxt)，前指针前进(pre)，当前指针前进(cur)

---

> [!tip]- 核心思路
> 
> ## 206. 反转链表
> 
> 使用三个指针：
> 
> - `pre`：已经反转好的链表头
>     
> - `cur`：当前正在处理的节点
>     
> - `nxt`：提前保存的下一个节点
>     
> 
> 每次循环只做一件事：
> 
> ```python
> cur.next = pre
> ```
> 
> 然后整体向后移动：
> 
> ```python
> pre = cur
> cur = nxt
> ```
> 
> ---
> 
> ## 92. 反转链表 II
> 
> 只反转 `[left, right]` 这一段。
> 
> 关键是找到反转段前一个节点 `p0`。
> 
> 反转结束后：
> 
> - `pre` 指向反转后这一段的头
>     
> - `cur` 指向反转段后面的第一个节点
>     
> - `p0.next` 原本是反转段的头，反转后变成尾
>     
> 
> 所以接回链表：
> 
> ```python
> p0.next.next = cur
> p0.next = pre
> ```
> 
> 为什么需要 `dummy`？
> 
> 因为 `left = 1` 时，反转段前面没有真实节点。加一个哨兵节点可以统一处理边界。
> 
> ---
> 
> ## 25. K 个一组翻转链表
> 
> 本质是重复执行“反转一段长度为 $k$ 的链表”。
> 
> 先统计链表长度 `n`，只有当剩余节点数 `n >= k` 时才反转。
> 
> 每一组反转后：
> 
> - `pre` 是这一组反转后的头
>     
> - `cur` 是下一组的起点
>     
> - `p0.next` 是这一组反转前的头，反转后变成尾
>     
> 
> 接回链表后，`p0` 要移动到当前组的尾部，准备处理下一组。

---

> [!example]- 示例推演  
> 以 `1 -> 2 -> 3 -> 4 -> 5`，反转区间 `left = 2, right = 4` 为例：
> 
> 初始：
> 
> ```text
> dummy -> 1 -> 2 -> 3 -> 4 -> 5
>          p0   cur
> ```
> 
> 反转 `2 -> 3 -> 4` 后：
> 
> ```text
> dummy -> 1    2 <- 3 <- 4    5
>          p0             pre  cur
> ```
> 
> 接回：
> 
> ```python
> p0.next.next = cur
> p0.next = pre
> ```
> 
> 得到：
> 
> ```text
> dummy -> 1 -> 4 -> 3 -> 2 -> 5
> ```

---

> [!success]- C++/Python 实现
> 
> ## 206. 反转链表
> 
> ```python
> class Solution:
>     def reverseList(self, head):
>         pre = None
>         cur = head
> 
>         while cur:
>             nxt = cur.next
>             cur.next = pre
>             pre = cur
>             cur = nxt
> 
>         return pre
> ```
> 
> 主流程：
> 
> - 用 `cur` 遍历原链表
>     
> - 用 `pre` 维护已经反转好的部分
>     
> - 每次只反转一个 `next` 指针
>     
> 
> 关键变量：
> 
> - `pre`：反转后链表的头
>     
> - `cur`：当前节点
>     
> - `nxt`：防止链表断裂
>     
> 
> 容易写错的位置：
> 
> - 必须先保存 `nxt = cur.next`
>     
> - 最后返回 `pre`，不是 `cur`
>     
> 
> ---
> 
> ## 92. 反转链表 II
> 
> ```python
> class Solution:
>     def reverseBetween(self, head, left, right):
>         dummy = ListNode(0, head)
>         p0 = dummy
> 
>         for _ in range(left - 1):
>             p0 = p0.next
> 
>         pre = None
>         cur = p0.next
> 
>         for _ in range(right - left + 1):
>             nxt = cur.next
>             cur.next = pre
>             pre = cur
>             cur = nxt
> 
>         p0.next.next = cur
>         p0.next = pre
> 
>         return dummy.next
> ```
> 
> 主流程：
> 
> - `p0` 先走到反转区间前一个节点
>     
> - 反转 `right - left + 1` 个节点
>     
> - 把反转后的区间重新接回链表
>     
> 
> 关键变量：
> 
> - `p0`：反转段前一个节点
>     
> - `pre`：反转段的新头
>     
> - `cur`：反转段后面的第一个节点
>     
> 
> 容易写错的位置：
> 
> ```python
> p0.next.next = cur
> p0.next = pre
> ```
> 
> 最难懂的是这两句
>
>```
>p0.next.next = curp0.next = pre
>```
>
>先看现在谁是谁：
>
>```
>dummy -> 1 -> 2         p0   p0.next
>```
>
>注意：虽然 `2` 被反转到尾部了，但是 `p0.next` 仍然能找到原来的区间头 `2`。
>
>反转后，原来的区间头 `2` 变成了区间尾。
>
>所以：
>
>```
>p0.next = 2
>```
>
>而 `2` 现在应该接到后面的 `5`。
>
>因此第一句：
>
>```
>p0.next.next = cur
>```
>
>含义是：
>
>```
>让 2.next = 5
>```
>
>得到：
>
>```
>dummy -> 1      4 -> 3 -> 2 -> 5         p0     pre
>```
>
>然后第二句：
>
>```
>p0.next = pre
>```
>
>含义是：
>
>```
>让 1.next = 4
>```
>
>最终：
>
>```
>dummy -> 1 -> 4 -> 3 -> 2 -> 5
>```
>
>返回：
>
>```
>return dummy.next
>```
>
>也就是返回真正头节点 `1`。
> 这两句顺序不能反。
>

> ## 25. K 个一组翻转链表
> 
> ```python
> class Solution:
>     def reverseKGroup(self, head, k):
>         n = 0
>         cur = head
>         while cur:
>             n += 1
>             cur = cur.next
> 
>         dummy = ListNode(0, head)
>         p0 = dummy
>         cur = head
> 
>         while n >= k:
>             n -= k
>             pre = None
> 
>             for _ in range(k):
>                 nxt = cur.next
>                 cur.next = pre
>                 pre = cur
>                 cur = nxt
> 
>             nxt = p0.next
>             p0.next.next = cur
>             p0.next = pre
>             p0 = nxt
> 
>         return dummy.next
> ```
> 
> 主流程：
> 
> - 先统计链表长度
>     
> - 每次只处理完整的 $k$ 个节点
>     
> - 每组内部使用普通反转链表逻辑
>     
> - 反转后把当前组接回原链表
>     
> 
> 关键变量：
> 
> - `n`：剩余节点数量
>     
> - `p0`：当前组前一个节点
>     
> - `cur`：下一组起点
>     
> - `nxt = p0.next`：当前组反转前的头，反转后会变成尾
>     
> 
> 容易写错的位置：
> 
> ```python
> nxt = p0.next
> p0.next.next = cur
> p0.next = pre
> p0 = nxt
> ```
> 
> `p0 = nxt` 是为了让 `p0` 移动到当前组反转后的尾部。

---

> [!warning]- 易错点
> 
> ## 1. 忘记保存 `nxt`
> 
> 错误写法：
> 
> ```python
> cur.next = pre
> cur = cur.next
> ```
> 
> 因为 `cur.next` 已经被改掉，原链表后面的节点会丢失。
> 
> 正确写法：
> 
> ```python
> nxt = cur.next
> cur.next = pre
> cur = nxt
> ```
> 
> ---
> 
> ## 2. 返回值写错
> 
> 普通反转链表结束后：
> 
> - `cur == None`
>     
> - `pre` 才是新头节点
>     
> 
> 所以返回：
> 
> ```python
> return pre
> ```
> 
> ---
> 
> ## 3. 区间反转没有用 `dummy`
> 
> 当 `left = 1` 时，头节点会变化。
> 
> 不加 `dummy`，需要单独处理头节点，非常容易写乱。
> 
> ---
> 
> ## 4. 区间接回顺序写反
> 
> 应该先让旧头节点接到后半段：
> 
> ```python
> p0.next.next = cur
> ```
> 
> 再让前半段接到新头：
> 
> ```python
> p0.next = pre
> ```
> 
> 如果先改 `p0.next = pre`，就找不到原来的区间头了。
> 
> ---
> 
> ## 5. K 个一组时处理了不足 $k$ 个节点
> 
> 题目要求：最后不足 $k$ 个节点保持原顺序。
> 
> 所以循环条件必须是：
> 
> ```python
> while n >= k:
> ```
> 
> 不能直接 `while cur:`。

---

> [!summary]- 复杂度
> 
> ## 206. 反转链表
> 
> 时间复杂度：$O(n)$
> 
> 空间复杂度：$O(1)$
> 
> 为什么：每个节点只访问一次，只使用常数个指针。
> 
> ---
> 
> ## 92. 反转链表 II
> 
> 时间复杂度：$O(n)$
> 
> 空间复杂度：$O(1)$
> 
> 为什么：最多遍历链表一次，只修改指针。
> 
> ---
> 
> ## 25. K 个一组翻转链表
> 
> 时间复杂度：$O(n)$
> 
> 空间复杂度：$O(1)$
> 
> 为什么：每个节点最多被反转一次，额外只使用若干指针。

---

## 一句话总结

反转链表的本质是维护 `pre / cur / nxt` 三个指针，逐个改变 `next` 方向；区间反转和 $k$ 组反转只是多了“找到前驱节点”和“反转后接回原链表”。

## 模板归纳

> [!tip]- 链表反转模板  
> 遇到下面这些题目时，优先想到链表反转模板：
> 
> - 反转整个链表
>     
> - 反转链表的一部分
>     
> - 每 $k$ 个节点一组翻转
>     
> - 链表重排前需要局部逆序
>     
> 
> 核心模板：
> 
> ```python
> pre = None
> cur = head
> 
> while cur:
>     nxt = cur.next
>     cur.next = pre
>     pre = cur
>     cur = nxt
> ```
> 
> 面试中最重要的解释：
> 
> - `nxt` 是为了防止后续链表丢失
>     
> - `pre` 永远指向已经反转好的部分
>     
> - `cur` 永远指向还没处理的部分
>     
> - 反转结束后，新头节点是 `pre`
>
