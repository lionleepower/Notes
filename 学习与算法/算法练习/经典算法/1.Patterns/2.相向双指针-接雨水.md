# 相向双指针：盛最多水的容器与接雨水

## 1. 核心问题

这类题都和“高度数组 height”有关：

```python
height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
```

但两道题的目标不同：

|题目|目标|
|---|---|
|盛最多水的容器|选两根柱子，使中间能装最多水|
|接雨水|每个位置能接多少雨水，求总和|

---

# 2. 盛最多水的容器
![Exported image](Exported%20image%2020260514133539-0.png)


## 2.1 面积怎么计算？

选中左右两根柱子：

```python
left
right
```

容器宽度是：

$$  
right - left  
$$

容器高度由较短的柱子决定：

$$  
\min(height[left], height[right])  
$$

所以面积是：

$$  
area = (right - left) \times \min(height[left], height[right])  
$$

---

## 2.2 为什么移动短板？

当前面积由短板决定。

如果：

```python
height[left] < height[right]
```

说明左边是短板。

这时如果移动右指针，宽度一定变小，而高度仍然受左边短板限制，面积不可能变大。

所以应该移动短板：

```python
left += 1
```

同理，如果右边更短：

```python
right -= 1
```

---

## 2.3 代码模板

```python
class Solution(object):
    def maxArea(self, height):
        ans = 0
        left = 0
        right = len(height) - 1

        while left < right:
            area = (right - left) * min(height[left], height[right])
            ans = max(ans, area)

            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return ans
```

---

## 2.4 复杂度

时间复杂度：

$$  
O(n)  
$$

空间复杂度：

$$  
O(1)  
$$

# 3. 接雨水

## 3.1 每个位置能接多少水？

对于位置 `i`，它能接多少水，取决于左右两边最高柱子的较小值。

左边最高：

$$  
pre_max[i]  
$$

右边最高：

$$  
suf_max[i]  
$$

当前位置水位高度：

$$  
\min(pre_max[i], suf_max[i])  
$$

当前位置柱子高度是：

$$  
height[i]  
$$

所以当前位置接水量是：

$$  
\min(pre_max[i], suf_max[i]) - height[i]  
$$

---

## 3.2 为什么是左右最大值的较小值？

雨水必须被左右两边挡住。

如果左边最高是 `3`，右边最高是 `5`，那么水最多只能到高度 `3`。

因为左边只有 `3`，超过 `3` 的水会从左边流走。

所以水位由较短的边界决定：

$$  
water_level = \min(left_max, right_max)  
$$

---

## 3.3 前后缀最大值写法

先计算每个位置左边最高：

```python
pre_max[i] = max(pre_max[i - 1], height[i])
```

再计算每个位置右边最高：

```python
suf_max[i] = max(suf_max[i + 1], height[i])
```

最后累加每个位置的接水量。

---

## 3.4 代码模板

```python
class Solution(object):
    def trap(self, height):
        n = len(height)

        pre_max = [0] * n
        pre_max[0] = height[0]

        for i in range(1, n):
            pre_max[i] = max(pre_max[i - 1], height[i])

        suf_max = [0] * n
        suf_max[-1] = height[-1]

        for i in range(n - 2, -1, -1):
            suf_max[i] = max(suf_max[i + 1], height[i])

        ans = 0

        for h, pre, suf in zip(height, pre_max, suf_max):
            ans += min(pre, suf) - h

        return ans
```

---

## 3.5 复杂度

时间复杂度：

$$  
O(n)  
$$

空间复杂度：

$$  
O(n)  
$$

因为用了两个数组：

```python
pre_max
suf_max
```

# 4. 两道题的区别

|题目|核心|
|---|---|
|盛最多水的容器|选两根柱子，面积最大|
|接雨水|每个位置单独算能接多少水|
|盛最多水的容器|宽度参与计算|
|接雨水|只看当前位置的左右边界|
|盛最多水的容器|移动短板|
|接雨水|计算左右最大边界|

---

# 5. 术语表

|术语|英文|含义|
|---|---|---|
|双指针|Two Pointers|用两个指针维护搜索范围|
|相向双指针|Opposite Two Pointers|左右指针从两端向中间移动|
|短板|Shorter Board|两侧高度较小的一边|
|前缀最大值|Prefix Maximum|从左到当前位置的最大高度|
|后缀最大值|Suffix Maximum|从右到当前位置的最大高度|
|接水量|Trapped Water|某个位置能存下的雨水高度|

---

# 6. 核心结论

1. 盛最多水的容器看的是两根柱子形成的最大面积。
    
2. 面积公式是：
    

$$  
area = (right - left) \times \min(height[left], height[right])  
$$

3. 盛最多水的容器每次移动短板。
    
4. 接雨水看的是每个位置能接多少水。
    
5. 接雨水当前位置的水量是：
    

$$  
\min(pre_max[i], suf_max[i]) - height[i]  
$$

6. 盛最多水的容器空间复杂度是：
    

$$  
O(1)  
$$

7. 前后缀写法的接雨水空间复杂度是：
    

$$  
O(n)  
$$

---

# 7. 常见误区

## 误区一：盛最多水移动高板

错。

应该移动短板。

因为面积高度由短板决定，移动高板只会让宽度变小，短板还没变，面积不可能更优。

---

## 误区二：接雨水只看相邻柱子

错。

当前位置能接多少水，不是由左右相邻柱子决定，而是由左侧最高柱子和右侧最高柱子决定。

---

## 误区三：把两道题混成一个公式

盛最多水的容器用：

$$  
(right - left) \times \min(height[left], height[right])  
$$

接雨水用：

$$  
\min(pre_max[i], suf_max[i]) - height[i]  
$$

一个算面积，一个算每个位置的水量，不是同一道题。
