# Python 字符串：回溯题里最常用的五个操作

字符串在 Python 里是**不可变的可迭代序列**。回溯题（电话号码、分割回文串等）反复用到同一小撮操作：遍历字符、切片、判回文、拼接、字符转下标——这篇一次讲清。

---

## 思路

这些操作单独都不难，难在题解里连着出现时每个都「晃一下」。先记住一条：**字符串支持一切序列操作（遍历、切片、反转），但任何「修改」都会生成新字符串。**

> [!tip]- 核心思路
> 
> ```python
> for c in s:          # 字符串本身可迭代，逐字符遍历
> t = s[i:j + 1]       # 切片：取 s[i..j]，左闭右开所以 +1
> t == t[::-1]         # 判回文：与自身反转比较
> ''.join(path)        # 把字符列表拼成一个新字符串
> MAPPING[int(ch)]     # 字符转整数，用数字本身当下标查表
> ```

---

## 1. 核心操作

| 操作 | 作用 | 注意事项 |
| --- | --- | --- |
| `for c in s` | 逐字符遍历 | 字符串可迭代，无需 `range(len(s))` |
| `s[i:j + 1]` | 取子串 `s[i..j]` | 切片是拷贝，花 $O(j - i)$ |
| `s[::-1]` | 反转（生成新字符串） | 判回文写法：`t == t[::-1]`，$O(n)$ |
| `''.join(path)` | 字符列表拼成字符串 | 生成**全新对象**，与 `path` 脱钩 |
| `int(ch)` | 字符 `'2'` → 整数 `2` | 索引取出的是**字符**，不是数字 |

---

## 2. 实例一：`MAPPING[int(digits[i])]` 逐层拆解

17. 电话号码的字母组合 里最常卡住的一行。

> [!example]- 拆解
> 
> ```python
> MAPPING = ["", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"]
> 
> digits[i]              # '2' —— 字符，不是数字
> int(digits[i])         # 2   —— 转成整数
> MAPPING[2]             # "abc" —— 数字本身当下标查表
> for c in "abc": ...    # 字符串可迭代，逐个字母枚举
> ```
> 
> `MAPPING` 前两格塞空串 `""` 就是占位：让下标 2 恰好对上 `"abc"`。

---

## 3. 实例二：`t == t[::-1]` 判回文

131. 分割回文串 中枚举每一段时的合法性检查（也是剪枝条件）。

> [!example]- 用法
> 
> ```python
> t = s[i:j + 1]        # 当前枚举的段
> if t == t[::-1]:      # 是回文才递归
>     ...
> ```
> 
> `[::-1]` 生成反转后的**新字符串**再逐字符比较，时间 $O(\text{len}(t))$。段长、判断次数多时可换相向双指针原地比较（省一份拷贝），见 [[1.0 相向双指针-多数之和]]。

---

## 常见易错点

> [!warning]- 易错点
> 
> - **`digits[i]` 直接当下标**：它是字符 `'2'`，不 `int()` 就成了 `MAPPING['2']` → `TypeError`。
> - **切片右端点忘 +1**：`s[i:j]` 左闭右开，要取 `s[i..j]` 必须写 `s[i:j + 1]`。
> - **以为 `join` 只是拼接**：`ans.append(''.join(path))` 之所以安全，正因为 join 生成了独立的新字符串；直接 `ans.append(path)` 存的是引用，见 [[Python_赋值与拷贝]]。
> - **忽略切片成本**：`s[i:j + 1]` 和 `[::-1]` 都是 $O(n)$ 拷贝，出现在回溯每个节点上时要算进总复杂度。

---

## 复杂度

> [!summary]- 复杂度
> 
> - 遍历 / 切片 / 反转 / join：都是 $O(n)$，$n$ 为涉及的字符数。
> - 出现在回溯每个节点上时，总复杂度 = 节点数 × $O(n)$，如 17 题的 $O(n \cdot 4^n)$。

---

## 一句话总结

字符串是不可变序列：能遍历、能切片、能 `[::-1]` 反转，`join` 拼接生成独立新串；字符要 `int()` 转换后才能当数字用。

---

## 模板归纳

看到以下信号时，优先想到本篇：

- 逐位处理数字字符串 → `int(s[i])` 查表
- 枚举子串并判回文 → `t = s[i:j + 1]`，`t == t[::-1]`
- 回溯收答案要字符串 → `''.join(path)`
