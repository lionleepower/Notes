# Python 除法与取整

理解 Python 中 `/`、`//`、`%` 的区别，尤其是刷题中常见的向上取整写法。

---

## 思路

Python 除法最容易混淆的是：`//` 不是简单“去掉小数”，而是 **向下取整 floor division**。  
刷题中常见的二分答案、计算次数、求中点，本质都依赖整数除法。  
尤其在类似“吃香蕉”“分组”“装载能力”这类题中，经常需要计算：

$$  
\lceil \frac{p}{k} \rceil  
$$

---

> [!tip]- 核心思路  
> Python 中常见三种除法相关运算：
> 
> - `/`：普通除法，结果通常是 `float`
>     
> - `//`：整除，准确说是 **向下取整除法 floor division**
>     
> - `%`：取余，和 `//` 配套使用
>     
> 
> 关键关系：
> 
> ```python
> a == (a // b) * b + (a % b)
> ```
> 
> 刷题中最常见的是：
> 
> ```python
> mid = (left + right) // 2
> ```
> 
> 以及向上取整：
> 
> ```python
> ceil(p / k) == (p + k - 1) // k
> ```

---

> [!example]- 示例推演  
> 普通除法：
> 
> ```python
> 5 / 2 == 2.5
> 4 / 2 == 2.0
> ```
> 
> 整除：
> 
> ```python
> 5 // 2 == 2
> 4 // 2 == 2
> ```
> 
> 负数时注意：
> 
> ```python
> -5 // 2 == -3
> ```
> 
> 因为：
> 
> ```python
> -5 / 2 = -2.5
> floor(-2.5) = -3
> ```
> 
> 所以 `//` 不是截断小数，而是向更小的方向取整。

---

> [!success]- C++/Python 实现  
> Python 常用写法：
> 
> ```python
> # 普通除法
> print(5 / 2)     # 2.5
> print(4 / 2)     # 2.0
> 
> # 整除 / 向下取整
> print(5 // 2)    # 2
> print(4 // 2)    # 2
> print(-5 // 2)   # -3
> 
> # 取余
> print(5 % 2)     # 1
> print(-5 % 2)    # 1
> 
> # 求中点
> mid = (left + right) // 2
> 
> # 向上取整：ceil(p / k)
> hours = (p + k - 1) // k
> ```
> 
> 主流程：
> 
> - `/` 用于真实除法
>     
> - `//` 用于整数结果
>     
> - `%` 用于判断是否有余数
>     
> - `(p + k - 1) // k` 用于整数向上取整
>     
> 
> 关键变量：
> 
> - `p`：总数量
>     
> - `k`：每次处理的数量
>     
> - `hours`：需要的次数
>     
> 
> 容易写错的位置：
> 
> - 把 `//` 理解成“截断小数”
>     
> - 用 `p // k + 1` 代替向上取整
>     
> - 没考虑 `p` 正好能被 `k` 整除的情况
>     

---

> [!warning]- 易错点
> 
> 1. `//` 不是截断，而是向下取整
>     
> 
> ```python
> -5 // 2 == -3
> ```
> 
> 不是：
> 
> ```python
> -5 // 2 == -2
> ```
> 
> ---
> 
> 2. 向上取整不能直接写成：
>     
> 
> ```python
> p // k + 1
> ```
> 
> 因为如果刚好整除，会多算一次。
> 
> 例如：
> 
> ```python
> p = 6
> k = 3
> 
> p // k + 1 == 3   # 错
> ```
> 
> 实际应该是：
> 
> ```python
> (p + k - 1) // k == 2
> ```
> 
> ---
> 
> 3. 二分中 `k` 不能为 0
>     
> 
> 例如“最小速度”问题中：
> 
> ```python
> left = 0
> k = (left + right) // 2
> ```
> 
> 如果 `k == 0`，后面计算 `p // k` 会直接报错。
> 
> 所以速度、容量这类答案通常从 `1` 开始：
> 
> ```python
> left = 1
> right = max(piles)
> ```

---

> [!summary]- 复杂度  
> 时间复杂度：
> 
> 单次除法、整除、取余都是 $O(1)$。
> 
> 空间复杂度：
> 
> $O(1)$。
> 
> 为什么：
> 
> 这些都是基本算术运算，不需要额外数据结构。

---

## 一句话总结

Python 的 `//` 是向下取整除法，刷题中向上取整最稳写法是 `(p + k - 1) // k`。

---

## 模板归纳

整数除法在刷题中常见于：

- 二分答案 Binary Search on Answer
    
- 求中点
    
- 计算批次数
    
- 计算需要多少小时 / 天数 / 轮数
    
- 判断容量、速度、分组大小是否满足条件
    

看到这种表达时：

```python
需要多少次才能处理完 p 个元素，每次处理 k 个
```

优先想到：

```python
(p + k - 1) // k
```

本质是：

$$  
\lceil \frac{p}{k} \rceil  
$$
