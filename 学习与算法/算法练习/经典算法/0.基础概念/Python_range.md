`for i in range(2, n-1)` 语法本身**完全合法**，能不能用得看你想遍历到哪。关键是它**取不到 `n-1` 本身**。

## range 的三种形态

`range(stop)` —— 从 0 开始，到 `stop` 前一个停：

```python
range(5)        # 0 1 2 3 4       取不到 5
```

`range(start, stop)` —— 从 `start` 开始，到 `stop` **前一个**停（左闭右开）：

```python
range(2, 6)     # 2 3 4 5         取不到 6
```

`range(start, stop, step)` —— 加步长，可正可负：

```python
range(1, 10, 2) # 1 3 5 7 9      每次 +2
range(5, 0, -1) # 5 4 3 2 1      倒着走
```

## 核心心智：**左闭右开** `[start, stop)`

这跟你二分那套 [[3_0_二分查找_红蓝染色法]] 的区间理解是同一个逻辑——**能取到左端，取不到右端**。所以：

- 元素个数 = `stop - start`（步长为 1 时），`range(2, 6)` 就是 `6 - 2 = 4` 个数。
- 想遍历到下标 `k`，要写 `range(..., k+1)`。

## 回到你的 `range(2, n-1)`

它遍历的是 `2, 3, ..., n-2`，**最大只到 `n-2`**，取不到 `n-1`。

对不对，取决于你的意图：

|你想遍历到|应该写|
|---|---|
|到 `n-2`（当前这样）|`range(2, n-1)` ✅|
|到 `n-1`（最后一个合法下标）|`range(2, n)`|
|到 `n`（会越界！）|`range(2, n+1)` ⚠️|

如果 `n = len(nums)`，合法下标是 `0 .. n-1`。想遍历到最后一个元素，一般写 `range(2, n)`——你现在这个 `n-1` 会**漏掉最后一个元素**，这是最常见的差一（off-by-one）坑。

**一句话判断法**：`range` 的第二个参数写的是「第一个你**不要**的数」。想让下标 `n-1` 进循环，就把 stop 写成 `n`。你的 `range(2, n-1)` 语法完全合法。用一张图快速帮你把「左闭右开」这个心智钉牢——这是理解 `range` 的关键，跟你二分那套区间理解是同一个逻辑。## range 的三种形态
