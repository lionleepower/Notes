# 剪枝：注定失败的子树，进门前就砍掉

剪枝 (Pruning) 是回溯的加速器：在**进入递归之前**判断「这棵子树不可能通向合法答案」，直接跳过。它解决的问题：回溯本质是指数级穷举，不剪枝就会把大量注定失败的分支走到底再验证；剪枝把它们成片提前排除。

---

## 思路

剪枝敢在半路给整棵子树「宣判死刑」，靠的不是运气，而是题目里存在某个**不可逆的量**。

> [!tip]- 成立前提：错误不可逆
> 
> 剪枝成立当且仅当：**当前的缺口无法被后面的选择补救**。
> 
> - 组合：剩的候选不够凑齐 $k$ 个——后面再怎么选也变不出新候选。
> - 216. 组合总和 III：剩余目标 `t < 0`——候选全是正数，和只会更大。
> - 22. 括号生成：某个前缀右括号超额——无论后面怎么填都救不回来。
> 
> 给一道题设计剪枝，就是在找它的「不可逆量」。剪枝写在**递归之前**，这是它与「先生成再过滤」的本质区别（见 [[6.0 回溯型算法]]）。

---

## 1. 可行性剪枝：剩的不够了

组合型最关键的一条：还需要 `d = k - len(path)` 个，候选池里只剩 `i` 个，不够就撤。

> [!success]- 核心写法（倒序枚举）
> 
> ```python
> d = k - len(path)     # 还差几个
> if i < d:             # 池子 [1, i] 里只有 i 个数，不够
>     return
> ```
> 
> 倒序枚举的价值就在这里：候选池 $[1, i]$ 的大小**就是 `i` 本身**，剪枝条件零换算。正序版池子 $[i, n]$ 大小是 $n - i + 1$，同一条剪枝多一层算术，`+1` 容易错。应用见 [[6.2 组合型回溯]]。

---

## 2. 同一个剪枝的两个位置

入口 `if i < d: return` 提前拦截；循环下界 `range(i, d - 1, -1)` 不让 `j` 走进无效区。两处**完全等价**，留一处就够，都写只是保险。

> [!tip]- 为什么循环下界是 d - 1：分两步拆
> 
> **第一步：`j` 的数学下界是 $d$，不是 $d-1$。** 选了 `j` 之后池子收缩成 $[1, j-1]$，只剩 $j-1$ 个数，而还需要 $d-1$ 个。要凑得齐必须 $j - 1 \ge d - 1$，即 $j \ge d$。直觉：还要选 $d$ 个互不相同的正整数、一路严格递减，最小是 1，所以最大的（这一层的 `j`）至少是 $d$。
> 
> **第二步：range 的 stop 是开区间。** 想让 `j` 一路取到 $d$，stop 就得写 `d - 1`——`range(i, d - 1, -1)` 生成 `i, i-1, ..., d`，停在 $d$。这个 `- 1` 纯粹是语法偏移，跟剪枝逻辑无关（见 [[Python_range]]）。

---

## 3. 约束剪枝：越界即撤

带数值约束的题（剩余和、剩余预算），一旦越过不可逆的界，立即返回。

> [!example]- 216. 组合总和 III
> 
> ```python
> def dfs(i, t):        # t：剩余目标和
>     if t < 0:         # 候选全为正，超了救不回来
>         return
>     ...
> ```
> 
> 注意前提：这条剪枝依赖「候选全为正」。若候选含负数，「超了」就是可逆的，提前返回会丢解——剪之前先确认不可逆性。

---

## 4. 剪枝 vs 边界：`i == 0` 是弱化版

选/不选切法必须显式写「池子空了」的边界 `if i == 0`（没有循环兜底，不写就无限递归）。但 `i == 0` 且没选够时必然满足 `i < d`，所以**边界被剪枝包含**：一句 `if i < d: return` 同时解决边界和剪枝。循环版则连这句都可省——`range` 为空自动兜底。

---

## 易错点

> [!warning]- 易错点
> 
> - **把 `d - 1` 当成剪枝逻辑**：数学约束是 $j \ge d$，`- 1` 只是开区间偏移；混在一起记，换道题就写错循环下界。
> - **剪枝和收答案顺序反了**：先判成功（`d == 0` 收答案），再判失败（`i < d` 撤）；反过来会误杀刚好在边界上凑齐的方案。
> - **对可逆量剪枝**：`t < 0` 依赖候选同号；含负数时这条「不可逆」不成立，剪了会丢解。

---

## 一句话总结

剪枝 = 找到题目里的「不可逆量」，在进入递归之前用它砍掉整棵注定失败的子树；组合型的条件反射是 `if i < k - len(path): return`。

---

## 模板归纳

看到以下信号时，想想有没有剪枝可加：

- 「恰好 $k$ 个」的长度约束 → 可行性剪枝 `i < d`
- 「和 / 预算为定值」且候选同号 → 越界剪枝 `t < 0`
- 合法性是全局性质 → 先翻译成「每步可查的前缀条件」再剪（22. 括号生成）

```python
def dfs(i):
    d = k - len(path)
    if d == 0:                      # 先判成功
        ans.append(path.copy())
        return
    if i < d:                       # 再剪枝（同时覆盖边界 i == 0）
        return
    for j in range(i, d - 1, -1):   # 同一剪枝的循环位置
        path.append(j)
        dfs(j - 1)
        path.pop()
```
