# Python 数组转树：把线性数据重建成有层次的树结构

把一维数组还原成带父子关系的树，解决"输入是数组、但算法需要在树上递归/遍历"的落差。算法题中凡是给你 `list` 却要求返回 `TreeNode`、或题面写着"完全二叉树 / 堆 / 层序序列 / 有序数组建 BST"时，就需要它。

---

## 思路

数组是**线性**的、只有先后顺序；树是**有层次**的、有父子关系。二者信息量不同，所以"转换"的本质是**约定一套规则，把下标解释成父子关系**。不用它、直接在数组上暴力模拟，会因为找不到"某节点的孩子在哪"而寸步难行；而只要规则确定，重建就是一次遍历的事。

关键在于先分清**数组代表哪种树**，规则完全不同：无空洞的完全二叉树靠下标公式；有序数组要平衡就取中点；带 `null` 的层序序列要靠队列逐层接。

> [!tip]- 核心思路 完全二叉树用下标算父子，有序数组取中点，层序序列用队列。
> 
> ```python
> # 完全二叉树：下标 i 的孩子
> left  = 2 * i + 1
> right = 2 * i + 2
> parent = (i - 1) // 2
> ```
> 
> 判断依据：数组"有没有空洞"和"有没有序"决定用哪套规则。

---

## 1. 导入与创建

下标法和取中点法只依赖内置 `list`，无需导入；层序反序列化需要 `collections.deque` 当队列。所有方法都先要一个统一的节点定义。

> [!success]- 基础语法
> 
> ```python
> # 层序建树需要导入队列
> from collections import deque
> 
> class TreeNode:
>     def __init__(self, val=0, left=None, right=None):
>         self.val = val
>         self.left = left
>         self.right = right
> 
> # 三类输入
> heap_like   = [8, 3, 10, 1, 6, 14, 13]          # 完全二叉树，无空洞
> sorted_arr  = [1, 3, 4, 6, 7, 8, 10, 13, 14]     # 有序，建平衡 BST
> level_order = [3, 9, 20, None, None, 15, 7]       # 层序，含 None 占位
> ```

---

## 2. 核心操作

|操作|作用|时间复杂度或注意事项|
|---|---|---|
|`2 * i + 1` / `2 * i + 2`|由父下标求左/右孩子下标|$O(1)$，仅适用于**无空洞**的完全二叉树|
|`(i - 1) // 2`|由孩子下标求父下标|$O(1)$，向下取整，根节点 `i=0` 无父|
|`len(nums) // 2`|有序数组取中点当根|$O(1)$，保证左右子树规模均衡，树高 $O(\log n)$|
|`deque.popleft()`|层序建树时取出待接孩子的父节点|$O(1)$，`list.pop(0)` 是 $O(n)$，别用|

> [!example]- 最小示例
> 
> ```python
> # 在"完全二叉树数组"上直接用下标当树用，无需真的建树
> arr = [8, 3, 10, 1, 6, 14, 13]
> i = 1                    # 节点 3
> print(arr[i])           # 3   当前值
> print(arr[2 * i + 1])   # 1   左孩子
> print(arr[2 * i + 2])   # 6   右孩子
> print(arr[(i - 1) // 2])# 8   父节点
> ```

---

## 3. 关键行为与边界

最容易混淆的是"下标法"和"队列法"的适用前提：前者要求数组**紧密无空洞**（第 `i` 个数组元素严格对应树的第 `i` 个层序位置），后者允许 `None` 空节点、下标与树位置**不再一一对应**。选错方法会把空节点也当成真节点接上去。

> [!tip]- 为什么这样做 完全二叉树的定义保证了"除最后一层外每层填满、最后一层靠左填"，所以层序下标和树位置严格对齐，公式 `2i+1 / 2i+2` 才成立。一旦允许中间出现空节点，这个对齐就被破坏，只能改用队列显式记录"下一个待接孩子的父节点是谁"。

> [!warning]- 边界条件
> 
> - 空输入：`arr == []` 或 `arr[0] is None` 时直接返回 `None`。
> - 下标越界：递归建树时必须先判 `i >= len(arr)` 再取 `arr[i]`，否则 `IndexError`。
> - `None` 占位：层序序列里的 `None` 表示空节点，**不入队**，但在读取时仍要占一个下标位。
> - 取中点写 `mid = len(nums) // 2`：右子树用 `nums[mid+1:]`，注意 `+1` 别把根节点重复算进去。

## 4. 实例一：完全二叉树数组 → 带指针的树

输入是无空洞的完全二叉树数组，目标是建出真正的 `TreeNode` 结构（比如题目要求返回根节点）。因为下标严格对齐，直接用公式递归即可，无需队列。

> [!success]- 完整实现
> 
> ```python
> def array_to_tree(arr, i=0):
>     # 越界或空位 → 该位置没有节点
>     if i >= len(arr) or arr[i] is None:
>         return None
>     node = TreeNode(arr[i])
>     node.left  = array_to_tree(arr, 2 * i + 1)   # 递归建左子树
>     node.right = array_to_tree(arr, 2 * i + 2)   # 递归建右子树
>     return node
> 
> 
> root = array_to_tree([8, 3, 10, 1, 6, 14, 13])
> print(root.val, root.left.val, root.right.val)   # 8 3 10
> ```

主流程是"取当前下标建节点 → 用 `2i+1 / 2i+2` 递归左右孩子"。最容易写错的位置是**越界判断放在取值之前**：必须先 `i >= len(arr)` 短路，否则 `arr[i]` 直接抛异常。

## 5. 实例二：有序数组 → 平衡 BST（LeetCode 108）

输入是**升序**数组，目标是建一棵**高度平衡**的二叉搜索树。每次取中间元素当根，能让左右两侧节点数几乎相等，从而把树高压在 $O(\log n)$，避免退化成链表。这体现了"取中点"这一手法的真正价值，而不只是换个输入。

> [!success]- 完整实现
> 
> ```python
> def sorted_array_to_bst(nums):
>     if not nums:
>         return None
>     mid = len(nums) // 2                              # 中点当根
>     root = TreeNode(nums[mid])
>     root.left  = sorted_array_to_bst(nums[:mid])      # 左半段 → 左子树
>     root.right = sorted_array_to_bst(nums[mid + 1:])  # 右半段 → 右子树
>     return root
> 
> 
> root = sorted_array_to_bst([1, 3, 4, 6, 7, 8, 10, 13, 14])
> print(root.val)   # 7   （中点元素）
> ```

> [!summary]- 当前实例复杂度
> 
> - 时间复杂度：$O(n)$，每个元素恰好被访问并建成一个节点一次。
> - 空间复杂度：$O(\log n)$ 递归栈（树平衡，深度为 $\log n$）；若把切片 `nums[:mid]` 产生的临时数组也算上则退化到 $O(n \log n)$，可改传下标区间 `lo, hi` 优化掉。

---

## 6. 与相近写法怎么选

|需求|推荐写法|原因|
|---|---|---|
|数组是无空洞的完全二叉树 / 堆|下标公式 `2i+1 / 2i+2`|严格对齐，$O(1)$ 定位孩子，甚至不必真的建树|
|有序数组、要求平衡 BST|取中点递归|中点当根保证左右均衡，树高 $O(\log n)$|
|带 `None` 的层序序列|队列逐层接（见模板归纳）|有空洞时下标不再对齐，只能显式记录待接父节点|
|只想"当树用"、不需要真节点|直接在原数组上用下标|省掉 $O(n)$ 指针与内存开销|

只保留会真正影响选择的差异：核心判据就是**有没有空洞**与**有没有序**。

## 7. 常见易错点

> [!warning]- 易错点
> 
> - **先取值后判越界**：写成 `if arr[i] is None` 而漏掉 `i >= len(arr)`，越界直接 `IndexError`；判断顺序必须"先越界、后取值"。
> - **对有空洞的序列硬套下标公式**：层序序列里一旦出现 `None`，`2i+1 / 2i+2` 就会错位，必须改用队列。
> - **取中点右子树切片漏 `+1`**：`nums[mid:]` 会把根节点重复放进右子树，必须是 `nums[mid + 1:]`。
> - **用 `list.pop(0)` 当队列**：这是 $O(n)$ 操作，会把整体拖到 $O(n^2)$；层序建树请用 `deque.popleft()`。
> - **切片建 BST 的隐藏空间**：`nums[:mid]` 每层都复制数组，空间从 $O(\log n)$ 悄悄涨到 $O(n \log n)$，大数据量下改传下标区间。

---

## 复杂度

> [!summary]- 复杂度
> 
> - 核心操作：由下标求父子为 $O(1)$，因为只是一次算术运算。
> - 完整流程：三种建树法都是 $O(n)$，因为每个元素只被访问、建成节点一次。
> - 额外空间：$O(h)$ 递归栈（$h$ 为树高，平衡时 $O(\log n)$、退化时 $O(n)$）；层序法额外 $O(n)$ 队列；返回的树结构本身 $O(n)$ 不计入"额外空间"。

---

## 一句话总结

数组转树的本质是**用一套下标/切分规则把线性顺序解释成父子关系**；触发信号是"给 `list` 要 `TreeNode`"；最关键写法是完全二叉树用 `2i+1 / 2i+2`、有序数组取 `len//2`、层序序列用 `deque`。

## 模板归纳

看到以下信号时，优先想到"数组转树"：

- 题面出现"完全二叉树 / 堆 / 数组表示的树"，且数组无空洞 → 下标公式。
- 给定**有序数组**并要求"高度平衡的 BST" → 取中点递归。
- 输入是形如 `[3, 9, 20, null, null, 15, 7]` 的**层序序列** → 队列反序列化。

```python
# 可直接复用的最小模板：层序序列（含 None）→ 树
from collections import deque

def build_tree(data):
    if not data or data[0] is None:
        return None
    root = TreeNode(data[0])
    queue = deque([root])
    i = 1
    while queue and i < len(data):
        node = queue.popleft()
        if i < len(data) and data[i] is not None:   # 左孩子
            node.left = TreeNode(data[i])
            queue.append(node.left)
        i += 1
        if i < len(data) and data[i] is not None:   # 右孩子
            node.right = TreeNode(data[i])
            queue.append(node.right)
        i += 1
    return root
```
