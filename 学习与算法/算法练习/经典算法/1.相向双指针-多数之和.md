
# 相向双指针：Two Sum II 与 3Sum

## 1. 这类题在解决什么问题？

相向双指针一般用于解决这类问题：

> 在一个有序数组中，找若干个数，使它们的和满足某个条件。

最典型的问题包括：

- `Two Sum II`
    
    - 给定一个已经升序排列的数组，找两个数，使它们的和等于 `target`
        
- `3Sum`
    
    - 给定一个数组，找所有不重复的三元组，使三个数之和等于 `0`
        

这类问题的核心不是“枚举所有组合”，而是利用排序后的单调性减少搜索空间。

---

## 2. 什么是相向双指针？

相向双指针，英文一般叫做 `two pointers from both ends`。

它的基本形式是：

```python
left = 0
right = len(nums) - 1

while left < right:
    s = nums[left] + nums[right]

    if s == target:
        # 找到答案
    elif s < target:
        left += 1
    else:
        right -= 1
```

其中：

- `left` 指向当前最小值
    
- `right` 指向当前最大值
    
- 每次计算 `nums[left] + nums[right]`
    
- 根据这个和与目标值的关系移动指针
    

---

## 3. 为什么数组必须有序？

相向双指针依赖一个关键前提：

> 数组有序之后，移动左指针会让当前和变大，移动右指针会让当前和变小。

假设数组是非递减排序：

$$  
nums[0] \le nums[1] \le nums[2] \le \cdots \le nums[n-1]  
$$

当前有两个指针：

$$  
left < right  
$$

当前和为：

$$  
s = nums[left] + nums[right]  
$$

如果：

$$  
s < target  
$$

说明当前和太小。

因为 `nums[right]` 已经是当前右侧能取到的较大值了，如果还不够大，那么只能增大左边的数：

$$  
left = left + 1  
$$

这样新的和大概率变大：

$$  
nums[left + 1] + nums[right] \ge nums[left] + nums[right]  
$$

如果：

$$  
s > target  
$$

说明当前和太大。

这时应该减小右边的数：

$$  
right = right - 1  
$$

因为：

$$  
nums[left] + nums[right - 1] \le nums[left] + nums[right]  
$$

这就是相向双指针正确性的基础。

## 4. Two Sum II：输入有序数组

### 4.1 问题描述

LeetCode 167：`Two Sum II - Input Array Is Sorted`

给定一个从下标 `1` 开始的整数数组 `numbers`，数组已经按照非递减顺序排列。

要求找到两个数，使得：

$$  
numbers[index_1] + numbers[index_2] = target  
$$

并且满足：

$$  
1 \le index_1 < index_2 \le numbers.length  
$$

返回：

```python
[index1, index2]
```

注意：

- 输入数组已经有序
    
- 每个输入只对应唯一答案
    
- 不能重复使用同一个元素
    
- 只能使用常量级额外空间
    

---

## 5. Two Sum II 的思路

### 5.1 暴力解法

最直接的做法是两层循环：

```python
for i in range(n):
    for j in range(i + 1, n):
        if numbers[i] + numbers[j] == target:
            return [i + 1, j + 1]
```

时间复杂度：

$$  
O(n^2)  
$$

空间复杂度：

$$  
O(1)  
$$

问题是：虽然空间满足要求，但时间太慢。

---

### 5.2 相向双指针解法

因为数组已经有序，所以可以用双指针。

初始状态：

```python
left = 0
right = len(numbers) - 1
```

每次计算：

$$  
s = numbers[left] + numbers[right]  
$$

然后判断：

### 情况一：当前和等于目标值

$$  
s = target  
$$

说明找到了答案，返回：

```python
[left + 1, right + 1]
```

因为题目要求下标从 `1` 开始，而 Python 下标从 `0` 开始。

---

### 情况二：当前和太大

$$  
s > target  
$$

说明右边这个数太大了。

由于数组已经排序，继续保留 `right` 只会让和偏大，所以应该让右指针左移：

```python
right -= 1
```

---

### 情况三：当前和太小

$$  
s < target  
$$

说明左边这个数太小了。

因为当前最大的右端都不够，所以需要增大左端：

```python
left += 1
```

---

## 6. Two Sum II 代码

```python
class Solution(object):
    def twoSum(self, numbers, target):
        """
        :type numbers: List[int]
        :type target: int
        :rtype: List[int]
        """
        left = 0
        right = len(numbers) - 1

        while left < right:
            s = numbers[left] + numbers[right]

            if s == target:
                return [left + 1, right + 1]
            elif s > target:
                right -= 1
            else:
                left += 1
```

---

## 7. Two Sum II 示例推演

给定：

```python
numbers = [2, 7, 11, 15]
target = 9
```

初始：

```python
left = 0
right = 3
```

对应：

$$  
numbers[left] = 2  
$$

$$  
numbers[right] = 15  
$$

当前和：

$$  
2 + 15 = 17  
$$

因为：

$$  
17 > 9  
$$

所以右指针左移：

```python
right = 2
```

现在：

$$  
2 + 11 = 13  
$$

仍然大于 `9`，继续右移：

```python
right = 1
```

现在：

$$  
2 + 7 = 9  
$$

找到答案。

返回：

```python
[1, 2]
```

---

## 8. Two Sum II 复杂度分析

每一次循环，`left` 或 `right` 至少移动一次。

两个指针最多共同移动 `n` 次，所以时间复杂度是：

$$  
O(n)  
$$

只使用了几个变量，所以空间复杂度是：

$$  
O(1)  
$$

# 3Sum：三数之和

## 9. 3Sum 问题描述

LeetCode 15：`3Sum`

给定一个整数数组 `nums`，判断是否存在三元组：

$$  
[nums[i], nums[j], nums[k]]  
$$

满足：

$$  
i \ne j  
$$

$$  
i \ne k  
$$

$$  
j \ne k  
$$

并且：

$$  
nums[i] + nums[j] + nums[k] = 0  
$$

返回所有和为 `0` 且不重复的三元组。

---

## 10. 3Sum 和 Two Sum 的关系

`3Sum` 本质上可以转化成很多个 `Two Sum`。

对于三数之和：

$$  
a + b + c = 0  
$$

如果先固定一个数：

$$  
a = nums[i]  
$$

那么问题就变成：

$$  
b + c = -a  
$$

也就是说：

> 固定一个数，然后在它右边的区间里找两个数，使它们的和等于 `-a`。

所以 `3Sum` 的结构是：

```text
排序
固定第一个数
在剩余区间使用 Two Sum 双指针
去重
```

---

## 11. 为什么 3Sum 需要先排序？

排序有两个作用：

### 作用一：让双指针成立

排序之后，可以根据当前三数之和移动左右指针。

如果当前和太大：

$$  
nums[i] + nums[j] + nums[k] > 0  
$$

说明右边的 `nums[k]` 太大，应该让 `k` 左移。

如果当前和太小：

$$  
nums[i] + nums[j] + nums[k] < 0  
$$

说明左边的 `nums[j]` 太小，应该让 `j` 右移。

---

### 作用二：方便去重

排序之后，相同的数字会挨在一起。

例如：

```python
nums = [-1, -1, -1, 0, 1, 2]
```

如果已经用过第一个 `-1` 作为固定值，那么后面的相同 `-1` 不需要再次作为固定值，否则会产生重复答案。

---

## 12. 3Sum 的基本流程

### 第一步：排序

```python
nums.sort()
```

排序后：

$$  
nums[0] \le nums[1] \le \cdots \le nums[n-1]  
$$

---

### 第二步：枚举第一个数

```python
for i in range(n - 2):
    x = nums[i]
```

为什么是 `n - 2`？

因为三元组至少需要三个数：

```text
i, j, k
```

其中：

```python
j = i + 1
k = n - 1
```

所以 `i` 最多只能到 `n - 3`。

---

### 第三步：跳过重复的固定值

```python
if i > 0 and nums[i] == nums[i - 1]:
    continue
```

为什么要跳过？

假设数组是：

```python
[-1, -1, 0, 1]
```

如果第一个 `-1` 已经作为固定值找过答案，那么第二个 `-1` 再作为固定值时，会找到重复的三元组。

所以当：

$$  
nums[i] = nums[i - 1]  
$$

说明当前固定值已经处理过，直接跳过。

---

### 第四步：在右侧区间做 Two Sum

固定：

```python
x = nums[i]
```

然后设置：

```python
j = i + 1
k = n - 1
```

当前和：

$$  
s = x + nums[j] + nums[k]  
$$

如果：

$$  
s > 0  
$$

说明和太大，让右指针左移：

```python
k -= 1
```

如果：

$$  
s < 0  
$$

说明和太小，让左指针右移：

```python
j += 1
```

如果：

$$  
s = 0  
$$

说明找到一个答案：

```python
ans.append([x, nums[j], nums[k]])
```

然后继续移动 `j` 和 `k`，寻找下一个不重复答案。

---

## 13. 3Sum 的剪枝优化

排序后，可以提前判断某些情况不可能有答案。

---

### 13.1 最小和都大于 0，直接结束

固定当前数：

```python
x = nums[i]
```

由于数组有序，当前能取到的最小三数和是：

$$  
x + nums[i + 1] + nums[i + 2]  
$$

如果：

$$  
x + nums[i + 1] + nums[i + 2] > 0  
$$

说明即使取后面最小的两个数，和也已经大于 `0`。

后面的 `x` 只会更大，所以之后不可能再出现和为 `0` 的三元组。

因此可以直接：

```python
break
```

---

### 13.2 最大和都小于 0，跳过当前固定值

当前固定值为：

```python
x = nums[i]
```

当前能取到的最大三数和是：

$$  
x + nums[n - 2] + nums[n - 1]  
$$

如果：

$$  
x + nums[n - 2] + nums[n - 1] < 0  
$$

说明即使用最大的两个数，和仍然小于 `0`。

这代表当前 `x` 太小，不可能组成答案。

因此跳过当前 `i`：

```python
continue
```

---

## 14. 3Sum 完整代码

```python
class Solution(object):
    def threeSum(self, nums):
        """
        :type nums: List[int]
        :rtype: List[List[int]]
        """
        nums.sort()
        ans = []
        n = len(nums)

        for i in range(n - 2):
            x = nums[i]

            # 去重：固定值不能重复
            if i > 0 and x == nums[i - 1]:
                continue

            # 剪枝 1：最小三数和已经大于 0，后面不可能有答案
            if x + nums[i + 1] + nums[i + 2] > 0:
                break

            # 剪枝 2：最大三数和仍然小于 0，当前 x 太小
            if x + nums[n - 2] + nums[n - 1] < 0:
                continue

            j = i + 1
            k = n - 1

            while j < k:
                s = x + nums[j] + nums[k]

                if s > 0:
                    k -= 1
                elif s < 0:
                    j += 1
                else:
                    ans.append([x, nums[j], nums[k]])

                    # 移动左指针，并跳过重复值
                    j += 1
                    while j < k and nums[j] == nums[j - 1]:
                        j += 1

                    # 移动右指针，并跳过重复值
                    k -= 1
                    while j < k and nums[k] == nums[k + 1]:
                        k -= 1

        return ans
```

## 15. 3Sum 示例推演

给定：

```python
nums = [-1, 0, 1, 2, -1, -4]
```

排序后：

```python
nums = [-4, -1, -1, 0, 1, 2]
```

---

### 第一轮：固定 `x = -4`

```python
i = 0
x = -4
j = 1
k = 5
```

当前：

$$  
s = -4 + (-1) + 2 = -3  
$$

因为：

$$  
s < 0  
$$

说明和太小，移动左指针：

```python
j += 1
```

继续尝试，仍然无法得到 `0`。

---

### 第二轮：固定 `x = -1`

```python
i = 1
x = -1
j = 2
k = 5
```

当前：

$$  
s = -1 + (-1) + 2 = 0  
$$

找到答案：

```python
[-1, -1, 2]
```

然后移动并去重。

继续：

```python
j = 3
k = 4
```

当前：

$$  
s = -1 + 0 + 1 = 0  
$$

找到答案：

```python
[-1, 0, 1]
```

---

### 第三轮：固定第二个 `-1`

```python
i = 2
x = -1
```

因为：

```python
nums[i] == nums[i - 1]
```

说明这个固定值已经处理过，所以跳过。

最终结果：

```python
[[-1, -1, 2], [-1, 0, 1]]
```

## 16. 3Sum 复杂度分析

排序需要：

$$  
O(n \log n)  
$$

外层循环最多执行：

$$  
O(n)  
$$

每一轮内部双指针最多移动：

$$  
O(n)  
$$

所以主过程是：

$$  
O(n^2)  
$$

总时间复杂度：

$$  
O(n \log n) + O(n^2) = O(n^2)  
$$

空间复杂度：

如果不考虑输出答案，排序之外只使用了常量级变量：

$$  
O(1)  
$$

如果考虑排序的内部栈空间，取决于语言和排序实现。

# 17. 通用模板：排序 + 固定 + 双指针

多数之和问题可以用这样的思路理解：

## 17.1 Two Sum

```text
两个数之和
```

如果数组已经有序，直接双指针。

---

## 17.2 3Sum

```text
固定一个数，把问题变成 Two Sum
```

公式：

$$  
a + b + c = target  
$$

固定：

$$  
a = nums[i]  
$$

则：

$$  
b + c = target - a  
$$

---

## 17.3 4Sum

```text
固定两个数，把问题变成 Two Sum
```

公式：

$$  
a + b + c + d = target  
$$

固定：

$$  
a = nums[i]  
$$

$$  
b = nums[j]  
$$

则：

$$  
c + d = target - a - b  
$$

## 18. 多数之和的核心递归思想

`kSum` 可以抽象成：

```text
kSum = 固定一个数 + 求 k-1 Sum
```

直到最后变成：

```text
2Sum = 双指针
```

也就是：

```text
4Sum
= 固定一个数 + 3Sum

3Sum
= 固定一个数 + 2Sum

2Sum
= 相向双指针
```

这就是多数之和问题的核心结构。

# 20. 核心结论

1. 相向双指针成立的前提是数组有序。
    
2. 对于有序数组中的 Two Sum，如果当前和太小，移动左指针；如果当前和太大，移动右指针。
    
3. Two Sum II 的时间复杂度是：
    

$$  
O(n)  
$$

4. 3Sum 的本质是：
    

```text
固定一个数 + 在剩余区间做 Two Sum
```

5. 3Sum 必须处理去重，否则会出现重复三元组。
    
6. 3Sum 的时间复杂度是：
    

$$  
O(n^2)  
$$

7. 多数之和问题的通用思路是：
    

```text
排序 -> 固定若干个数 -> 最后转化成 Two Sum 双指针
```

# 21. 常见误区

## 误区一：没有排序就使用相向双指针

相向双指针依赖单调性。

如果数组没有排序，那么：

```python
left += 1
```

不一定会让和变大。

```python
right -= 1
```

也不一定会让和变小。

所以没有排序时，不能直接套这个模板。

---

## 误区二：3Sum 找到答案后只移动一个指针

找到答案后：

```python
ans.append([x, nums[j], nums[k]])
```

应该继续移动指针寻找下一个答案。

一般写法是：

```python
j += 1
k -= 1
```

然后分别跳过重复值。

如果只移动一个指针，也能运行，但更容易写出重复答案或遗漏逻辑。

---

## 误区三：只对固定值去重，不对左右指针去重

3Sum 需要三层去重：

```text
固定值 x 去重
左指针 j 去重
右指针 k 去重
```

固定值去重避免重复枚举同一个 `x`。

左右指针去重避免重复加入相同三元组。

---

## 误区四：不理解 `break` 和 `continue` 的区别

在 3Sum 剪枝中：

```python
if x + nums[i + 1] + nums[i + 2] > 0:
    break
```

这里用 `break`，因为当前最小和已经大于 `0`，后面的固定值只会更大，所以整体结束。

```python
if x + nums[n - 2] + nums[n - 1] < 0:
    continue
```

这里用 `continue`，因为只是当前 `x` 太小，后面的 `x` 变大后仍然可能有答案。

---

## 误区五：忘记 LeetCode 167 返回的是 1-based index

Python 数组下标从 `0` 开始。

但是 LeetCode 167 要求返回从 `1` 开始的下标，所以返回时要写：

```python
return [left + 1, right + 1]
```

而不是：

```python
return [left, right]
```

---

## 误区六：认为双指针一定是 $O(n^2)$

对于 Two Sum II：

$$  
O(n)  
$$

因为两个指针总共最多移动 `n` 次。

对于 3Sum：

$$  
O(n^2)  
$$

因为外层固定一个数是 $O(n)$，内层双指针是 $O(n)$。

所以复杂度取决于外面固定了多少层。
