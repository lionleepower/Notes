
# OpenMP Introduction

## 1. 本节核心总结

OpenMP 是一种用于 **shared-memory parallel programming** 的[[academic_words#API|API]] specification，主要用于在单台多核机器上编写多线程并行程序。  
它常用于 High Performance Computing，即 [[academic_words#hpc|hpc]]，可以让程序在一个节点上的多个 CPU cores 同时执行计算任务。  
OpenMP 本身主要解决 **单节点多核并行** 问题；如果要在多个节点之间并行计算，通常还需要 MPI。  
当 OpenMP 和 MPI 结合使用时，称为 **hybrid programming**，可以同时利用多节点和每个节点内部的多核资源。

## 3. OpenMP 是什么？

OpenMP 是一种 **parallel programming API specification**。

它不是一种新的编程语言，而是一套可以嵌入 C、C++ 或 Fortran 程序中的并行编程接口。

在 C/C++ 中，OpenMP 通常通过 `#pragma omp` 指令使用，例如：

```c
#pragma omp parallel
{
    // code executed by multiple threads
}
````

简单来说，OpenMP 的作用是：

> 让程序员用较少的代码，把原本串行执行的程序改成多线程并行执行。

---

## 4. OpenMP 主要用于什么场景？

OpenMP 主要用于 **shared-memory computers**，也就是共享内存计算机。

在这种机器中，多个 CPU cores 可以访问同一块主内存。

```text
Single Node
├── Core 0
├── Core 1
├── Core 2
├── Core 3
└── Shared Memory
```

所以 OpenMP 很适合在单个节点上使用多个 CPU cores 来并行执行任务。

常见应用包括：

|应用场景|说明|
|---|---|
|Scientific Computing|科学计算|
|Matrix Operations|矩阵计算|
|Stencil Computation|模板计算|
|Numerical Simulation|数值模拟|
|Data Processing|数据处理|
|HPC Applications|高性能计算应用|

---

## 5. OpenMP 和 HPC 的关系

HPC，全称是 **High Performance Computing**，即高性能计算。

HPC 的目标是利用大量计算资源加速复杂问题的求解，例如：

- 天气模拟
    
- 流体力学
    
- 分子动力学
    
- 大规模矩阵计算
    
- 机器学习训练
    
- 科学仿真
    

OpenMP 在 HPC 中的作用是：

> 充分利用一个计算节点内部的多个 CPU cores，让同一个程序的不同部分可以同时运行。

也就是说，OpenMP 更偏向于 **node-level parallelism**，即节点内部的并行。

---

## 6. OpenMP 的核心并行模型

OpenMP 使用的是 **thread-based parallelism**。

程序开始时通常只有一个主线程，称为 **master thread** 或 **initial thread**。

当程序进入 OpenMP parallel region 时，会创建多个线程共同执行代码。

```text
Before parallel region:

Master Thread

Inside parallel region:

Thread 0
Thread 1
Thread 2
Thread 3
```

对应代码示例：

```c
#include <stdio.h>
#include <omp.h>

int main() {
    #pragma omp parallel
    {
        int id = omp_get_thread_num();
        printf("Hello from thread %d\n", id);
    }

    return 0;
}
```

这段程序中，`#pragma omp parallel` 会让多个线程同时执行大括号中的代码。

---

## 7. OpenMP 的限制

虽然 OpenMP 很方便，但它主要适合单个多核节点。

原因是 OpenMP 假设线程之间可以访问同一块内存。

如果计算资源分布在多个节点上，例如 HPC 集群：

```text
Node 0: Memory 0
Node 1: Memory 1
Node 2: Memory 2
Node 3: Memory 3
```

不同节点之间通常没有共享内存，所以 OpenMP 不能单独完成多节点通信。

这时就需要 MPI。

---

## 8. OpenMP 和 MPI 的区别

|对比点|OpenMP|MPI|
|---|---|---|
|并行模型|Shared-memory parallelism|Distributed-memory parallelism|
|基本单位|Threads|Processes|
|通信方式|通过共享变量隐式通信|通过 message passing 显式通信|
|主要范围|单节点内部|多节点之间|
|编程难度|相对较低|相对较高|
|典型用法|多核 CPU 并行|集群并行|
|常见关键词|`#pragma omp parallel`|`MPI_Send`, `MPI_Recv`|

简单理解：

> OpenMP 管一个节点内部的多个 cores，MPI 管多个节点之间的数据通信。

---

## 9. 什么是 Hybrid Programming？

当 OpenMP 和 MPI 结合使用时，称为 **hybrid programming**。

这种模式通常用于 HPC 集群。

典型结构是：

```text
Cluster
├── Node 0
│   ├── MPI Process 0
│   │   ├── OpenMP Thread 0
│   │   ├── OpenMP Thread 1
│   │   └── OpenMP Thread 2
│
├── Node 1
│   ├── MPI Process 1
│   │   ├── OpenMP Thread 0
│   │   ├── OpenMP Thread 1
│   │   └── OpenMP Thread 2
```

在 hybrid programming 中：

- MPI 负责不同节点之间的通信
    
- OpenMP 负责每个节点内部多个 cores 的并行计算
    

可以总结为：

> MPI between nodes, OpenMP within each node.

---

## 10. 为什么需要 OpenMP？

OpenMP 的主要价值在于：

|原因|解释|
|---|---|
|利用多核 CPU|现代 CPU 通常有多个 cores，不并行就会浪费资源|
|编程相对简单|通过 compiler directives 就可以并行化代码|
|适合逐步优化|可以先写串行代码，再逐步加入 OpenMP|
|常用于 HPC|很多科学计算程序可以通过 OpenMP 加速|
|可与 MPI 结合|可以扩展到 hybrid parallel programming|

## 11. 一个简单理解例子

假设有一个数组求和程序：

```c
double sum = 0.0;

for (int i = 0; i < n; i++) {
    sum += a[i];
}
```

串行情况下，只有一个线程从头加到尾。

使用 OpenMP 后，可以让多个线程分工：

```c
double sum = 0.0;

#pragma omp parallel for reduction(+:sum)
for (int i = 0; i < n; i++) {
    sum += a[i];
}
```

理解方式：

```text
Thread 0: 计算一部分数组
Thread 1: 计算一部分数组
Thread 2: 计算一部分数组
Thread 3: 计算一部分数组

最后把每个线程的局部结果合并成 sum
```

这里的 `reduction(+:sum)` 用来安全地合并多个线程的求和结果。

## 12. 本节可以记住的英文表达

### OpenMP 定义

OpenMP is an API specification for parallel programming on shared-memory computers.

### OpenMP 的用途

OpenMP allows programmers to develop threaded parallel applications that can use multiple cores on a single node.

### OpenMP 和 MPI 的关系

OpenMP is mainly used for shared-memory parallelism within a node, while MPI is used for communication between nodes in a distributed-memory system.

### Hybrid Programming

Hybrid programming combines MPI and OpenMP to exploit both inter-node and intra-node parallelism.
