下面这张可以直接放进 Obsidian，作为 MAP 常用参数速查表。

| 参数 / 写法                      | 属于哪一层         | 作用                                  | 常见写法                                         | 备注                                |
| ---------------------------- | ------------- | ----------------------------------- | -------------------------------------------- | --------------------------------- |
| `map`                        | MAP           | 启动 Linaro Forge MAP，对程序进行 profiling | `map --profile ./my_program`                 | MAP 命令本体                          |
| `--profile`                  | MAP           | 开始性能采样，生成 `.map` profiling 文件       | `map --profile ./ex2`                        | 实战中最常用                            |
| `-n <N>`                     | MAP           | 指定总 MPI rank 数                      | `map -n 32`                                  | 通常等于 `nodes × ntasks-per-node`    |
| `--mpi=slurm`                | MAP           | 告诉 MAP 使用 Slurm 启动 MPI 程序           | `--mpi=slurm`                                | 在 Slurm 集群上常用                     |
| `--mpiargs="..."`            | MAP → Slurm   | 把参数传给 Slurm / srun                  | `--mpiargs="--nodes=2 --ntasks-per-node=16"` | Slurm 参数不要直接写成 MAP 参数             |
| `--connect`                  | MAP           | 连接到 GUI 或远程调试/分析会话                  | `map --connect ./my_program`                 | 需要交互式分析时可能用                       |
| `--output <file>`            | MAP           | 指定 MAP 输出文件名                        | `--output run_2nodes_16ranks.map`            | 有些系统/版本支持，具体以 `map --help` 为准     |
| `--help`                     | MAP           | 查看 MAP 命令帮助                         | `map --help`                                 | 参数不确定时先查它                         |
| `--version`                  | MAP           | 查看 Forge / MAP 版本                   | `map --version`                              | 方便记录实验环境                          |
| `--nodes=<N>`                | Slurm / srun  | 指定使用多少个节点                           | `--mpiargs="--nodes=2"`                      | 放进 `--mpiargs`                    |
| `--ntasks-per-node=<R>`      | Slurm / srun  | 每个节点启动多少个 MPI rank                  | `--mpiargs="--ntasks-per-node=16"`           | `R` 是每节点 rank 数                   |
| `--cpus-per-task=<T>`        | Slurm / srun  | 每个 MPI rank 分配多少 CPU core           | `--mpiargs="--cpus-per-task=8"`              | 通常要等于 `OMP_NUM_THREADS`           |
| `--exact`                    | Slurm / srun  | 要求 Slurm 精确按照指定资源启动任务               | `--mpiargs="--exact"`                        | 避免资源布局和预期不一致                      |
| `--hint=nomultithread`       | Slurm / srun  | 尽量不用超线程，优先使用物理核心                    | `--mpiargs="--hint=nomultithread"`           | HPC profiling 常用                  |
| `--distribution=block:block` | Slurm / srun  | 控制 task 的分布方式                       | `--mpiargs="--distribution=block:block"`     | 常用于让 rank 分布更可控                   |
| `OMP_NUM_THREADS=<T>`        | OpenMP        | 控制每个 MPI rank 内部开启多少线程              | `export OMP_NUM_THREADS=8`                   | 不是 MAP 参数，但 hybrid profiling 必须关注 |
| `SRUN_CPUS_PER_TASK=<T>`     | Slurm 环境变量    | 告诉 `srun` 每个 task 使用多少 CPU          | `export SRUN_CPUS_PER_TASK=8`                | 通常和 `--cpus-per-task` 保持一致        |
| `< /dev/null`                | Shell         | 不给程序交互输入，避免作业卡住                     | `./ex2 < /dev/null`                          | 放在整条命令后面                          |
| `                            | tee "${LOG}"` | Shell                               | 输出同时显示到屏幕并保存到日志                              | `                                 |
| `-m <M>`                     | PETSc / ex2   | 设置 PETSc `ex2` 的问题规模参数之一            | `-m 6400`                                    | 放在可执行程序后面                         |
| `-n <N>`                     | PETSc / ex2   | 设置 PETSc `ex2` 的问题规模参数之一            | `-n 6400`                                    | 注意和 `map -n` 不是一回事                |
| `-log_view`                  | PETSc         | 输出 PETSc 性能日志                       | `./ex2 -log_view`                            | 分析 PETSc 内部耗时常用                   |
| `-ksp_converged_reason`      | PETSc         | 输出 KSP 迭代收敛原因                       | `./ex2 -ksp_converged_reason`                | 用来确认求解是否正常收敛                      |
| `-ksp_type <type>`           | PETSc         | 指定 Krylov 求解器类型                     | `-ksp_type cg`                               | 例如 `cg`、`gmres`                   |
| `-pc_type <type>`            | PETSc         | 指定预条件器类型                            | `-pc_type gamg`                              | 例如 `gamg`、`jacobi`、`hypre`        |
| `-ksp_rtol <value>`          | PETSc         | 设置相对收敛容差                            | `-ksp_rtol 1e-5`                             | 控制收敛精度                            |
| `-ksp_atol <value>`          | PETSc         | 设置绝对收敛容差                            | `-ksp_atol 1e-10`                            | 控制收敛精度                            |

## 最常用组合

```bash
map -n "${MAP_RANKS}" \
    --mpi=slurm \
    --mpiargs="--nodes=${NODES} --ntasks-per-node=${R} --cpus-per-task=${T} --exact --hint=nomultithread --distribution=block:block" \
    --profile \
    "${PETSC_DIR}/src/ksp/ksp/tutorials/ex2" \
    -m "${M}" -n "${N}" \
    -ksp_converged_reason -log_view \
    -ksp_type cg \
    -pc_type gamg \
    -ksp_rtol 1e-5 -ksp_atol 1e-10 \
  < /dev/null \
  | tee "${LOG}"
```

## 记忆版

```text
map 参数：控制 MAP 怎么 profiling
--mpiargs：控制 Slurm 怎么启动 MPI ranks
export OMP_NUM_THREADS：控制每个 rank 开多少 OpenMP threads
ex2 后面的参数：控制 PETSc 程序怎么计算
shell 重定向和 tee：控制输入输出和日志
```
