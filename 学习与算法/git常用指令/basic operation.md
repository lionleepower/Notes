# Git 指令速查表

|目的|指令|
|---|---|
|查看状态|`git status`|
|添加所有修改|`git add .`|
|提交修改|`git commit -m "message"`|
|推送到远程|`git push`|
|拉取远程更新|`git pull`|
|克隆仓库|`git clone <url>`|
|查看历史|`git log --oneline`|
|查看差异|`git diff`|
|查看分支|`git branch`|
|创建并切换分支|`git switch -c <branch>`|
|切换分支|`git switch <branch>`|
|合并分支|`git merge <branch>`|
|临时保存修改|`git stash`|
|恢复临时修改|`git stash pop`|
|取消暂存|`git restore --staged <file>`|
|放弃本地修改|`git restore <file>`|
|查看远程地址|`git remote -v`|
|强制推送|`git push --force-with-lease`|
