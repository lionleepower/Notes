# 正则 零宽断言 Lookaround

> [!abstract] 一句话 Lookaround（环视 / 零宽断言 zero-width assertion）是「站在某个位置往左或往右看一眼、做个检查」的构件。检查通过才放行，但它**本身不吃掉任何字符**——所以叫「零宽」。常用来卡边界、排除粘连。

相关：[[正则表达式 Regex 速查]] · [[re 模块]] · [[数据清洗]]

---

## 四种写法 The Four Forms

> [!important]- 必背 记忆法：`<` 表示往**左**看（behind），没有 `<` 就是往**右**看（ahead）；`=` 是「必须是」，`!` 是「必须不是」。

|写法|名称|看哪边|含义|
|---|---|---|---|
|`(?=...)`|先行 lookahead|右边|右边**必须是** …|
|`(?!...)`|否定先行 negative lookahead|右边|右边**必须不是** …|
|`(?<=...)`|后顾 lookbehind|左边|左边**必须是** …|
|`(?<!...)`|否定后顾 negative lookbehind|左边|左边**必须不是** …|

---

## 核心特性：零宽 Zero-Width

> [!warning]- 它不占字符，只做检查 lookaround 只是在当前位置「往旁边看一眼」，检查通过就放行，**不把看到的内容算进匹配结果**。
> 
> ```python
> import re
> # 匹配后面跟着 "元" 的数字，但 "元" 不算进结果
> re.findall(r"\d+(?=元)", "苹果5元，香蕉8斤，橘子12元")
> # ['5', '12']   ← 注意：没有 '元'，也没匹配到 8（后面是"斤"）
> ```
> 
> 对比普通写法 `\d+元` 会把「元」也吃进去 → `['5元', '12元']`。要「按条件筛选、但不把条件本身纳入结果」时，lookaround 正合适。

## 逐个例子 Worked Examples

> [!example]- 否定后顾：排除粘连的数字 匹配「独立的 4 位以上数字」，排除嵌在字母/数字里的（如型号 `A2024`）。
> 
> ```python
> re.findall(r"(?<![A-Za-z\d])\d{4,}", "订单 12345，产品 A2024，价格 9999")
> # ['12345', '9999']   ← A2024 里的 2024 被左边的 A 拦掉
> ```
> 
> `(?<![A-Za-z\d])` = 数字左边不能紧挨字母或数字。

> [!example]- 两头都卡：配成一对 左右都不许接字母/数字，彻底排除粘连（`A2024B` 这种）。
> 
> ```python
> r"(?<![A-Za-z\d])\d{4,}(?![A-Za-z\d])"
> ```

> [!example]- 后顾：提取货币金额（不要符号）
> 
> ```python
> re.findall(r"(?<=￥)\d+", "价格 ￥199 和 ￥2999")
> # ['199', '2999']   ← ￥ 只用来定位，不进结果
> ```

> [!example]- 先行 + 否定先行：密码强度校验（面试常见） 「至少 8 位，且必须同时含字母和数字」。
> 
> ```python
> r"^(?=.*[A-Za-z])(?=.*\d).{8,}$"
> ```
> 
> 三个断言叠在开头，各自独立检查一遍整串：`(?=.*[A-Za-z])` 保证有字母，`(?=.*\d)` 保证有数字，最后 `.{8,}` 才真正匹配长度。断言都零宽，所以能层层叠加不冲突。

## 易错点 Pitfalls

> [!danger]- 三个常踩的坑
> 
> 1. **零宽 = 不进结果**：匹配到的只有主体部分，断言里看到的字符不包含在内。想要那部分就别用断言，改用捕获组 [[正则表达式 Regex 速查|捕获组]]。
> 2. **`(?<...)` 后顾在某些引擎要求定长**：Python `re` 的 lookbehind **必须是固定长度**，`(?<=\d{2})` 可以，`(?<=\d+)` 会报错。需要变长后顾要用 `regex` 第三方库。
> 3. **和非捕获组别搞混**：`(?:...)` 是分组不提取（会吃字符），`(?=...)` 是断言（不吃字符）。虽然都以 `(?` 开头，作用完全不同。

---

## 什么时候用 When to Reach for It

> [!tip]- 判断信号 当你想说「匹配 A，**但前提是**它旁边是/不是 B，而且 B 不要出现在结果里」时，就是 lookaround 的场景。典型：卡单词边界、按上下文筛选、多条件校验（如密码规则）。日常匹配用不到，属进阶但很好使的工具。
