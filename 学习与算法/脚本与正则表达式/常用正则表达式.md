# 正则表达式 Regex 速查

> [!abstract] 一句话
> 
> 正则（regular expression）是一套**独立于语言**的「文本匹配规则」，同一段规则复制到 Python / SQL / JavaScript / grep 里逻辑一致。语言只是通过各自的引擎（Python 里是 [[re 模块]]）把它接进来执行。

相关：[[re 模块]] · [[字符串处理]] · [[数据清洗]] · [[LeetCode 字符串题]]

## 核心构件 Core Building Blocks

> [!tip]- 心法 别背全表，先掌握这一小组，遇到需求现查现用。
> 
> 覆盖 90% 日常场景就靠下面几类。复杂的（lookaround、回溯性能）用到再补。

### 字符类 Character Classes

|符号|含义|等价写法|
|---|---|---|
|`\d`|一个数字 digit|`[0-9]`|
|`\D`|非数字|`[^0-9]`|
|`\w`|字母/数字/下划线 word char|`[a-zA-Z0-9_]`|
|`\W`|非 word char|`[^a-zA-Z0-9_]`|
|`\s`|空白 whitespace（空格、Tab、换行）|`[ \t\n\r\f]`|
|`\S`|非空白|—|
|`.`|任意字符（默认不含换行）|—|
|`[abc]`|a、b 或 c 中任一个（字符集 character set）|—|
|`[^abc]`|除 a、b、c 外的任一个（取反）|—|
|`[a-z]`|范围 range，小写字母|—|

### 数量词 Quantifiers

|符号|含义|
|---|---|
|`+`|一个或多个 one or more|
|`*`|零个或多个 zero or more|
|`?`|零个或一个 optional|
|`{3}`|恰好 3 次|
|`{2,5}`|2 到 5 次|
|`{2,}`|至少 2 次|

> [!warning]- 贪婪 vs 懒惰 Greedy vs Lazy（面试高频陷阱）
> 
> 数量词**默认贪婪**（greedy）——尽可能多匹配。加 `?` 变懒惰（lazy）——尽可能少匹配。
> 
> ```python
> import re
> text = "<a><b>"
> re.search(r"<.+>",  text).group()  # '<a><b>'  贪婪，吃到最后一个 >
> re.search(r"<.+?>", text).group()  # '<a>'     懒惰，遇到第一个 > 就停
> ```

### 位置锚点 Anchors

|符号|含义|
|---|---|
|`^`|字符串开头 start|
|`$`|字符串结尾 end|
|`\b`|单词边界 word boundary|
|`\B`|非单词边界|

### 分组与选择 Grouping & Alternation

|符号|含义|
|---|---|
|`(...)`|捕获组 capturing group，匹配内容可单独提取|
|`(?:...)`|非捕获组 non-capturing group，只分组不提取（省内存/不占编号）|
|`(?P<name>...)`|命名组 named group|
|`\|`|或 alternation，`cat\|dog` 匹配 cat 或 dog|
|`\1`|反向引用 backreference，指代第 1 个捕获组|

### 转义 Escaping

想匹配特殊字符**本身**，前面加 `\`：

```text
\.   \+   \*   \?   \(   \)   \[   \]   \\
```

> [!example]- 例：匹配文件名里的小数
> 
> ```python
> re.findall(r"\d+\.\d+", "v2.5 and 10.0.1")  # ['2.5', '10.0']
> #              ↑ 这个 \. 是「点本身」，不是「任意字符」
> ```

## Python 里怎么用 `re`

> [!note]- 五个最常用的函数
> 
> ```python
> import re
> 
> # search: 扫描整串，返回第一个匹配的 match object，找不到返回 None
> m = re.search(r"(\d+)kg", "包裹 25kg 和 3kg")
> m.group(0)   # '25kg'  整个匹配
> m.group(1)   # '25'    第 1 个捕获组
> 
> # match: 只从开头匹配（注意：不是全局扫描！）
> re.match(r"\d+", "25kg")   # 匹配到 '25'
> re.match(r"kg",  "25kg")   # None，因为开头不是 kg
> 
> # findall: 返回所有匹配，list of str
> re.findall(r"(\d+)kg", "25kg 和 3kg")   # ['25', '3']
> 
> # finditer: 返回所有匹配的 match object 迭代器（要位置信息时用）
> for m in re.finditer(r"\d+", "a1b22c"):
>     print(m.group(), m.start(), m.end())
> 
> # sub: 替换 substitute
> re.sub(r"\d+", "#", "a1b22c")   # 'a#b#c'
> ```

> [!danger]- 易错点（也是常考点）
> 
> 1. **`match` ≠ `search`**：`match` 只从**开头**匹配，`search` 扫描整串。
> 2. **匹配失败返回 `None`**：直接 `.group()` 会抛 `AttributeError`，一定先判断。
>     
>     ```python
>     m = re.search(pattern, text)if m:    print(m.group())
>     ```
>     
> 3. **`\d+` 只匹配整数**：`25.5` 会漏掉小数部分，需要 `\d+(?:\.\d+)?`。
> 4. **别忘了 raw string `r"..."`**：见下方说明。

## `r"..."` 到底是谁的语法？

> [!question]- raw string 归属 raw string 属于 Python，不属于正则。
> 
> `r"..."` 是 **Python 的字符串语法**，作用是「别让 Python 先处理反斜杠」。它跟正则没有关系——JavaScript、Java 写正则都没有这东西。
> 
> 之所以正则里几乎必配 raw string，是因为正则大量用 `\`。不加 `r`，`\d` 会先被 Python 当转义序列解释，容易踩坑。
> 
> ```python
> "\d"    # Python 会警告：无效转义（未来可能报错）
> r"\d"   # 干净地把两个字符 \ 和 d 交给正则引擎
> ```
> 
> **记忆锚**：引号 `""` 里的内容才是正则；引号外的 `re.search`、`r`、变量名全是 Python。

## 面试常见 Pattern（可直接抄）

> [!example]- 复制即用
> 
> ```python
> r"\d+"                      # 整数
> r"-?\d+(?:\.\d+)?"          # 带符号的整数或小数
> r"\b\w+@\w+\.\w+\b"         # 简易邮箱（够用，非严格 RFC）
> r"^\d{4}-\d{2}-\d{2}$"      # 日期 YYYY-MM-DD
> r"\s+"                      # 一段连续空白（常用于分词/清洗）
> r"(?:https?://)?[\w.-]+"    # 简易 URL
> ```
