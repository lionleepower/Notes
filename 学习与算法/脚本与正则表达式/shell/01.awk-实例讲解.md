# AWK 实例讲解：按行读取、按列处理、按条件统计

`awk` 是一个面向文本记录的处理工具：它逐行读取输入，把每一行拆成字段，再根据条件筛选、计算或重新输出。处理日志、空白分隔数据、结构简单的 CSV，以及 HPC 实验结果时尤其方便。

---

## 思路

只用 `grep` 可以找出满足条件的整行，但当任务变成“筛选状态为 `completed` 的记录，再取出运行时间并计算平均值”时，还需要识别字段和保存统计状态。`awk` 把“匹配记录”和“处理字段”放在同一套语法中，适合一次扫描完成这类任务。

> [!tip]- 核心思路
> `awk` 的处理模型可以记成：
>
> ```text
> 读取一行 → 拆成字段 → 判断 pattern → 执行 action
> ```
>
> 最常用的写法是：
>
> ```bash
> awk '条件 { 动作 }' 文件
> ```
>
> 如果有统计结果需要最后输出，再加上 `END`：
>
> ```bash
> awk '条件 { 逐行累积 } END { 输出结果 }' 文件
> ```

---

## 1. 基本结构

```bash
awk 'pattern { action }' file
```

- `pattern`：当前行需要满足的条件。
- `action`：条件成立后执行的动作。
- `file`：要读取的文件；也可以接收管道传来的标准输入。

> [!success]- 基础语法
> ```bash
> # 每一行都执行动作
> awk '{ print $0 }' file.txt
>
> # 只处理第 2 行及之后的内容
> awk 'NR > 1 { print $0 }' file.txt
>
> # 动作省略时，默认打印满足条件的整行
> awk 'NR > 1' file.txt
> ```

`print` 和 `print $0` 都表示打印当前整行。因此下面两条命令等价：

```bash
awk '$2 > 10 { print }' file.txt
awk '$2 > 10 { print $0 }' file.txt
```

## 2. 字段与常用内置变量

默认情况下，`awk` 把连续的空格或 Tab 当作字段分隔符。

假设 `results.txt` 的内容是：

```text
small    1    120.5
medium   4     35.2
large    8     20.1
```

每一行会被拆成三个字段：`$1`、`$2` 和 `$3`。

| 写法 | 含义 | 常见用途 |
| --- | --- | --- |
| `$0` | 当前整行 | 保留原始记录 |
| `$1`、`$2` | 当前行第 1、2 个字段 | 提取指定列 |
| `NF` | 当前行的字段总数 | 检查列数 |
| `$NF` | 当前行的最后一个字段 | 处理列数不固定的数据 |
| `NR` | 当前记录的累计行号 | 跳过表头、选择指定行 |
| `FNR` | 当前文件内的行号 | 同时处理多个文件时分别计数 |

> [!example]- 最小示例
> ```bash
> awk '{ print NR, $1, $NF }' results.txt
> ```
>
> 输出：
>
> ```text
> 1 small 120.5
> 2 medium 35.2
> 3 large 20.1
> ```

> [!warning]- `$1` 不是第 1 行
> `$1` 表示“当前行的第 1 个字段”；第几行要用 `NR` 判断：
>
> ```bash
> awk 'NR == 1 { print $0 }' file.txt
> ```

## 3. 条件、比较与正则匹配

| 条件 | 含义 | 示例 |
| --- | --- | --- |
| `/Time/` | 当前整行匹配正则 `Time` | `awk '/Time/' log.txt` |
| `$1 == "small"` | 第 1 个字段等于字符串 `small` | `awk '$1 == "small"' file.txt` |
| `$4 > 10` | 第 4 个字段在数值比较中大于 10 | `awk '$4 > 10' file.txt` |
| `$1 ~ /^small/` | 第 1 个字段匹配正则 | `awk '$1 ~ /^small/' file.txt` |
| `$1 !~ /^small/` | 第 1 个字段不匹配正则 | `awk '$1 !~ /^small/' file.txt` |
| `NR > 1 && $4 > 10` | 两个条件都成立 | 跳过表头并筛选数值 |
| `$1 == "small" \|\| $1 == "medium"` | 任意一个条件成立 | 选择两种规模 |

常见比较运算符包括 $==$、`!=`、`>`、`<`、`>=` 和 `<=`。

### 正则与普通字符串

`/.../` 和 `~ /.../` 使用正则表达式。`.`、`*`、`+`、`?`、`^`、`$`、`[]`、`()` 和 `|` 等字符可能具有特殊含义。

```bash
# 匹配字面量 Time (sec):，括号需要转义
awk '/Time \(sec\):/ { print $3 }' log.txt
```

如果只想查找固定字符串，可以使用 `index()`，避免处理大部分正则转义：

```bash
awk 'index($0, "Time (sec):") { print $3 }' log.txt
```

> [!warning]- 优先用单引号包住 AWK 程序
> 推荐：
>
> ```bash
> awk '{ print $3 }' file.txt
> ```
>
> 如果改用双引号，Shell 可能先展开 `$3`，导致 `awk` 收到错误的程序。需要从 Shell 变量向 AWK 传值时，优先使用 `-v`：
>
> ```bash
> limit=10
> awk -v max="$limit" '$2 <= max { print $0 }' file.txt
> ```

## 4. 分隔符与输出格式

### 指定输入分隔符

空白分隔文本不需要额外设置。对于简单的逗号分隔数据，可用 `-F,` 指定输入字段分隔符：

```bash
awk -F, '{ print $1, $4 }' results.csv
```

下面两种写法等价：

```bash
awk -F,  '{ print $1 }' results.csv
awk -F',' '{ print $1 }' results.csv
```

也可以在 `BEGIN` 中设置输入和输出分隔符：

```bash
awk 'BEGIN { FS = ","; OFS = "," } NR > 1 { print $1, $4 }' results.csv
```

这里：

- `FS`：输入字段分隔符。
- `OFS`：`print` 输出多个字段时使用的分隔符。

> [!warning]- `-F,` 不是完整的 CSV 解析器
> 它只是按每个逗号切分，不能正确处理字段内部带逗号、双引号或换行的标准 CSV，例如：
>
> ```csv
> "Smith, Alice",completed,12.5
> ```
>
> 遇到这类数据应使用 Python `csv`、Miller 等真正理解 CSV 引号规则的工具。

### `print` 与 `printf`

`print` 适合直接输出；`printf` 适合控制列宽、小数位和换行。

```bash
# print 会使用 OFS 分隔多个表达式
awk -F, '{ print $1, $4 }' results.csv

# printf 不会自动换行，需要显式写 \n
awk -F, 'NR > 1 { printf "%-12s runtime=%8.2f\n", $1, $4 }' results.csv
```

常用格式符：

| 格式 | 含义 |
| --- | --- |
| `%s` | 字符串 |
| `%d` | 整数 |
| `%f` | 浮点数 |
| `%.2f` | 保留两位小数 |
| `%-12s` | 左对齐、宽度为 12 的字符串 |
| `\n` | 换行 |

## 5. `BEGIN`、逐行处理与 `END`

一个完整的 AWK 程序可以分成三个阶段：

```bash
awk '
  BEGIN { 读取输入前执行一次 }
  条件  { 每个满足条件的输入行执行一次 }
  END   { 输入处理完后执行一次 }
' file
```

> [!example]- 执行顺序
> ```bash
> awk -F, '
>   BEGIN  { print "runtime values:" }
>   NR > 1 { print $4 }
>   END    { print "done" }
> ' results.csv
> ```

### 计数

```bash
awk -F, 'NR > 1 && $14 == "completed" { count++ }
         END { print count + 0 }' runtime_results.csv
```

`count++` 每匹配一行就加 1。`count + 0` 可以让没有任何匹配时明确输出 `0`。

### 求和与平均值

```bash
awk -F, '
  NR > 1 && $14 == "completed" {
    sum += $12
    count++
  }
  END {
    if (count > 0)
      printf "average runtime: %.2f\n", sum / count
    else
      print "no completed records"
  }
' runtime_results.csv
```

> [!tip]- 为什么要检查 `count > 0`
> 如果没有符合条件的数据，直接计算 `sum / count` 会发生除以零。聚合代码应明确处理空输入和零匹配结果。

## 6. 变量、数值转换与文本清理

AWK 变量不需要预先声明。变量会根据使用场景参与字符串或数值运算。

```bash
awk -F, 'NR > 1 {
  runtime = $12 + 0
  nodes = $5 + 0
  estimated_cu = nodes * runtime / 3600
  print $1, estimated_cu
}' runtime_results.csv
```

这里的 `+ 0` 明确表达“把字段按数值使用”。但它不会验证原始内容是否合法：非数字文本通常会被当作 `0`，因此重要数据应先检查格式。

`gsub()` 用于替换当前记录或指定字段中的所有匹配：

```bash
# 删除当前记录里的所有回车符，常用于清理 CRLF 残留
gsub(/\r/, "")

# 只清理第 15 个字段
gsub(/\r/, "", $15)
```

完整命令示例：

```bash
awk -F, '{ gsub(/\r/, "", $14); print $14 }' runtime_results.csv
```

## 7. 实例一：从日志中提取运行时间

假设 `run.log` 内容如下：

```text
Problem size: 2240x2240
Iterations: 350
Time (sec): 12.35
Status: completed
```

目标是找到固定标签 `Time (sec):`，并提取数值：

> [!success]- 完整命令
> ```bash
> awk 'index($0, "Time (sec):") { print $3 }' run.log
> ```
>
> 输出：
>
> ```text
> 12.35
> ```

选择 `index()` 是因为目标是固定文本，不需要正则能力。若日志格式可能出现多个空格，默认的空白字段切分仍能正确把 `12.35` 识别为 `$3`。

如果同一日志可能包含多次运行，可以同时标出匹配行号：

```bash
awk 'index($0, "Time (sec):") { print NR, $3 }' run.log
```

## 8. 实例二：处理 HPC 实验 CSV

下面沿用项目脚本中的字段约定：

| 字段 | 含义 |
| --- | --- |
| `$1` | scale |
| `$5` | nodes |
| `$9` | iterations |
| `$12` | runtime_seconds |
| `$14` | status |

这些编号只适用于对应的 `runtime_results.csv` 结构。表头顺序改变后，字段编号也必须同步修改。

### 筛选完成的记录

```bash
awk -F, 'NR > 1 && $14 == "completed" { print $0 }' runtime_results.csv
```

### 统计完成的记录数

```bash
awk -F, 'NR > 1 && $14 == "completed" { count++ }
         END { print count + 0 }' runtime_results.csv
```

### 计算估算 CU

若 CU 的定义为：

$$
\mathrm{estimated\ CU} = \frac{\mathrm{nodes} \times \mathrm{runtime\ seconds}}{3600}
$$

则可以写成：

```bash
awk -F, 'NR > 1 && $14 == "completed" {
  nodes = $5 + 0
  runtime = $12 + 0
  estimated_cu = nodes * runtime / 3600
  printf "%s %.4f\n", $1, estimated_cu
}' runtime_results.csv
```

### 生成 Markdown 表格行

```bash
awk -F, 'NR > 1 && $14 == "completed" {
  printf "| %s | %d | %.2f |\n", $1, $9, $12
}' runtime_results.csv
```

输出形如：

```markdown
| small | 350 | 12.35 |
| medium | 420 | 31.80 |
```

> [!summary]- 当前实例复杂度
> - 时间复杂度：$O(n)$，每条记录只处理一次。
> - 额外空间：$O(1)$，这里只保存固定数量的统计变量。
> - 如果使用数组按 scale 分组统计，额外空间会变为 $O(k)$，其中 $k$ 是不同 scale 的数量。

## 9. 关键边界与常见易错点

> [!warning]- 易错点
> - **忘记 CSV 分隔符**：`awk '{ print $1 }' file.csv` 默认按空白拆分，可能把整行当作 `$1`；简单 CSV 应使用 `-F,`。
> - **把 `$1` 当成第 1 行**：字段用 `$1`，行号用 `NR`。
> - **字符串不加引号**：`$14 == completed` 会把 `completed` 当作变量；正确写法是 `$14 == "completed"`。
> - **双引号包 AWK 程序**：Shell 可能提前展开 `$1`、`$2`；AWK 程序通常放在单引号中。
> - **把 `/Time/` 当作字段匹配**：裸正则匹配整行；只匹配第 1 个字段应写 `$1 ~ /Time/`。
> - **平均值没有处理空结果**：在 `END` 中除法前检查 `count > 0`。
> - **误把 `-F,` 当完整 CSV 支持**：含引号逗号或换行的 CSV 需要专用解析器。
> - **依赖固定列号却忽略表头变化**：数据列顺序调整后，所有 `$n` 都要复核。
> - **忘记 `printf` 不自动换行**：需要在格式字符串末尾写 `\n`。

### `NR` 与多个输入文件

读取多个文件时，`NR` 会持续累计，而 `FNR` 会在每个新文件开始时重新从 1 计数：

```bash
awk '{ print FNR, NR, $0 }' first.txt second.txt
```

如果只处理一个文件，通常使用 `NR` 就够了。

## 10. 常用命令速查

| 需求 | 命令 |
| --- | --- |
| 打印整行 | `awk '{ print $0 }' file.txt` |
| 打印第 1、3 个字段 | `awk '{ print $1, $3 }' file.txt` |
| 打印最后一个字段 | `awk '{ print $NF }' file.txt` |
| 给每行加行号 | `awk '{ print NR, $0 }' file.txt` |
| 匹配包含 `Time` 的行 | `awk '/Time/' log.txt` |
| 只匹配第 1 个字段 | `awk '$1 ~ /^small/' file.txt` |
| 按逗号拆分 | `awk -F, '{ print $1, $4 }' file.csv` |
| 跳过表头 | `awk -F, 'NR > 1' file.csv` |
| 统计匹配行数 | `awk '条件 { n++ } END { print n + 0 }' file` |
| 求某列平均值 | `awk '{ sum += $3; n++ } END { if (n) print sum / n }' file` |

> [!tip]- 可直接复用的统计模板
> ```bash
> awk -F, '
>   NR > 1 && 条件 {
>     value = $列号 + 0
>     sum += value
>     count++
>   }
>   END {
>     if (count > 0)
>       print sum / count
>     else
>       print "no matching records"
>   }
> ' file.csv
> ```

## 一句话总结

看到“逐行读取、按字段筛选、重新格式化或一次扫描完成统计”时，优先想到 `awk '条件 { 动作 } END { 汇总 }' 文件`。
