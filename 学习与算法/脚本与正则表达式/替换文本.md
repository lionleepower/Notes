# Python re.sub：按模式替换，还能边匹配边计算

`re.sub(pattern, repl, string)` 用正则 (regex) 匹配文本并替换。它比 `str.replace` 强的地方是：匹配用**模式**而非固定字面量，替换端还能**引用捕获组**甚至**传函数做计算**。凡是遇到「按规则批量改写文本」——归一化空白、重排格式、打码脱敏、查表映射——都优先想到它。

---

## 思路

不用它的问题：`str.replace` 只能「固定串换固定串」，一旦「要匹配的东西有规律但不完全一样」（所有数字、所有日期、所有 `xxx元`），它就无能为力。手写循环切片处理这些又极其啰嗦易错。

它为什么适合：`re.sub` 把能力分成递进的三档——① 替换成**固定字符串**（匹配到什么都不管，一律换掉）；② 替换串里**引用捕获组** `\1`（把匹配的一部分搬运、重排）；③ 替换参数传**函数**（每个匹配调用一次，参数是 match 对象，返回值就是替换结果，从而能做任意计算）。第三档是真正的杀手锏，前两档只能搬运文本，函数能计算。

> [!tip]- 核心思路 「匹配靠 pattern，替换靠 repl；repl 可以是字符串、带 `\1` 的模板、或一个函数」。
> 
> ```python
> import re
> 
> re.sub(r"\s+", " ", text)                    # ① 固定串
> re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\2/\3/\1", text)  # ② 引用捕获组
> re.sub(r"(\d+)", lambda m: str(int(m.group(1)) * 2), text)  # ③ 传函数
> ```
> 
> 判断依据：替换结果需要「算」出来（而非照搬）时，就必须用第三档的函数形式。

---

## 1. 导入与创建

标准库 `re`，无需安装。核心签名如下，`repl` 是唯一会变形态的参数。

> [!success]- 基础语法
> 
> ```python
> import re
> 
> # re.sub(pattern, repl, string, count=0, flags=0)
> #   pattern : 正则模式（建议 raw string，如 r"\d+"）
> #   repl    : 替换内容 —— 字符串 / 带 \1 的模板串 / 函数
> #   string  : 被处理的原文
> #   count   : 最多替换几次，0 表示全部（默认）
> ```

---

## 2. 核心操作

|操作|作用|时间复杂度或注意事项|
|---|---|---|
|`re.sub(p, "X", s)`|每个匹配都换成固定串 `X`|$O(n)$（典型），无视匹配内容|
|`re.sub(p, r"\1", s)`|替换串引用第 1 个捕获组|替换串**必须 raw string**，否则 `\1` 被误解|
|`re.sub(p, func, s)`|每个匹配调用 `func(m)`，用返回值替换|`func` 返回值**必须是 str**|
|`re.subn(p, r, s)`|同 sub，但额外返回替换次数|返回 `(新串, 次数)`，调试利器|
|`re.sub(p, r, s, count=1)`|只替换前 `count` 处|`count=0`（默认）= 全部替换，别误解为零次|

> [!example]- 最小示例
> 
> ```python
> import re
> 
> # ① 固定串：把连续空白（空格/制表符/换行）压成单个空格
> print(re.sub(r"\s+", " ", "hello   world\t!"))   # 'hello world !'
> 
> # ② 捕获组：日期 2026-07-15 → 07/15/2026
> print(re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\2/\3/\1", "截止 2026-07-15"))
> # '截止 07/15/2026'
> ```

---

## 3. 关键行为与边界

最容易踩的两个坑：替换串里的反斜杠转义、以及 `count=0` 的反直觉语义。函数形式还有「必须返回字符串」的硬要求。

> [!tip]- 为什么这样做 `\1` 里的反斜杠会**先被 Python 字符串层解释**再交给 re，所以不写 raw string 时 `"\1"` 会变成一个不可见的控制字符 `\x01` 而非「第 1 组」。写成 `r"\1"` 让反斜杠原样传给 re，才被当作分组引用。同理 pattern 也几乎总该用 raw string。

> [!warning]- 边界条件
> 
> - **分组引用消歧**：`\1` 后紧跟数字会歧义，`r"\10"` 被读成「第 10 组」而非「第 1 组 + 字符 0」。要表达后者用 `r"\g<1>0"`。
> - **函数返回值**：repl 是函数时返回值**必须是 str**，返回 int 会 `TypeError`，记得 `str(...)` 包一层。
> - **无匹配**：模式一次都没命中时，`re.sub` 原样返回输入串，不报错——这也是 bug 静默的来源，用 `subn` 看次数排查。
> - **`count` 语义**：`count=0`（默认）表示**替换全部**，不是替换零次；`count=1` 才是只换第一处。

## 4. 实例一：文本归一化与格式重排

输入：脏乱的文本（多余空白、非标准日期）；目标：清洗成统一格式。这是 `re.sub` 最高频的用途，属于前两档能力（固定串 + 捕获组），不需要计算。

> [!success]- 完整实现
> 
> ```python
> import re
> 
> 
> def normalize(text):
>     # ① 多段空白 → 单空格，并去掉首尾空白
>     text = re.sub(r"\s+", " ", text).strip()
>     # ② 手机号打码：保留前 3 后 4，中间 4 位换成 *
>     text = re.sub(r"(\d{3})\d{4}(\d{4})", r"\1****\2", text)
>     return text
> 
> 
> print(normalize("  联系  13812345678 \t 谢谢 "))
> # '联系 138****5678 谢谢'
> ```

主流程：先压空白、再脱敏。最容易写错的位置是**替换串忘了 raw string**——`"\1****\2"` 里的 `\1` 会被 Python 提前吃掉，必须写 `r"\1****\2"`。

---

## 5. 实例二：传函数——边匹配边计算

输入：含数值的文本；目标：对每个匹配到的数字**做运算**后再替换。前两档做不到「算」，只有函数形式能做。这是体现 `re.sub` 真正威力的场景。

> [!success]- 完整实现
> 
> ```python
> import re
> 
> 
> # 场景 A：所有价格打八折
> def discount(m):
>     return str(round(int(m.group(1)) * 0.8)) + "元"
> 
> print(re.sub(r"(\d+)元", discount, "苹果30元，梨20元"))
> # '苹果24元，梨16元'
> 
> 
> # 场景 B：华氏转摄氏
> print(re.sub(
>     r"(\d+)F",
>     lambda m: f"{(int(m.group(1)) - 32) * 5 // 9}C",
>     "今天 86F，明天 95F",
> ))
> # '今天 30C，明天 35C'
> 
> 
> # 场景 C：查表映射（罗马数字 → 阿拉伯数字）
> ROMAN = {"I": "1", "II": "2", "III": "3"}
> print(re.sub(r"\b(I{1,3})\b", lambda m: ROMAN[m.group(1)], "Chapter II and III"))
> # 'Chapter 2 and 3'
> ```

> [!summary]- 当前实例复杂度
> 
> - 时间复杂度：$O(n + k \cdot c)$，$n$ 为文本长度（一次扫描完成匹配），$k$ 为匹配次数，$c$ 为单次回调 (callback) 的计算成本；查表场景 $c = O(1)$，整体 $O(n)$。
> - 空间复杂度：$O(n)$，结果是一个新字符串（Python 字符串不可变，无法原地修改）。

---

## 6. 与相近写法怎么选

|需求|推荐写法|原因|
|---|---|---|
|固定串换固定串，无模式|`str.replace`|无需正则引擎，更快更直观|
|按模式匹配 + 固定替换|`re.sub(p, "X", s)`|`str.replace` 无法表达「所有数字」这类模式|
|搬运/重排匹配内容|`re.sub(p, r"\1...", s)`|捕获组引用，零计算|
|替换结果需要计算/查表|`re.sub(p, func, s)`|只有函数形式能对匹配做运算|
|想知道替换了几次（调试）|`re.subn(p, r, s)`|返回次数，`0` 即规则没命中|

---

## 7. 常见易错点

> [!warning]- 易错点
> 
> - 替换串忘写 raw string：`"\1"` 被 Python 解释成控制字符，正确写法是 `r"\1"`。
> - 分组引用紧跟数字：`r"\10"` 是「第 10 组」，想接字面 `0` 要用 `r"\g<1>0"`。
> - 函数返回非字符串：回调返回 int/None 会 `TypeError`，务必 `str(...)`。
> - 误以为 `count=0` 是零次：`0` 表示替换**全部**，只换第一处要显式 `count=1`。
> - 规则悄悄没命中：`re.sub` 无匹配时静默返回原串，怀疑规则没生效时用 `re.subn` 查次数。

---

## 复杂度

> [!summary]- 复杂度
> 
> - 核心流程：时间复杂度典型为 $O(n)$，$n$ 为文本长度，正则引擎一次扫描完成匹配与替换。
> - 病态回溯：含嵌套量词的模式（如 `(a+)+`）遇到特定输入可能触发灾难性回溯 (catastrophic backtracking)，退化到指数级，写模式时要避免。
> - 额外空间：$O(n)$，因字符串不可变，必然生成新串；函数形式额外承担 $k$ 次回调的调用开销，$k$ 为匹配次数。

---

## 一句话总结

`re.sub` 是「按正则模式改写文本」的工具，看到「有规律的批量替换」信号就用它，关键在于替换端三档形态：固定串照换、`r"\1"` 搬运重排、传函数则能边匹配边计算。

## 模板归纳

看到以下信号时，优先想到 `re.sub`：

- 「把所有 XXX 换成 YYY」，且 XXX 是**模式**而非固定字面量（所有数字、所有日期、所有 `#tag`）。
- 需要**保留匹配的一部分、改写另一部分**（脱敏、格式重排）。
- 替换结果需要**算出来或查表**得到，而不是照搬原文。

```python
# 可直接复用的最小模板：带计算的替换
import re


def transform(text):
    def repl(m):
        # m.group(0) 整个匹配；m.group(1) 第 1 个捕获组
        value = int(m.group(1))
        return str(value)  # 计算后务必返回字符串

    return re.sub(r"(\d+)", repl, text)
```
