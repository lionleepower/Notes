# Vim：用模式和动作高效编辑文本

Vim 的核心不是记住大量快捷键，而是理解 mode、motion 与 operator 的组合。先掌握安全退出、基础移动和搜索，再逐步形成肌肉记忆。

---

## 1. 模式

| 模式 | 进入 | 用途 |
| --- | --- | --- |
| Normal | `Esc` | 移动与执行命令 |
| Insert | `i`、`a`、`o` | 输入文本 |
| Visual | `v`、`V` | 选择文本 |
| Command-line | Normal 中输入 `:` | 保存、退出、替换、配置 |

## 2. 生存命令

```text
:w       保存
:q       退出
:wq      保存并退出
:q!      放弃未保存修改并退出
u        撤销
Ctrl-r   重做
```

遇到不确定状态先按 `Esc` 回到 Normal mode。

## 3. 移动与编辑

| 命令 | 作用 |
| --- | --- |
| `h j k l` | 左下上右 |
| `w` / `b` / `e` | 按单词移动 |
| `0` / `^` / `$` | 行首、首个非空白、行尾 |
| `gg` / `G` | 文件开头 / 结尾 |
| `x` | 删除字符 |
| `dd` / `yy` | 删除 / 复制整行 |
| `p` / `P` | 在光标后 / 前粘贴 |

Vim 组合 operator 与 motion：`dw` 删除到下一个单词，`d$` 删除到行尾，`3dd` 删除三行。

## 4. 搜索与替换

```text
/PATTERN       向下搜索
n / N          下一个 / 上一个
:%s/old/new/g  全文件替换
:%s/old/new/gc 每次替换前确认
```

Vim pattern 不是所有正则工具完全相同的语法，复杂替换应先缩小范围或使用确认选项。

## 5. 分屏与 Shell

```text
:split FILE
:vsplit FILE
Ctrl-w h/j/k/l
:!make
:terminal
```

`Ctrl-Z` 会暂停 Vim，使用 Shell 的 `fg` 返回；它不是退出命令。

## 6. 最小配置

```vim
syntax on
set number
set expandtab
set tabstop=4
set shiftwidth=4
```

不同项目对 tab 有不同要求，不要把个人默认值误当作通用标准。

> [!success]- 推荐练习
> ```bash
> vimtutor
> ```

> [!warning]- 易错点
> - 删除内容会进入 register，之后粘贴结果可能变化。
> - `:q!` 会丢弃当前 buffer 未保存的修改。
> - `source` Shell 脚本与 Vim 的 `:source` 配置文件不是同一语境。
