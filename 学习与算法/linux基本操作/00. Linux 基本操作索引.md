# Linux 基本操作索引：从系统概念到命令行实践

这组笔记面向 Linux 初学者、HPC 用户与面试复习。推荐先理解系统模型，再学习 Shell、编辑器和运维常识；练习笔记用于第二遍主动回忆。

---

## 学习路线

```text
Linux 背景与系统模型
→ Shell 命令、路径与文件操作
→ I/O、搜索、管道、作业与环境变量
→ 文本编辑器
→ 账户、SSH、文件系统与权限
```

> [!tip]- 使用方法
> - 第一次阅读：按编号顺序学习，并亲手运行安全示例。
> - 第二次复习：只看每篇的核心结论、表格和易错点。
> - 面试准备：优先阅读带 `#interview/important` 的主题，再回答折叠自测题。
