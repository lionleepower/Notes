# 重定向练习：查看文件、输入流与脚本执行

这些练习把 `cat`、`less`、`head`、`tail` 和输入重定向放进可观察的数据流中。

---

## 练习 1：保存并查看目录列表

> [!success]- 答案
> ```bash
> ls -l /etc > mylist.txt
> less mylist.txt
> ```
>
> `cat` 适合短文件，`less` 适合长文件，`head` 和 `tail` 用于查看开头或结尾。

## 练习 2：覆盖与追加

> [!success]- 答案
> ```bash
> printf '%s\n' 'first line' > notes.txt
> printf '%s\n' 'second line' >> notes.txt
> cat notes.txt
> ```

## 练习 3：实时查看日志

> [!success]- 答案
> ```bash
> tail -n 20 run.log
> tail -f run.log
> ```
>
> `tail -f` 持续跟踪增长的文件，按 `Ctrl-C` 结束。日志轮转时可根据实现考虑 `tail -F`。

## 练习 4：stdin 透传脚本

创建：

```sh
#!/bin/sh
cat
```

然后比较：

> [!success]- 答案
> ```bash
> chmod u+x tryme.sh
> ./tryme.sh < notes.txt
> sh tryme.sh < notes.txt
> . ./tryme.sh < notes.txt
> ```
>
> `./tryme.sh` 根据 shebang 启动解释器；`sh tryme.sh` 明确由 `sh` 读取文件；`.` 或 `source` 在当前 Shell 中执行并忽略 shebang 的解释器选择。此脚本只运行 `cat`，三者输出相同，但环境副作用不同。

## 练习 5：分别保存正常与错误输出

> [!success]- 答案
> ```bash
> COMMAND > stdout.log 2> stderr.log
> ```

## 练习 6：合并显示并保存

> [!success]- 答案
> ```bash
> set -o pipefail
> COMMAND 2>&1 | tee run.log
> status=$?
> ```

> [!warning]- 易错点
> - `cat` 无参数会读终端 stdin，看起来像“卡住”；按 `Ctrl-D` 发送 EOF。
> - `source` 会改变当前 Shell，普通脚本不应仅为省略执行权限而使用它。
> - shebang 只有直接执行文件时由系统用于选择解释器。
> - 不要用 `cat > IMPORTANT_FILE` 练习，`>` 会立即截断文件。
