# Linux 搜索：区分文件路径与文件内容

找文件名使用 `find` 或 `locate`，找文件内容使用 `grep`。先判断搜索对象，再选择实时遍历、索引查询或正则匹配。

---

## 核心对比

| 工具 | 搜索对象 | 特点 |
| --- | --- | --- |
| `find` | 目录树中的文件 | 实时、条件丰富、可能较慢 |
| `locate` | 路径数据库 | 很快，但数据库可能过期 |
| `grep` | 文本内容 | 按字符串或正则筛选行 |

## 1. find

```bash
find . -type f -name '*.txt'
find "$HOME" -type d -name results
find . -type f -mtime -7 -print
```

`'*.txt'` 要加引号，防止当前 Shell 先展开；`find` 才能在遍历过程中对每个名称匹配。

```bash
find . -type f -name '*.log' -exec grep -H 'ERROR' {} +
```

使用 `-delete` 或 `-exec rm` 前先用 `-print` 验证结果。

## 2. locate

```bash
locate report.pdf
```

`locate` 查询预建数据库，新文件可能尚未收录，已删除文件也可能短暂残留。数据库更新方式和权限取决于系统。

## 3. grep

```bash
grep -n 'ERROR' run.log
grep -inF 'time (sec):' run.log
grep -RIn --include='*.sh' 'SBATCH' scripts/
```

| 选项 | 含义 |
| --- | --- |
| `-i` | 忽略大小写 |
| `-n` | 显示行号 |
| `-v` | 反向选择 |
| `-F` | 固定字符串，不解释正则 |
| `-E` | 扩展正则 |
| `-R` | 递归并跟随命令行符号链接语义 |

grep 的常见退出状态：`0` 有匹配，`1` 无匹配，`2` 发生错误；“无匹配”不等于命令损坏。

> [!warning]- 易错点
> - `find . -name *.txt` 可能被 Shell 提前展开。
> - `grep` 默认区分大小写并按行输出。
> - Binary file、权限错误和换行格式会影响结果。
> - 搜索文件内容不要先无意义地写 `cat FILE | grep`，直接 `grep PATTERN FILE` 更清楚。
