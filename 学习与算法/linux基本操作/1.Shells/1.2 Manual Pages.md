# Linux Manual Pages：用系统文档解决命令问题

`man` 提供本机已安装命令、系统调用、配置格式和库函数的权威说明。遇到陌生命令时，应先定位正确 section，再阅读 synopsis、options 和 examples。

---

## 核心命令

```bash
man COMMAND
man SECTION NAME
man -k KEYWORD
```

| Section | 内容 | 示例 |
| --- | --- | --- |
| 1 | 用户命令 | `man 1 printf` |
| 2 | system call | `man 2 open` |
| 3 | library function | `man 3 printf` |
| 5 | 文件格式与配置 | `man 5 passwd` |
| 7 | 惯例、协议与概览 | `man 7 signal` |
| 8 | 管理命令 | `man 8 mount` |

同名条目可能存在于不同 section，因此 `man printf` 和 `man 3 printf` 不一定相同。

## 如何读 SYNOPSIS

```text
command [OPTION]... FILE...
```

- `[]` 表示可选；
- `...` 表示可重复；
- 粗体或普通命令名按字面输入；
- `FILE` 等大写词是需要替换的参数。

不要把方括号或省略号原样输入命令。

## 页面导航

| 按键 | 作用 |
| --- | --- |
| `Space` / `PageDown` | 向下翻页 |
| `b` / `PageUp` | 向上翻页 |
| `/PATTERN` | 向下搜索 |
| `n` / `N` | 下一个 / 上一个匹配 |
| `q` | 退出 |

`man` 通常调用 `less` 作为 pager，所以导航方式相似。

## 找不到页面时

```bash
man -k 'copy files'
apropos 'copy files'
COMMAND --help
```

`--help` 不是统一标准，某些命令使用其他方式；没有安装对应文档包时，`man` 也可能找不到页面。

> [!warning]- 安全阅读
> 阅读 `rm`、`chmod` 或 `mount` 文档不等于应直接尝试高风险示例。先在临时测试目录确认路径和选项。

> [!question]- 自测
> 1. 如何区分 `printf` 命令与 C library function？
> 2. SYNOPSIS 中的 `[]` 是否要输入？
> 3. 如何按功能关键词搜索未知命令？

## 一句话总结

使用 man page 时先选对 section，再从 SYNOPSIS 理解语法，从 OPTIONS 和 SEE ALSO 深入。
