# 文件与目录操作：创建、复制、移动和安全删除

Linux 文件操作通常不可撤销，尤其是覆盖和删除。可靠工作流应先确认当前目录与展开结果，再执行修改命令。

---

## 核心命令

| 命令 | 作用 | 关键选项 |
| --- | --- | --- |
| `mkdir` | 创建目录 | `-p` 创建缺失父目录 |
| `touch` | 更新时间戳；不存在时创建空文件 | 不会清空已有文件 |
| `cp` | 复制 | `-a` 保留结构和属性，`-i` 覆盖前询问 |
| `mv` | 移动或重命名 | `-i` 覆盖前询问 |
| `rm` | 删除目录项 | `-r` 递归，`-i` 询问 |
| `rmdir` | 删除空目录 | 非空时拒绝 |

## 1. 创建与复制

```bash
mkdir -p project/{src,data,results}
touch project/README.md
cp -- input.txt project/data/
cp -a -- project project-backup
```

复制目录时需要递归语义。`cp -a` 通常比简单的 `cp -r` 更适合备份，因为它还尝试保留链接、时间和权限。

## 2. 移动与重命名

```bash
mv -- draft.txt report.txt
mv -i -- report.txt results/
```

目标是已存在目录时，源会移动进去；目标不是目录时，操作通常相当于重命名。跨文件系统移动可能退化为“复制后删除”，不再是瞬时操作。

## 3. 删除前的安全流程

```bash
pwd
printf '%s\n' ./*.tmp
rm -i -- ./*.tmp
```

> [!warning]- 高风险命令
> `rm -rf` 不经过回收站。不要在变量未验证、路径为空或通配符结果不明确时使用。笔记中的递归删除示例只应在明确创建的测试目录中练习。

`--` 可防止以 `-` 开头的文件名被解释成选项：

```bash
rm -- -strange-name
```

## 4. 完整示例

```bash
mkdir -p demo/input demo/output
touch demo/input/data.txt
cp demo/input/data.txt demo/output/data.bak
mv demo/output/data.bak demo/output/data.txt
find demo -maxdepth 2 -print
```

> [!warning]- 易错点
> - `touch FILE` 不等于清空文件。
> - `mv` 与 `cp` 都可能覆盖同名目标，是否询问受选项和 alias 影响。
> - 先用 `ls` 检查通配符只能辅助观察，真正执行前仍要核对路径。
> - 修改文件内容需要文件写权限；删除文件主要取决于父目录权限。
