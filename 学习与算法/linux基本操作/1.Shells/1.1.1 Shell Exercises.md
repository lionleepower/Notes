# Shell 基础练习：PATH、Shell、时间与进程

这组练习用于验证命令查找、系统文件读取和进程观察。先独立写命令，再展开答案。

---

## 练习 1：查看 PATH

输出当前 `PATH`，并说明冒号的含义。

> [!success]- 答案
> ```bash
> printf '%s\n' "$PATH"
> ```
>
> `PATH` 是按冒号分隔的目录列表，Shell 从左到右查找外部命令；它不是可执行文件列表。

## 练习 2：确认命令来自哪里

判断 `cd` 与 `python3` 是 builtin、alias 还是外部命令。

> [!success]- 答案
> ```bash
> type -a cd
> type -a python3
> command -v python3
> ```

## 练习 3：查看可用登录 Shell

> [!success]- 答案
> ```bash
> cat /etc/shells
> ```
>
> 文件通常列出系统认可的登录 Shell。它不表示当前正在使用哪一个，也可能包含 `/sbin/nologin` 等禁止交互登录的程序。

## 练习 4：查看当前 Shell

> [!success]- 答案
> ```bash
> printf '%s\n' "$SHELL"
> ps -p "$$" -o pid,comm,args=
> ```
>
> `$SHELL` 通常记录登录 Shell；当前进程可能是后来启动的另一个 Shell，因此用 `$$` 查看当前 Shell PID 更可靠。

## 练习 5：查看时间

> [!success]- 答案
> ```bash
> date
> date '+%Y-%m-%d %H:%M:%S %Z'
> ```

## 练习 6：观察进程

显示当前终端相关进程，并解释为什么输出中可能看到 `ps` 自己。

> [!success]- 答案
> ```bash
> ps
> ps -o pid,ppid,stat,cmd
> ```
>
> `ps` 在收集进程信息时本身也是活跃进程，所以可能出现在快照里。

## 综合练习

1. 创建一个不在 `PATH` 中的脚本，解释为什么要用 `./script.sh`。
2. 比较 `type ls`、`command -v ls` 与 `which ls`；哪个更了解当前 Shell 的 builtin、function 和 alias？
3. 运行一个失败的 `grep`，立即观察 `$?`。

> [!warning]- 易错点
> - 不要把 `/etc/shells` 当作“正在运行的 Shell 列表”。
> - `$SHELL` 与当前 Shell 进程不一定相同。
> - `ps` 是瞬时快照，持续观察应使用 `top` 或其他监控工具。
