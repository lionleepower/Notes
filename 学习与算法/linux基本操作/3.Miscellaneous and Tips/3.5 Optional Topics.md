# Linux 补充主题：归档、链接、sudo、包管理与挂载

这些工具处理系统日常维护，但风险级别不同：归档和链接通常是用户操作，sudo、包管理和挂载可能改变整个系统。

---

## 1. tar 与 gzip

`tar` 负责把多个路径归档，gzip 负责压缩字节流；`.tar.gz` 表示先归档再 gzip 压缩。

```bash
tar -cf project.tar project/
tar -tf project.tar
tar -xf project.tar
tar -czf project.tar.gz project/
tar -tzf project.tar.gz
tar -xzf project.tar.gz
```

> [!warning]- 解包安全
> 先用 `-t` 查看归档内容，再解压到明确的空目录。来自不可信来源的归档可能包含路径穿越、符号链接或覆盖目标。

## 2. Symbolic Link

```bash
ln -s TARGET LINK_NAME
readlink LINK_NAME
readlink -f LINK_NAME
```

Symlink 保存目标路径。相对目标是相对于“链接所在目录”解析，不是相对于创建命令时的工作目录。目标删除后链接会 dangling。

## 3. Root 与 sudo

| 概念 | 含义 |
| --- | --- |
| `/` | 文件系统根目录 |
| `/root` | root 用户 home |
| UID 0 | 内核视角的超级用户身份 |
| `sudo` | 按 sudo policy 以其他用户身份执行命令 |

```bash
sudo -l
sudo COMMAND
```

编辑 sudoers 应使用 `visudo`。不要对不理解的网络脚本直接使用 sudo。

## 4. Package Manager

| 系统 | 高层工具 | 底层格式/工具 |
| --- | --- | --- |
| Debian / Ubuntu | `apt` | `.deb`、`dpkg` |
| Fedora / RHEL 系 | `dnf` | RPM |
| Arch Linux | `pacman` | Arch package |

```bash
sudo apt update
sudo apt install PACKAGE
sudo dnf install PACKAGE
```

`update` 通常刷新软件源元数据，`upgrade` 才升级已安装软件。HPC 普通用户通常无 sudo，应使用站点 module、容器或用户环境。

## 5. Mount

挂载把一个 filesystem 接到目录树的 mount point。

```bash
findmnt
lsblk -f
sudo mount DEVICE MOUNT_POINT
sudo umount MOUNT_POINT
```

命令是 `umount`。卸载前确保没有进程把工作目录或打开文件留在该 filesystem，可用 `findmnt`、`lsof` 或 `fuser` 排查。`/etc/fstab` 配置错误可能影响启动，应先验证配置。

## 怎么选

| 需求 | 工具 |
| --- | --- |
| 打包多个文件 | `tar` |
| 减小归档体积 | `tar` + gzip |
| 为长路径建立入口 | `ln -s` |
| 安装系统软件 | 发行版 package manager |
| HPC 加载预装软件 | `module` |
| 接入新 filesystem | `mount` |

> [!warning]- 共同原则
> 涉及 sudo、设备、系统目录或递归操作时，先确认对象、查看 dry-run/列表、备份配置，并遵守系统管理员或 HPC 站点规范。
