# 列表构建四件套：append / extend / += / * 解包

来源：task_008 scaling_report 的 parts 拼接（2026-07-14）。

## 一句话总览

| 语法 | 加几个元素 | 就地还是新建 | 典型用途 |
|---|---|---|---|
| `lst.append(x)` | **1 个**（x 是什么就塞什么） | 就地 | 循环里逐个攒 |
| `lst.extend(iter)` | iter 里的**每个元素** | 就地 | 把另一个列表摊平并入 |
| `lst += iter` | 同 extend | 就地 | extend 的运算符写法 |
| `[a, *iter, b]` | 字面量里摊平 iter | **新建**列表 | 声明式地一次拼好 |

## 逐个例子

```python
parts = ["# 标题"]
bullets = ["- 甲", "- 乙"]

# append：整个对象作为一个元素 —— 传列表会嵌套！
parts.append("## 解读")        # ["# 标题", "## 解读"]
parts.append(bullets)          # [..., ["- 甲", "- 乙"]]  ← 嵌套，join 时 TypeError

# extend：把可迭代对象逐个摊平加入
parts.extend(bullets)          # [..., "- 甲", "- 乙"]

# +=：语义同 extend（就地修改）
parts += bullets               # 同上
parts += ["尾行"]              # 加单个元素也要包成列表

# * 解包：在字面量里摊平，一次声明整段结构
parts += ["## 解读", *bullets, ""]
# 等价于三行：append("## 解读") + extend(bullets) + append("")
```

## 三个高频坑

**1. append 一个列表 = 嵌套一层**（task_008 实际踩过的形态）：

```python
["## 亮点", bullets, ""]     # 3 个元素，中间是 list → "\n".join 爆 TypeError
["## 亮点", *bullets, ""]    # 摊平，全是 str ✅
```

**2. extend / += 遇到字符串会拆成单字符**（字符串也是可迭代的）：

```python
parts.extend("abc")   # [..., "a", "b", "c"]  ← 几乎永远不是你想要的
parts += "abc"        # 同样拆！
parts.append("abc")   # [..., "abc"] ✅ 加一整个字符串用 append
```

判断口诀：**加"一个东西"用 append，并"一串东西"用 extend/+=/解包**。

**3. += 就地修改，= lst + [...] 新建对象**——有别名（两个变量指向同一列表）时结果不同：

```python
a = [1]; b = a
a += [2]        # 就地：a 和 b 都变成 [1, 2]
a = a + [3]     # 新建：a 是 [1, 2, 3]，b 还是 [1, 2]
```

## `*` 的家族（同一符号，按位置区分收/放）

```python
[0, *lst, 9]              # 字面量里：摊开（放）
func(*args_list)          # 调用处：把列表拆成多个实参（放）
def f(*args): ...         # 定义处：把多个实参收进元组（收）
first, *rest = [1, 2, 3]  # 赋值处：收集剩余（收）
{**d1, **d2}              # 字典版：两个星号，合并（放）
```

记法：**定义/赋值处是"收拢"，调用/字面量处是"摊开"**。

## 本项目的实际锚点

```python
# hpc_agent/report.py — scaling_report 的 parts 拼接
parts = [f"# 问题规模 {unknowns}", ""]
parts += [SECTION_TABLE, _render_scaling_table(rows), ""]      # 并入固定几段
parts.append(SECTION_MODES)                                    # 单个元素
parts += [SECTION_READING, *_interpretation_bullets(rows), ""] # 摊平不定长 bullets
markdown = "\n".join(parts)                                    # 最后一次性拼接
```

选型逻辑：段落结构固定时用 `+= [..]` 按块声明；元素数量由数据决定（bullets）时用 `*` 摊平；真正的"逐个攒"（表格行循环）用 append。
