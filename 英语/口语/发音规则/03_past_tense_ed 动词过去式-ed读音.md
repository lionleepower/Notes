# 动词过去式 -ed 读音

## 1. 想解决什么问题？

为什么 `helped`, `wanted`, `played` 的 -ed 读音不一样？

## 2. 核心规则

-ed 的读音也取决于前一个音。

| 前一个音 | -ed 读音 | 例子 |
|---|---|---|
| 清辅音 /p/ /k/ /f/ /tʃ/ /ʃ/ | /t/ | helped, worked, watched, pushed |
| /t/ 或 /d/ | /ɪd/ | wanted, needed |
| 元音或其他浊辅音 | /d/ | turned, cleaned, played |

## 3. PDF 例词整理

### 读 /t/

| 原形 | 过去式 |
|---|---|
| help | helped |
| work | worked |
| watch | watched |
| push | pushed |
| stop | stopped |
| drop | dropped |
| jump | jumped |
| walk | walked |

### 读 /ɪd/

| 原形 | 过去式 |
|---|---|
| want | wanted |
| need | needed |
| vote | voted |

### 读 /d/

| 原形 | 过去式 |
|---|---|
| turn | turned |
| clean | cleaned |
| learn | learned / learnt |
| play | played |
| enjoy | enjoyed |
| love | loved |
| serve | served |

## 4. y 结尾变化

辅音字母 + y 结尾时，y 变 i 再加 -ed：

| 原形 | 过去式 |
|---|---|
| study | studied |
| try | tried |

## 5. 容易错在哪里？

- 容易把所有 -ed 都读成 /ɪd/。
- `worked`, `helped`, `watched` 不应该读成两个很明显的音节。
- `wanted`, `needed` 才需要明显读出 /ɪd/。

## 6. 练习句

```text
I worked yesterday.
She helped me.
He wanted to leave.
I needed more time.
They played football.
I enjoyed the movie.
```
