## 1. 想解决什么问题？

为什么 `present`, `record`, `increase` 作名词和动词时重音不同？

## 2. 核心规则

很多双音节词：

- 作名词时，重音常在前面
- 作动词时，重音常在后面

这不是绝对规则，但非常常见。

## 3. PDF 例词整理

| 名词重音 | 动词重音 |
|---|---|
| PRE-sent | pre-SENT |
| RE-cord | re-CORD |
| SUS-pect | sus-PECT |
| DE-crease | de-CREASE |
| IN-crease | in-CREASE |
| IN-sult | in-SULT |
| CON-flict | con-FLICT |
| PER-mit | per-MIT |
| RE-ject | re-JECT |
| RE-fuse | re-FUSE |
| OB-ject | ob-JECT |
| DES-ert | des-ERT |
| CON-tent | con-TENT |

## 4. 例句

```text
Jimmy bought me a lovely PRE-sent.
We have to pre-SENT a presentation next week.

We are going to re-CORD the new song.
We have a RE-cord of all the records.

There has been a DE-crease in the number of students.
The number of students de-CREASEd last year.

I re-FUSE to go out today.
Put the RE-fuse into the trash bin.
```

## 5. 容易错在哪里？

- 只记单词意思，不注意词性和重音。
- `present` 作名词和动词不是一个读法。
- `record` 作名词和动词重音不同。
- 说句子时，重音错了会影响别人理解。

## 6. 练习方法

每组都按这个方式练：

```
noun → verbPRE-sent → pre-SENTRE-cord → re-CORDIN-crease → in-CREASE
```

然后放进句子里练。
