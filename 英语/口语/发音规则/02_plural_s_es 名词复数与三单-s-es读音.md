# -s / -es 词尾读音

## 1. 想解决什么问题？

为什么 `books`, `bags`, `watches` 结尾的 s 读音不一样？

## 2. 核心规则

-s / -es 的读音主要看前一个音是什么，而不是只看拼写。

| 前一个音 | 词尾读音 | 例子 |
|---|---|---|
| 清辅音 /p/ /k/ /f/ /θ/ | /s/ | helps, breaks, cloths |
| 浊辅音或元音 | /z/ | pigs, pens, trees, days |
| /s/ /z/ /ʃ/ /tʃ/ /dʒ/ | /ɪz/ | fixes, pushes, watches, buses, pages |

## 3. PDF 例词整理

### 读 /s/

| 原形 | 加 s 后 |
|---|---|
| help | helps |
| break | breaks |
| cloth | cloths |
| breath | breaths |

### 读 /z/

| 原形 | 加 s 后 |
|---|---|
| need | needs |
| demand | demands |
| day | days |
| paper | papers |
| play | plays |
| pig | pigs |
| pen | pens |
| tree | trees |
| clothe | clothes |
| breathe | breathes |

### 读 /ɪz/

| 原形 | 加 es 后 |
|---|---|
| fix | fixes |
| push | pushes |
| watch | watches |
| bus | buses |
| page | pages |
| advantage | advantages |
| disadvantage | disadvantages |
| increase | increases |
| decrease | decreases |
| exercise | exercises |

## 4. y 结尾的变化

以辅音字母 + y 结尾时，y 变 i 再加 -es：

| 原形 | 变化 |
|---|---|
| study | studies |
| baby | babies |
| try | tries |

注意：`tries` 读 /traɪz/，不是 /traɪɪz/。

## 5. 常见小词中的 z 音

PDF 中特别提醒了一些常见词：

| 单词 | 实际读音倾向 |
|---|---|
| is | iz |
| his | hiz |
| was | waz |
| as | az / əz |
| these | theze |
| those | thoze |
| because | becauze |

## 6. 容易错在哪里？

- 看到 s 就全部读 /s/。
- 把 `days`, `papers`, `plays` 的结尾读得太轻。
- 把 `watches`, `buses`, `exercises` 的 /ɪz/ 漏掉。

## 7. 练习句
```
He helps me.
She needs paper.
The bus stops here.
He watches TV.
There are many advantages.
Because he was busy.
```
