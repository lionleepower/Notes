# 连读 Linking

## 1. 想解决什么问题？

为什么英语母语者说话时，单词之间不像一个个分开的词，而像一串声音？

## 2. 核心概念

连读是指前一个词的结尾音和后一个词的开头音连接起来。英语口语中很常见。

## 3. PDF 中的连读类型

### 类型一：辅音 + 辅音

当前一个单词结尾和后一个单词开头都是辅音时，可能出现省音、叠合或弱化。

#### 例子

```text
bad boy
I don’t care
I had a bad cold
active → a(c)tive
blackboard → bla(ck)board
football → foo(t)ball
```
#### 我的理解

不是每个辅音都要清楚爆破出来。自然语速中，有些爆破音会被弱化或省掉。

---

### 类型二：辅音 + 元音

当前一个单词以辅音结尾，后一个单词以元音开头时，两个词通常连起来读。

#### r + 元音

```
far awayfor agestake care of
```

#### l + 元音

```
She works in a school of law.
```

#### n + 元音

```
an answerlater onin an hourin an emergency
```

#### t + 元音

```
get innot alonenot at allget along with sb.
```

#### k + 元音

```
Take a seat, please.work out
```

#### s + 元音

```
She works in a school of law.
```

#### d + 元音

```
stand up
```

#### v + 元音

```
give upMay I have a cup of tea?
```

---

### 类型三：元音 + 元音

两个元音相遇时，中间常常自然滑出 /w/ 或 /j/。

#### 加 /w/ 的感觉

当前一个词以 /əʊ/, /aʊ/, /u/, /uː/ 结尾，后一个词以元音开头时，中间可能出现 /w/ 的滑音。

```
do ityou areshow usgo up
```

#### 加 /j/ 的感觉

当前一个词以 /eɪ/, /aɪ/, /ɔɪ/, /iə/, /i/, /iː/ 结尾，后一个词以元音开头时，中间可能出现 /j/ 的滑音。

```
say itshe isbe ablesee us
```

## 4. 容易错在哪里？

- 容易把每个单词都分开读。
- `get in` 不应该像两个完全断开的词。
- `go up` 中间会自然有一点 /w/ 的感觉。
- `say it` 中间会自然有一点 /j/ 的感觉。
