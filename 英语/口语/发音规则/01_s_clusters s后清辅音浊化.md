# s 后清辅音浊化

## 1. 想解决什么问题？

为什么 `student`, `school`, `space`, `street` 里面的 t / k / p 听起来不像普通的 /t/ /k/ /p/？

## 2. 核心规则

当清辅音 /p/ /t/ /k/ 出现在 /s/ 后面时，常常会变得接近对应的浊辅音：

| 拼写组合 | 实际听感 |
|---|---|
| st | 接近 sd |
| sk | 接近 sg |
| sp | 接近 sb |
| str | 接近 sdr |
| skr | 接近 sgr |
| spr | 接近 sbr |

注意：这不是拼写变化，而是发音听感变化。

## 4. 容易错在哪里？

- 把 `student` 读成很重的 /t/。
- 把 `school` 读得像中文“死酷”。
- 在 `spring`, `street`, `screen` 这种三个辅音连在一起的地方卡住。

## 5. 练习方法

先慢读，再连读：

```text
student, school, space
street, screen, spring
I am a student.
The school is far away.
Spring is coming.
```
