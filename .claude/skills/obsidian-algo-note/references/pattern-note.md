# Patterns 笔记模板（1.Patterns\）

根据输入自动选择一种模式，不要把两种结构混用：

- **单题模式**：一道具体算法题——围绕题意、核心思路、代码、易错点和复杂度展开。
- **专题模式**：同一算法模板下的多道题或多个变体——先讲统一模板，再分别说明典型变体之间「什么不变、什么改变」。专题笔记可省略难度标签。

`X.0` 总述笔记通常用专题模式；`X.1`、`X.2`… 视内容选单题或专题模式。

## 注意

- 模板中「真实存在的索引 / 专题」只是占位提示，输出时必须替换成真实文件或删除，不能原样保留。
- 没有对应内容的章节或 callout 直接省略，不输出空结构。
- 篇幅：单题折叠后 1～2 屏；专题以完整覆盖统一模板和关键变体为准。
- 优先保留：识别信号、核心不变量、关键代码、易错点、复杂度。
